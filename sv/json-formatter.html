  2. Välj en åtgärdTryck på Formatera för att göra den läsbar med indrag, Förminska för att krympa den till en rad eller Validera endast för att kontrollera den utan att ändra den.

Vad JSON är och varför formatering är viktigt

JSON, förkortning för JavaScript Object Notation, är det vanligaste sättet som datorer utbyter strukturerad data på på webben. API:er, konfigurationsfiler och många appar talar alla JSON eftersom det är enkelt att läsa och lätt för maskiner att analysera. Ett giltigt JSON-dokument är byggt av objekt inom klammerparenteser, arrayer inom hakparenteser, strängar inom dubbla citattecken, siffror och värdena true, false och null. Formatering förändrar inte vad data betyder, men det ändrar hur lätt det är för en människa att läsa. Minifierad JSON, med alla mellanslag borttagna, är mindre och snabbare att skicka över ett nätverk, varför API:er använder det, men det är nästan omöjligt att läsa eller felsöka. Förskönade JSON, med indrag i två mellanslag och ett värde per rad, är större men låter dig upptäcka ett saknat kommatecken eller en fel parentes på några sekunder.

De vanligaste JSON-felen

  • Saknade eller extra kommatecken: varje objekt i ett objekt eller array utom det sista behöver ett kommatecken, och ett avslutande kommatecken efter det sista objektet är inte tillåtet i strikt JSON.
  • Enkla citattecken istället för dubbla citattecken: JSON-strängar måste använda dubbla citattecken, även om JavaScript-koden ofta tillåter enkla citattecken.
  • Ociterade nycklar: objektnycklar måste vara citattecken, så {name: "Ana"} är ogiltigt och måste vara {"name": "Ana"}.
  • Kommentarer: JSON tillåter inte kommentarer, så rader som börjar med // kommer att avbryta analysen även om de ser ofarliga ut.
  • Efterföljande text eller flera dokument: att klistra in två JSON-objekt efter varandra är ogiltigt; slå in dem i en array eller fixa dem en i taget.

Formatering kontra förminskande: När ska man använda varje

Använd Format när du läser, felsöker eller lär dig från JSON, eftersom indrag avslöjar strukturen med en blick och gör kapsling uppenbar. Använd Minify när du behöver klistra in JSON i en URL, ett kompakt konfigurationsfält, en testförfrågan eller ett meddelande där storleken spelar roll och läsbarheten inte spelar roll. Använd endast Validera när du bara behöver ett ja-eller-nej-svar, till exempel innan du sparar en konfigurationsfil, eftersom den kontrollerar JSON utan att ersätta din ursprungliga text. I alla tre fallen analyserar verktyget först JSON, så att ett minifierat eller formaterat resultat garanterat är giltigt; om analysen misslyckas, får du ett felmeddelande istället för en tyst bruten utdata, vilket är precis vad du vill ha innan sändningskoden.

Sekretess och begränsningar

Denna formatterare körs helt i din webbläsare. Din JSON laddas aldrig upp, loggas eller delas, vilket är viktigt eftersom JSON ofta innehåller API-nycklar, personlig data eller intern konfiguration. Klistra aldrig in hemligheter i någon onlineformaterare som du inte litar på, och rotera någon nyckel som du av misstag avslöjar. Verktyget hanterar typiska API-svar och konfigurationsfiler enkelt, men extremt stora dokument, tiotals megabyte, kan vara långsamma i en webbläsarflik eftersom att analysera och omstränga dem tar minne. Det följer också strikta JSON-regler, så det kommer att avvisa JavaScript-liknande extrafunktioner som efterföljande kommatecken, enstaka citattecken och kommentarer, även om vissa verktyg accepterar dem löst.

Vanliga frågor (FAQs)

Vad är skillnaden mellan Format och Minify?
Format lägger till indrag och radbrytningar så att JSON är lätt att läsa för människor. Minify tar bort alla onödiga mellanslag och radbrytningar så att JSON är så liten som möjligt för att skicka eller lagra.
Varför misslyckas min JSON med ett avslutande kommafel?
Strict JSON tillåter inte ett kommatecken efter det sista objektet i ett objekt eller array. Ta bort det sista kommatecken och JSON kommer att analysera.
Kan jag använda enstaka citattecken i JSON?
Nej. JSON-strängar och nycklar måste använda dubbla citattecken. Enstaka citat fungerar i JavaScript-kod, men de är inte giltiga JSON och det här verktyget kommer korrekt att avvisa dem.
Är min JSON-data lagrad eller skickad någonstans?
Nej. Formatering och validering körs helt i din webbläsare, så din data lämnar aldrig din enhet.
Ändrar formateringen mina data?
Nej. Formatering och minifiering ändrar endast avstånd och radbrytningar. Värdena, nycklarna och strukturen förblir exakt desamma, så länge som JSON var giltig till att börja med.
