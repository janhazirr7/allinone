Vad JSON är och varför formatering spelar roll

JSON, förkortning för JavaScript Object Notation, är det vanligaste sättet datorer utbyter strukturerade data på webben. API:er, konfigurationsfiler och många appar talar alla JSON eftersom det är enkelt att läsa och lätt för maskiner att tolka. Ett giltigt JSON-dokument byggs av objekt i klammerparenteser, arrayer i hakparenteser, strängar i dubbla citattecken, tal och värdena true, false och null. Formatering ändrar inte vad data betyder, men det ändrar hur lätt det är för en människa att läsa. Minifierad JSON, med alla mellanslag borttagna, är mindre och snabbare att skicka över ett nätverk, vilket är anledningen till att API:er använder den, men den är nästan omöjlig att läsa eller felsöka. Förskönad JSON, med två mellanslags indrag och ett värde per rad, är större men låter dig upptäcka ett saknat komma eller en felaktig hakparentes på sekunder.

De vanligaste JSON-felen

  • Saknade eller extra komman: varje post i ett objekt eller en array utom den sista behöver ett komma, och ett avslutande komma efter den sista posten är inte tillåtet i strikt JSON.
  • Enkla citattecken i stället för dubbla citattecken: JSON-strängar måste använda dubbla citattecken, även om JavaScript-kod ofta tillåter enkla citattecken.
  • O-citerade nycklar: objektnycklar måste vara citerade strängar, så {name: "Ana"} är ogiltigt och måste vara {"name": "Ana"}.
  • Kommentarer: JSON tillåter inte kommentarer, så rader som börjar med // bryter parsningen även om de ser ofarliga ut.
  • Efterföljande text eller flera dokument: att klistra in två JSON-objekt efter varandra är ogiltigt; omslut dem i en array eller åtgärda dem ett i taget.

Formatering kontra minifiering: när du ska använda vad

Använd Formatera när du läser, felsöker eller lär dig från JSON, eftersom indrag avslöjar strukturen vid en blick och gör nästling uppenbar. Använd Minifiera när du behöver klistra in JSON i en URL, ett kompakt konfigurationsfält, en testförfrågan eller ett meddelande där storlek spelar roll och läsbarhet inte gör det. Använd Validera endast när du bara behöver ett ja- eller nej-svar, till exempel innan du sparar en konfigurationsfil, eftersom det kontrollerar JSON utan att ersätta din ursprungliga text. I alla tre fallen tolkar verktyget först JSON, så ett minifierat eller formaterat resultat är garanterat giltigt; om tolkningen misslyckas får du ett fel i stället för en tyst trasig utdata, vilket är precis vad du vill ha innan du levererar kod.

Integritet och begränsningar

Den här formateraren körs helt i din webbläsare. Din JSON laddas aldrig upp, loggas eller delas, vilket spelar roll eftersom JSON ofta innehåller API-nycklar, personuppgifter eller intern konfiguration. Klistra aldrig in hemligheter i en onlineformaterare du inte litar på, och byt ut varje nyckel du råkar exponera. Verktyget hanterar typiska API-svar och konfigurationsfiler lätt, men extremt stora dokument, tiotals megabyte, kan vara långsamma i en webbläsarflik eftersom parsning och omsträngning tar minne. Det följer också strikta JSON-regler, så det avvisar JavaScript-liknande tillägg som avslutande komman, enkla citattecken och kommentarer, även om vissa verktyg accepterar dem löst.

Vanliga frågor och svar (FAQ)

Vad är skillnaden mellan Formatera och Minifiera?
Formatering lägger till indrag och radbrytningar så att JSON blir lätt för människor att läsa. Minifiering tar bort alla onödiga mellanslag och radbrytningar så att JSON blir så liten som möjligt för att skicka eller lagra.
Varför misslyckas min JSON med ett fel om avslutande komma?
Strikt JSON tillåter inte ett komma efter den sista posten i ett objekt eller en array. Ta bort det sista kommat så tolkas JSON.
Kan jag använda enkla citattecken i JSON?
Nej. JSON-strängar och nycklar måste använda dubbla citattecken. Enkla citattecken fungerar i JavaScript-kod, men de är inte giltig JSON och det här verktyget avvisar dem korrekt.
Lagras eller skickas mina JSON-data någonstans?
Nej. Formatering och validering körs helt i din webbläsare, så dina data lämnar aldrig din enhet.
Ändrar formatering mina data?
Nej. Formatering och minifiering ändrar bara avstånd och radbrytningar. Värdena, nycklarna och strukturen förblir exakt desamma, så länge JSON var giltig från början.
