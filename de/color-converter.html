Verwendung des Farbkonverters

Designer, Entwickler und Drucker beschreiben alle die gleiche Farbe in verschiedenen Sprachen. Ein Webentwickler schreibt # 2563EB, ein Druckdesigner denkt in Prozentsätzen von Cyan und Magenta, und ein CSS-Autor passt die Helligkeit für HSL an. Die manuelle Konvertierung zwischen diesen Formaten ist langsam und fehleranfällig, insbesondere bei der Mathematik hinter HSL. Dieser Konverter macht es sofort: Geben Sie eine Farbe in einem beliebigen Format ein und sehen Sie alle drei auf einmal, mit einem Live-Feld, damit Sie das Ergebnis mit Ihren Augen beurteilen können, nicht nur Zahlen.

  1. AbGeben Sie einen Hex-Code mit oder ohne Hash ein, z. B. #FF0000 oder 2563EB, und drücken Sie Konvertieren von HEX. Dreistellige Kurzschrift wie F00 funktioniert auch und wird auf FF0000 erweitert.
  2. Oder starten Sie von RGBGeben Sie die roten, grünen und blauen Kanäle von 0 bis 255 ein und drücken Sie von RGB konvertieren. Dies ist praktisch, wenn ein Design-Tool oder eine Screenshot-Auswahl Ihnen RGB-Werte liefert.
  3. Oder starten Sie bei HSLGeben Sie den Farbton von 0 bis 360 Grad sowie die Sättigung und Helligkeit in Prozent ein und drücken Sie auf Von HSL konvertieren. HSL ist das einfachste Format, um hellere oder dunklere Versionen einer Farbe zu erstellen.
  4. VoraussetzungenDie konvertierten Werte werden unten zusammen mit kopierfähigem CSS angezeigt. Die Vorschau des Farbfelds wird von jeder Eingabe aus aktualisiert, sodass Sie frei experimentieren und die Farbänderung beobachten können.

HEX, RGB und HSL erklärt

HEX ist die Abkürzung des Webs für RGB. Jedes Hexadezimalziffernpaar repräsentiert einen Kanal: Das erste Paar ist rot, das zweite grün, das dritte blau. FF0000 ist daher reinrot, 00FF00 reingrün und 000000 schwarz, während FFFFFF weiß ist. Hexadezimal verwendet die Ziffern 0 bis 9 plus die Buchstaben A bis F, wobei A 10 und F 15 bedeutet, weshalb zwei Hexadezimalzahlen jeden Wert von 0 bis 255 darstellen können. Die dreistellige Kurzschrift verdoppelt einfach jede Ziffer, so dass F00 zu FF0000 und 369 zu 336699 wird.

RGB beschreibt Farbe als Licht: wie viel rotes, grünes und blaues Licht zu mischen ist. Bildschirme emittieren Licht, so dass das Hinzufügen aller drei Kanäle in voller Stärke Weiß erzeugt und das Ausschalten alle Schwarz erzeugt. Dieses additive Modell ist intuitiv für Bildschirme, aber umständlich für Menschen, die versuchen, eine Farbe anzupassen, da das Ändern der Helligkeit bedeutet, alle drei Zahlen auf einmal zu ändern. HSL korrigiert das, indem es Farbe so beschreibt, wie die Leute darüber denken: Farbton ist die Position um den Farbkreis in Grad, wobei 0 rot, 120 grün und 240 blau ist; Sättigung ist, wie lebendig die Farbe ist, von Grau bei 0 % bis Vollfarbe bei 100 %; und Helligkeit geht von Schwarz bei 0 % über die reine Farbe bei 50 % bis zu Weiß bei 100 %.

HEX #RRGGBB = RGB (rot, grün, blau), je 0-255
HSL (Farbton 0-360, Sättigung 0-100%, Helligkeit 0-100%)
Beispiele: Reines Rot ist #FF0000 = rgb(255, 0, 0) = hsl(0, 100%, 50%). Reines Grün ist #00FF00 = rgb(0, 255, 0) = hsl(120, 100%, 50%). Grau hat bei jedem Farbton eine Sättigung von 0 %.

Praktische Anwendungen und Tipps zur Barrierefreiheit

Die häufigste Konvertierungsaufgabe besteht darin, eine Markenfarbe zwischen den Tools zu verschieben. Eine Logodatei kann Ihnen einen Hex-Code geben, das Stylesheet eines Entwicklers benötigt RGB für Transparenzeffekte wie rgba(37, 99, 235, 0,5), und ein Designer, der einen Hover-Zustand erstellt, benötigt HSL, um die gleiche Farbe aufzuhellen, indem er die Helligkeit um zehn Punkte erhöht. Wenn Sie diese Schritte hier durchführen, bleibt eine Wahrheitsquelle erhalten: Geben Sie die Markenfarbe einmal ein, und jedes Format bleibt konsistent, anstatt durch manuelle Wiederholungs- und Rundungsfehler zu driften.

1. Erstellen Sie eine Palette aus einer Farbe

Beginnen Sie mit Ihrer Hauptfarbe in HSL, halten Sie dann den Farbton fest und variieren Sie die Helligkeit: 30 % für dunklen Text, 50 % für die Hauptfarbe, 85 % für eine blasse Hintergrundtönung. Das Ergebnis sieht entworfen aus, nicht zufällig.

2. Überprüfen Sie den Kontrast vor dem Versand

Heller Text auf hellem Hintergrund ist der häufigste Fehler bei der Barrierefreiheit im Web. Verwenden Sie das Muster, um auf einen Blick zu beurteilen, und bevorzugen Sie dunklen Text auf blasse Farben und weißen Text auf gesättigte dunkle Farben.

3. Farben aus Screenshots korrigieren

Farbwähler melden oft RGB-Werte. Fügen Sie sie hier ein, um den Hex-Code für Ihr Stylesheet zu erhalten, oder die HSL-Werte, um den Farbton zu verfeinern, ohne Kanal für Kanal zu erraten.

Ein letzter Hinweis zur Präzision: Die Konvertierung zwischen RGB und HSL beinhaltet das Runden, da HSL-Prozentsätze hier ganze Zahlen sind, während RGB-Kanäle ganze Zahlen sind. Das Konvertieren einer Farbe in HSL und zurück kann einen Kanal um eine Einheit verschieben, was für das Auge unsichtbar und für jeden Konverter normal ist. Wenn Sie eine pixelgenaue Reproduktion für den Druck benötigen, behalten Sie die ursprünglichen Hex- oder RGB-Werte als Master-Kopie bei. Alles läuft hier privat in Ihrem Browser, sodass Ihre Markenfarben und -paletten nie hochgeladen oder gespeichert werden.

Häufig gestellte Fragen (FAQs)

Was ist ein Hex-Farbcode?
Ein HEXADEZIMALCODE ist eine sechsstellige hexadezimale Abkürzung für RGB-Werte, die mit einem führenden Hash geschrieben wird, wie #FF0000 für reines Rot. Jedes Ziffernpaar steht für Rot, Grün und Blau, von 00 (keine) bis FF (voll oder 255). Dreistellige Codes wie F00 sind Abkürzungen, die jede Ziffer auf FF0000 verdoppeln.
Wie konvertiere ich HEX in RGB?
Teilen Sie die sechs Hexadezimalziffern in drei Paare auf und wandeln Sie jedes Paar von hexadezimal in dezimal um. Für #2563EB wird 25 zu 37, 63 zu 99 und EB zu 235, was rgb(37, 99, 235) ergibt. Dieser Konverter macht diese Arithmetik für Sie in beide Richtungen.
Was bedeuten H, S und L bei HSL?
H ist der Farbton, die Position auf dem Farbkreis von 0 bis 360 Grad, wobei 0 rot, 120 grün und 240 blau ist. S ist die Sättigung, von 0% grau bis 100% voll lebendig. L ist die Helligkeit, von 0 % Schwarz über 50 % reine Farbe bis hin zu 100 % Weiß.
Warum ändert das Hin- und Herwechseln einen Wert um 1?
HSL-Prozentsätze werden hier auf ganze Zahlen gerundet, und RGB-Kanäle sind ganze Zahlen, so dass eine Hin- und Rückfahrt einen Kanal um eine Einheit verschieben kann. Der Unterschied ist für das Auge unsichtbar. Behalten Sie Ihren ursprünglichen HEX- oder RGB-Wert als Master-Kopie für pixelgenaue Arbeit.
Kann ich diesen Konverter für Druckfarben verwenden?
Für das Screendesign ja. Print verwendet CMYK, ein anderes Modell, das auf Tinte und nicht auf Licht basiert, sodass eine für den Druck umgewandelte Bildschirmfarbe auf Papier anders aussieht. Drucken Sie Farben immer mit den CMYK-Werten Ihres Druckers.
Werden meine Farbdaten gespeichert?
Nein. Alle Conversions werden in Ihrem Browser ausgeführt. Nichts, was Sie eingeben, wird an einen Server gesendet oder gespeichert.
