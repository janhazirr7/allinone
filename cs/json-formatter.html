Jak používat formátovač JSON

  1. Vložte svůj JSONZkopírujte JSON z API, konfiguračního souboru nebo návodu a vložte ho do velkého pole.
  2. Vyberte akciStiskněte Formátovat, aby byl čitelný s odsazením, Zmenšit, abyste ho zmenšili na jeden řádek, nebo Pouze ověřit, abyste ho zkontrolovali, aniž byste ho změnili.
  3. Přečtěte si chybu, pokud nějaká jePokud je JSON neplatný, nástroj ukáže přesnou chybu z analyzátoru prostými slovy, takže víte, co opravit.
  4. Zkopírujte výsledekPoužijte Kopírovat výstup, abyste vzali zformátovaný nebo zmenšený JSON zpět do svého kódu, konfigurace nebo API nástroje.

Co je JSON a proč na formátování záleží

JSON, zkratka pro JavaScript Object Notation, je nejběžnějším způsobem, jakým si počítače na webu vyměňují strukturovaná data. API, konfigurační soubory a mnoho aplikací mluví JSON, protože je jednoduchý na čtení a snadný pro stroje ke zpracování. Platný dokument JSON je postaven z objektů ve složených závorkách, polí v hranatých závorkách, řetězců ve dvojitých uvozovkách, čísel a hodnot true, false a null. Formátování nemění to, co data znamenají, ale mění to, jak snadné je pro člověka je číst. Zmenšený JSON, se všemi odstraněnými mezerami, je menší a rychlejší k odeslání po síti, proto ho API používají, ale je téměř nemožné ho číst nebo ladit. Zkrášlený JSON, s odsazením dvěma mezerami a jednou hodnotou na řádek, je větší, ale umožňuje během několika sekund odhalit chybějící čárku nebo špatnou závorku.

Nejčastější chyby JSON

  • Chybějící nebo přebytečné čárky: každá položka v objektu nebo poli kromě poslední potřebuje čárku a koncová čárka po poslední položce není ve striktním JSON povolena.
  • Jednoduché uvozovky místo dvojitých uvozovek: řetězce JSON musí používat dvojité uvozovky, i když kód JavaScript často povoluje jednoduché uvozovky.
  • Neuvozené klíče: klíče objektů musí být uvozené řetězce, takže {name: "Ana"} je neplatné a musí být {"name": "Ana"}.
  • Komentáře: JSON nepovoluje komentáře, takže řádky začínající // rozbijí zpracování, i když vypadají neškodně.
  • Koncový text nebo více dokumentů: vložení dvou objektů JSON za sebou je neplatné; zabalte je do pole nebo je opravte jeden po druhém.

Formátování versus zmenšení: kdy použít které

Použijte Formátovat, když JSON čtete, ladíte nebo se z něj učíte, protože odsazení na první pohled odhalí strukturu a vnoření učiní zřejmým. Použijte Zmenšit, když potřebujete vložit JSON do URL, kompaktního konfiguračního pole, testovacího požadavku nebo zprávy, kde záleží na velikosti a čitelnost ne. Použijte Pouze ověřit, když potřebujete pouze odpověď ano-ne, například před uložením konfiguračního souboru, protože zkontroluje JSON, aniž by nahradil váš původní text. Ve všech třech případech nástroj nejprve zpracuje JSON, takže zmenšený nebo zformátovaný výsledek je zaručeně platný; pokud zpracování selže, dostanete chybu místo tiše rozbitého výstupu, což je přesně to, co chcete před odesláním kódu.

Soukromí a limity

Tento formátovač běží výhradně ve vašem prohlížeči. Váš JSON se nikdy nenahrává, nezaznamenává ani nesdílí, což je důležité, protože JSON často obsahuje API klíče, osobní data nebo interní konfiguraci. Nikdy nevkládejte tajné údaje do žádného online formátovače, kterému nedůvěřujete, a obměňte jakýkoli klíč, který omylem odhalíte. Nástroj snadno zvládá typické odpovědi API a konfigurační soubory, ale extrémně velké dokumenty, desítky megabajtů, mohou být v kartě prohlížeče pomalé, protože jejich zpracování a opětovné převedení na řetězec zabírá paměť. Také se řídí striktními pravidly JSON, takže odmítne extras ve stylu JavaScriptu, jako jsou koncové čárky, jednoduché uvozovky a komentáře, i když je některé nástroje přijímají volně.

Často kladené otázky (FAQ)

Jaký je rozdíl mezi Formátovat a Zmenšit?
Formátování přidává odsazení a zalomení řádků, takže JSON je pro lidi snadno čitelný. Zmenšení odstraňuje všechny zbytečné mezery a zalomení řádků, takže JSON je co nejmenší pro odeslání nebo uložení.
Proč můj JSON selhává s chybou koncové čárky?
Striktní JSON nepovoluje čárku po poslední položce v objektu nebo poli. Odstraňte tuto poslední čárku a JSON se zpracuje.
Mohu v JSON použít jednoduché uvozovky?
Ne. Řetězce a klíče JSON musí používat dvojité uvozovky. Jednoduché uvozovky fungují v kódu JavaScript, ale nejsou platným JSON a tento nástroj je správně odmítne.
Ukládají se moje data JSON nebo se někam odesílají?
Ne. Formátování a ověřování běží výhradně ve vašem prohlížeči, takže vaše data nikdy neopustí vaše zařízení.
Mění formátování moje data?
Ne. Formátování a zmenšení mění pouze mezery a zalomení řádků. Hodnoty, klíče a struktura zůstávají přesně stejné, pokud byl JSON od začátku platný.
