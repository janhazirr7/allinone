Jak používat formátovač JSON

  1. Vložte svůj JSONZkopírujte JSON z API, konfiguračního souboru nebo výukového programu a vložte jej do velkého pole.
  2. Vyberte akciStiskněte Formát, aby bylo čitelné s odsazením, Zmenšit, chcete-li jej zmenšit na jeden řádek, nebo Pouze ověřit, chcete-li jej zkontrolovat, aniž byste jej změnili.
  3. Přečtěte si chybu, pokud existujePokud je JSON neplatný, nástroj zobrazí přesnou chybu z analyzátoru jednoduchými slovy, takže víte, co opravit.
  4. Zkopírujte výsledekPomocí tlačítka Kopírovat výstup přeneste naformátovaný nebo miniifikovaný JSON zpět do svého kódu, konfigurace nebo nástroje API.

Co je JSON a proč na formátování záleží

JSON, zkratka pro JavaScript Object Notation, je nejběžnějším způsobem, jakým si počítače vyměňují strukturovaná data na webu. Rozhraní API, konfigurační soubory a mnoho aplikací mluví JSON, protože je snadno čitelný a pro počítače snadno analyzovatelný. Platný dokument JSON se skládá z objektů ve složených závorkách, polí v hranatých závorkách, řetězců v uvozovkách, čísel a hodnot true, false a null. Formátování nemění to, co data znamenají, ale mění to, jak snadno jsou pro člověka čitelná. Minifikovaný JSON s odstraněnými všemi mezerami je menší a rychlejší pro odesílání přes síť, proto jej používají API, ale je téměř nemožné jej číst nebo ladit. Zkrášlený JSON s odsazením dvěma mezerami a jednou hodnotou na řádek je větší, ale během několika sekund vám umožní najít chybějící čárku nebo špatnou závorku.

Nejčastější chyby JSON

  • Chybějící čárky nebo čárky navíc: každá položka v objektu nebo poli kromě posledního potřebuje čárku a koncová čárka za poslední položkou není ve striktním JSON povolena.
  • Jednoduché uvozovky místo dvojitých uvozovek: Řetězce JSON musí používat dvojité uvozovky, i když kód JavaScript často jednoduché uvozovky umožňuje.
  • Klíče bez uvozovek: Klíče objektů musí být řetězce v uvozovkách, takže {jméno: "Ana"} je neplatné a musí být {"jméno": "Ana"}.
  • Komentáře: JSON neumožňuje komentáře, takže řádky začínající na // přeruší analýzu, i když vypadají neškodně.
  • Text na konci nebo více dokumentů: vkládání dvou objektů JSON jeden po druhém je neplatné; zabalte je do pole nebo je opravte jeden po druhém.

Formátování versus minifikace: Kdy je použít

Formát použijte při čtení, ladění nebo učení se z JSON, protože odsazení odhalí strukturu na první pohled a zviditelní vnoření. Minifikaci použijte, když potřebujete vložit JSON do adresy URL, kompaktního konfiguračního pole, testovacího požadavku nebo zprávy, kde na velikosti záleží a na čitelnosti ne. Použijte Pouze ověřit, když potřebujete pouze odpověď ano-nebo-ne, například před uložením konfiguračního souboru, protože zkontroluje JSON, aniž by nahradil váš původní text. Ve všech třech případech nástroj nejprve analyzuje JSON, takže je zaručeno, že minifikovaný nebo formátovaný výsledek bude platný; pokud se analýza nezdaří, místo tiše přerušeného výstupu se zobrazí chyba, což je přesně to, co chcete před odesláním kódu.

Soukromí a omezení

Tento formátovač běží výhradně ve vašem prohlížeči. Váš JSON se nikdy nenahrává, nezaprotokoluje ani nesdílí, což je důležité, protože JSON často obsahuje klíče API, osobní údaje nebo interní konfiguraci. Nikdy nevkládejte tajemství do žádného online formátovače, kterému nedůvěřujete, a otáčejte libovolným klíčem, který omylem odhalíte. Nástroj si snadno poradí s typickými odpověďmi rozhraní API a konfiguračními soubory, ale extrémně velké dokumenty, desítky megabajtů, mohou být na kartě prohlížeče pomalé, protože jejich analýza a opětovné vytvoření řetězce zabírá paměť. Dodržuje také přísná pravidla JSON, takže odmítne doplňky ve stylu JavaScriptu, jako jsou koncové čárky, jednoduché uvozovky a komentáře, i když je některé nástroje přijímají volně.

Často kladené otázky (FAQ)

Jaký je rozdíl mezi formátem a minifikací?
Formát přidává odsazení a zalomení řádků, takže JSON je pro lidi snadno čitelný. Minifikace odstraňuje všechny zbytečné mezery a konce řádků, takže JSON je pro odesílání nebo ukládání co nejmenší.
Proč můj JSON selže s chybou čárky na konci?
Striktní JSON nepovoluje čárku za poslední položkou v objektu nebo poli. Odstraňte poslední čárku a JSON bude analyzovat.
Mohu v JSON používat jednoduché uvozovky?
Ne. Řetězce a klíče JSON musí používat dvojité uvozovky. Jednoduché uvozovky fungují v kódu JavaScript, ale nejsou platným JSON a tento nástroj je správně odmítne.
Jsou moje data JSON někde uložena nebo odeslána?
Ne. Formátování a ověřování probíhá výhradně ve vašem prohlížeči, takže vaše data nikdy neopustí vaše zařízení.
Změní formátování moje data?
Ne. Formátování a minifikace mění pouze mezery a zalomení řádků. Hodnoty, klíče a struktura zůstávají přesně stejné, dokud byl JSON platný.
