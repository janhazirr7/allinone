O que é JSON e por que a formatação é importante

JSON, abreviação de JavaScript Object Notation, é a maneira mais comum de os computadores trocarem dados estruturados na web. APIs, arquivos de configuração e muitos aplicativos falam JSON porque é simples de ler e fácil para as máquinas analisarem. Um documento JSON válido é construído a partir de objetos entre chaves, matrizes entre colchetes, strings entre aspas duplas, números e os valores true, false e null. A formatação não muda o que os dados significam, mas muda a facilidade de leitura para um ser humano. O JSON reduzido, com todos os espaços removidos, é menor e mais rápido para enviar por uma rede, e é por isso que as APIs o usam, mas é quase impossível ler ou depurar. O JSON embelezado, com indentação de dois espaços e um valor por linha, é maior, mas permite detectar uma vírgula ausente ou um colchete errado em segundos.

Os erros JSON mais comuns

  • Vírgulas ausentes ou extras: todos os itens de um objeto ou matriz, exceto o último, precisam de uma vírgula, e uma vírgula final após o último item não é permitida em JSON estrito.
  • Aspas simples em vez de aspas duplas: as strings JSON devem usar aspas duplas, embora o código JavaScript geralmente permita aspas simples.
  • Chaves não cotadas: as chaves do objeto devem ser cadeias de caracteres entre aspas, portanto, {name: "Ana"} é inválido e deve ser {"name": "Ana"}.
  • Comentários: O JSON não permite comentários, portanto, as linhas que começam com // interromperão a análise, mesmo que pareçam inofensivas.
  • Texto à direita ou vários documentos: colar dois objetos JSON um após o outro é inválido; envolva-os numa matriz ou corrija-os um de cada vez.

Formatação versus redução: quando usar cada um

Use Formatar quando estiver lendo, depurando ou aprendendo com JSON, porque a indentação revela a estrutura rapidamente e torna o aninhamento óbvio. Use Minify quando precisar colar JSON em um URL, um campo de configuração compacto, uma solicitação de teste ou uma mensagem onde o tamanho é importante e a legibilidade não. Use Validar somente quando precisar apenas de uma resposta sim ou não, por exemplo, antes de salvar um arquivo de configuração, porque ele verifica o JSON sem substituir o texto original. Em todos os três casos, a ferramenta analisa primeiro o JSON, portanto, um resultado reduzido ou formatado é garantido como válido; se a análise falhar, você recebe um erro em vez de uma saída quebrada silenciosamente, que é exatamente o que você deseja antes de enviar o código.

Privacidade e Limites

Este formatador é executado inteiramente no seu navegador. Seu JSON nunca é carregado, registrado ou compartilhado, o que é importante porque o JSON geralmente contém chaves de API, dados pessoais ou configuração interna. Nunca cole segredos em qualquer formatador online em que não confie e gire qualquer chave que acidentalmente exponha. A ferramenta lida com respostas típicas de API e arquivos de configuração facilmente, mas documentos extremamente grandes, dezenas de megabytes, podem ficar lentos em uma guia do navegador porque analisá-los e re-stringi-los consome memória. Ele também segue regras rígidas de JSON, por isso rejeitará extras no estilo JavaScript, como vírgulas, aspas simples e comentários, mesmo que algumas ferramentas os aceitem livremente.

Perguntas frequentes (FAQ)

Qual é a diferença entre Formatar e Minificar?
O formato adiciona indentação e quebras de linha para que o JSON seja fácil para os humanos lerem. O Minify remove todos os espaços desnecessários e quebras de linha para que o JSON seja o menor possível para envio ou armazenamento.
Por que o meu JSON falha com um erro de vírgula final?
O JSON estrito não permite uma vírgula após o último item de um objeto ou matriz. Remova essa vírgula final e o JSON analisará.
Posso usar aspas simples em JSON?
Não. As strings e chaves JSON devem usar aspas duplas. As aspas simples funcionam no código JavaScript, mas não são JSON válidas e esta ferramenta irá rejeitá-las corretamente.
Meus dados JSON são armazenados ou enviados para algum lugar?
Não. A formatação e a validação são executadas inteiramente no seu navegador, para que os seus dados nunca saiam do seu dispositivo.
A formatação altera meus dados?
Não. A formatação e a redução apenas alteram o espaçamento e as quebras de linha. Os valores, chaves e estrutura permanecem exatamente os mesmos, desde que o JSON fosse válido para começar.
