O que é JSON e porque é que a formatação importa

JSON, abreviatura de JavaScript Object Notation, é a forma mais comum de os computadores trocarem dados estruturados na web. APIs, ficheiros de configuração e muitas apps falam JSON porque é simples de ler e fácil de analisar para máquinas. Um documento JSON válido é construído a partir de objetos entre chavetas, matrizes entre parênteses retos, cadeias entre aspas duplas, números e os valores true, false e null. A formatação não altera o que os dados significam, mas altera quão fácil é para um humano ler. O JSON minificado, com todos os espaços removidos, é menor e mais rápido de enviar pela rede, razão pela qual as APIs o usam, mas é quase impossível de ler ou depurar. O JSON embelezado, com indentação de dois espaços e um valor por linha, é maior mas permite-lhe detetar uma vírgula em falta ou um parêntese errado em segundos.

Os erros JSON mais comuns

  • Vírgulas em falta ou a mais: cada item num objeto ou matriz, exceto o último, precisa de uma vírgula, e uma vírgula final após o último item não é permitida em JSON estrito.
  • Aspas simples em vez de aspas duplas: as cadeias JSON têm de usar aspas duplas, mesmo que o código JavaScript permita muitas vezes aspas simples.
  • Chaves sem aspas: as chaves de objetos têm de ser cadeias entre aspas, por isso {name: "Ana"} é inválido e tem de ser {"name": "Ana"}.
  • Comentários: o JSON não permite comentários, por isso linhas que começam com // vão quebrar a análise mesmo que pareçam inofensivas.
  • Texto final ou vários documentos: colar dois objetos JSON um após o outro é inválido; envolva-os numa matriz ou corrija-os um de cada vez.

Formatar versus minificar: quando usar cada um

Use Formatar quando estiver a ler, depurar ou aprender com JSON, porque a indentação revela a estrutura de relance e torna o aninhamento óbvio. Use Minificar quando precisar de colar JSON num URL, num campo de configuração compacto, num pedido de teste ou numa mensagem onde o tamanho importa e a legibilidade não. Use Apenas validar quando só precisar de uma resposta sim-ou-não, por exemplo antes de guardar um ficheiro de configuração, porque verifica o JSON sem substituir o seu texto original. Nos três casos a ferramenta primeiro analisa o JSON, por isso um resultado minificado ou formatado é garantidamente válido; se a análise falhar, recebe um erro em vez de uma saída silenciosamente danificada, o que é exatamente o que quer antes de enviar código.

Privacidade e limites

Este formatador funciona inteiramente no seu navegador. O seu JSON nunca é carregado, registado ou partilhado, o que importa porque o JSON contém muitas vezes chaves de API, dados pessoais ou configuração interna. Nunca cole segredos em nenhum formatador online em que não confie, e substitua qualquer chave que exponha acidentalmente. A ferramenta trata facilmente respostas típicas de API e ficheiros de configuração, mas documentos extremamente grandes, de dezenas de megabytes, podem ser lentos num separador do navegador porque analisá-los e voltar a convertê-los em texto consome memória. Também segue regras estritas de JSON, por isso rejeitará extras ao estilo JavaScript como vírgulas finais, aspas simples e comentários, mesmo que algumas ferramentas os aceitem de forma permissiva.

Perguntas frequentes (FAQ)

Qual é a diferença entre Formatar e Minificar?
Formatar soma indentação e quebras de linha para que o JSON seja fácil de ler para humanos. Minificar remove todos os espaços e quebras de linha desnecessários para que o JSON seja o mais pequeno possível para enviar ou guardar.
Porque é que o meu JSON falha com um erro de vírgula final?
O JSON estrito não permite uma vírgula após o último item num objeto ou matriz. Remova essa vírgula final e o JSON será analisado.
Posso usar aspas simples em JSON?
Não. As cadeias e chaves JSON têm de usar aspas duplas. As aspas simples funcionam em código JavaScript, mas não são JSON válido e esta ferramenta rejeitá-las-á corretamente.
Os meus dados JSON ficam guardados ou são enviados para algum lugar?
Não. A formatação e validação funcionam inteiramente no seu navegador, por isso os seus dados nunca saem do seu dispositivo.
A formatação altera os meus dados?
Não. Formatar e minificar só alteram espaçamento e quebras de linha. Os valores, chaves e estrutura ficam exatamente iguais, desde que o JSON fosse válido desde o início.
