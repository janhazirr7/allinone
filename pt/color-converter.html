Como usar o conversor de cores

Designers, desenvolvedores e impressoras descrevem a mesma cor em diferentes idiomas. Um desenvolvedor web escreve #2563EB, um designer de impressão pensa em porcentagens de ciano e magenta e um autor de CSS ajusta o brilho para HSL. Converter entre esses formatos manualmente é lento e propenso a erros, especialmente com a matemática por trás do HSL. Este conversor faz isso instantaneamente: insira uma cor em qualquer formato e veja todas as três ao mesmo tempo, com uma amostra ao vivo para que você possa julgar o resultado com os olhos, não apenas com números.

  1. Comece em HEXDigite um código hexadecimal com ou sem o hash, por exemplo #FF0000 ou 2563EB, e pressione Converter de HEXADECIMAL. Uma abreviação de três dígitos como F00 também funciona e se expande para FF0000.
  2. Ou comece em RGBDigite os canais vermelho, verde e azul, cada um de 0 a 255, e pressione Converter de RGB. Isso é útil quando uma ferramenta de design ou um selecionador de captura de tela fornece valores RGB.
  3. Ou comece em HSLDigite matiz de 0 a 360 graus, mais saturação e luminosidade como porcentagens, e pressione Converter de HSL. HSL é o formato mais fácil para criar versões mais claras ou mais escuras de uma cor.
  4. Copie o que você precisaOs valores convertidos aparecem abaixo, juntamente com o CSS pronto para cópia. A amostra de pré-visualização é atualizada a partir de qualquer entrada, para que possa experimentar livremente e ver a mudança de cor.

HEX, RGB e HSL explicados

HEX é a abreviação da web para RGB. Cada par de dígitos hexadecimais representa um canal: o primeiro par é vermelho, o segundo verde, o terceiro azul. FF0000 é, portanto, vermelho puro, 00FF00 verde puro e 000000 preto, enquanto FFFFFF é branco. O hexadecimal usa dígitos de 0 a 9 mais letras de A a F, onde A significa 10 e F significa 15, e é por isso que dois dígitos hexadecimais podem representar todos os valores de 0 a 255. A abreviação de três dígitos simplesmente dobra cada dígito, então F00 se torna FF0000 e 369 se torna 336699.

O RGB descreve a cor como luz: quanta luz vermelha, verde e azul deve ser misturada. As telas emitem luz, portanto, adicionar todos os três canais com força total produz branco, e desligá-los todos produz preto. Esse modelo aditivo é intuitivo para telas, mas estranho para humanos que tentam ajustar uma cor, porque mudar o brilho significa mudar todos os três números de uma só vez. O HSL corrige isso descrevendo a cor da maneira como as pessoas pensam sobre ela: matiz é a posição em torno da roda de cores em graus, onde 0 é vermelho, 120 é verde e 240 é azul; saturação é o quão vívida é a cor, do cinza em 0% até a cor completa em 100%; e a luminosidade vai do preto em 0% até a cor pura em 50% até o branco em 100%.

HEX #RRGGBB = RGB (vermelho, verde, azul), cada 0-255
HSL (matiz 0-360, saturação 0-100%, leveza 0-100%)
Exemplos: vermelho puro é #FF0000 = rgb(255, 0, 0) = hsl(0, 100%, 50%). O verde puro é #00FF00 = rgb(0, 255, 0) = hsl(120, 100%, 50%). O cinza tem 0% de saturação em qualquer matiz.

Usos práticos e dicas de acessibilidade

A tarefa de conversão mais comum é mover uma cor de marca entre ferramentas. Um arquivo de logotipo pode fornecer um código hexadecimal, a folha de estilo de um desenvolvedor precisa de RGB para efeitos de transparência, como rgba(37, 99, 235, 0,5), e um designer que cria um estado de foco precisa de HSL para clarear a mesma cor, aumentando a luminosidade em dez pontos. Fazer essas etapas aqui mantém uma fonte de verdade: digite a cor da marca uma vez, e cada formato permanece consistente em vez de passar por erros manuais de redigitação e arredondamento.

1. Construa uma paleta de uma cor

Comece pela sua cor principal em HSL, depois mantenha a tonalidade fixa e varie a luminosidade: 30% para texto escuro, 50% para a cor principal, 85% para uma tonalidade de fundo pálido. O resultado parece projetado, não aleatório.

2. Verifique o contraste antes de enviar

Texto claro sobre um fundo claro é a falha de acessibilidade mais comum na web. Use a amostra para julgar rapidamente e prefira texto escuro em cores pálidas e texto branco em cores escuras saturadas.

3. Corrija as cores das capturas de tela

Os seletores de cores geralmente relatam valores RGB. Cole-os aqui para obter o código hexadecimal da sua folha de estilo ou os valores HSL para ajustar a tonalidade sem adivinhar canal por canal.

Uma nota final sobre precisão: a conversão entre RGB e HSL envolve arredondamento, porque as porcentagens de HSL são números inteiros aqui, enquanto os canais RGB são números inteiros. A conversão de uma cor para HSL e vice-versa pode deslocar um canal por uma unidade, que é invisível aos olhos e normal para cada conversor. Se você precisar de reprodução perfeita de pixels para impressão, mantenha os valores hexadecimais ou RGB originais como sua cópia mestre. Tudo aqui é executado de forma privada no seu navegador, para que as cores e paletas da sua marca nunca sejam carregadas ou armazenadas.

Perguntas frequentes (FAQ)

O que é um código de cores HEX?
Um código HEXADECIMAL é uma abreviação hexadecimal de seis dígitos para valores RGB, escrito com um hash inicial, como #FF0000 para vermelho puro. Cada par de dígitos significa vermelho, verde e azul, de 00 (nenhum) a FF (completo ou 255). Códigos de três dígitos como F00 são abreviações que dobram cada dígito para FF0000.
Como faço para converter HEX em RGB?
Divida os seis dígitos hexadecimais em três pares e converta cada par de hexadecimal para decimal. Para #2563EB, 25 torna-se 37, 63 torna-se 99 e EB torna-se 235, dando rgb(37, 99, 235). Este conversor faz essa aritmética para você em qualquer direção.
O que H, S e L significam em HSL?
H é matiz, a posição na roda de cores de 0 a 360 graus, onde 0 é vermelho, 120 é verde e 240 é azul. S é a saturação, de 0% cinza a 100% totalmente vívida. L é a luminosidade, de 0% de preto a 50% de cor pura a 100% de branco.
Por que a conversão para frente e para trás altera um valor em 1?
As porcentagens de HSL são arredondadas para números inteiros aqui, e os canais RGB são números inteiros, portanto, uma viagem de ida e volta pode deslocar um canal em uma unidade. A diferença é invisível aos olhos. Mantenha seu valor HEXADECIMAL ou RGB original como a cópia mestra para um trabalho perfeito em pixels.
Posso usar este conversor para imprimir cores?
Para o design da tela, sim. A impressão usa CMYK, um modelo diferente baseado em tinta em vez de luz, portanto, uma cor de tela convertida para impressão parecerá diferente no papel. Sempre comprove as cores de impressão com os valores CMYK da sua impressora.
Meus dados de cores são armazenados?
Não. Todas as conversões são executadas no seu navegador. Nada do que introduzir é enviado para um servidor ou armazenado.
