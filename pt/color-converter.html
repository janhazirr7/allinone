Como usar o conversor de cores

Designers, programadores e impressores descrevem todos a mesma cor em linguagens diferentes. Um programador web escreve #2563EB, um designer de impressão pensa em percentagens de ciano e magenta, e um autor de CSS a ajustar o brilho recorre ao HSL. Converter entre estes formatos à mão é lento e propenso a erros, especialmente com a matemática por trás do HSL. Este conversor faz isso instantaneamente: introduza uma cor em qualquer um dos formatos e veja os três de uma só vez, com uma amostra em direto para poder avaliar o resultado com os seus olhos, e não apenas com números.

  1. Comece a partir de HEXEscreva um código hex com ou sem o cardinal, por exemplo #FF0000 ou 2563EB, e prima Converter a partir de HEX. A abreviatura de três dígitos como F00 também funciona e expande-se para FF0000.
  2. Ou comece a partir de RGBIntroduza os canais vermelho, verde e azul, cada um de 0 a 255, e prima Converter a partir de RGB. Isto é útil quando uma ferramenta de design ou um seletor de capturas de ecrã lhe dá valores RGB.
  3. Ou comece a partir de HSLIntroduza a matiz de 0 a 360 graus, mais saturação e luminosidade em percentagens, e prima Converter a partir de HSL. O HSL é o formato mais fácil para criar versões mais claras ou mais escuras de uma cor.
  4. Copie o que precisaOs valores convertidos aparecem abaixo, juntamente com CSS pronto a copiar. A amostra de pré-visualização atualiza a partir de qualquer entrada, por isso pode experimentar livremente e ver a cor mudar.

HEX, RGB e HSL explicados

O HEX é a abreviatura da web para RGB. Cada par de dígitos hexadecimais representa um canal: o primeiro par é o vermelho, o segundo o verde, o terceiro o azul. FF0000 é, portanto, vermelho puro, 00FF00 verde puro e 000000 preto, enquanto FFFFFF é branco. O hexadecimal usa os dígitos de 0 a 9 mais as letras de A a F, onde A significa 10 e F significa 15, razão pela qual dois dígitos hex podem representar todos os valores de 0 a 255. A abreviatura de três dígitos simplesmente duplica cada dígito, por isso F00 torna-se FF0000 e 369 torna-se 336699.

O RGB descreve a cor como luz: quanta luz vermelha, verde e azul misturar. Os ecrãs emitem luz, por isso somar os três canais na força máxima produz branco, e desligá-los todos produz preto. Esse modelo aditivo é intuitivo para ecrãs mas estranho para humanos a tentar ajustar uma cor, porque mudar o brilho significa mudar os três números de uma só vez. O HSL resolve isso descrevendo a cor da forma como as pessoas pensam nela: a matiz é a posição à volta da roda de cores em graus, onde 0 é vermelho, 120 é verde e 240 é azul; a saturação é quão vívida a cor é, de cinzento a 0% a cor total a 100%; e a luminosidade vai de preto a 0% através da cor pura a 50% até branco a 100%.

HEX #RRGGBB = RGB (vermelho, verde, azul), cada um 0-255
HSL (matiz 0-360, saturação 0-100%, luminosidade 0-100%)
Exemplos: o vermelho puro é #FF0000 = rgb(255, 0, 0) = hsl(0, 100%, 50%). O verde puro é #00FF00 = rgb(0, 255, 0) = hsl(120, 100%, 50%). O cinzento tem 0% de saturação em qualquer matiz.

Usos práticos e dicas de acessibilidade

A tarefa de conversão mais comum é mover uma cor de marca entre ferramentas. Um ficheiro de logótipo pode dar-lhe um código hex, a folha de estilos de um programador precisa de RGB para efeitos de transparência como rgba(37, 99, 235, 0,5), e um designer a criar um estado de hover precisa de HSL para clarear a mesma cor subindo a luminosidade dez pontos. Fazer esses passos aqui mantém uma única fonte de verdade: escreva a cor da marca uma vez, e todos os formatos ficam consistentes em vez de se desviarem por redigitação manual e erros de arredondamento.

1. Crie uma paleta a partir de uma cor

Comece a partir da sua cor principal em HSL, depois mantenha a matiz fixa e varie a luminosidade: 30% para texto escuro, 50% para a cor principal, 85% para um tom de fundo pálido. O resultado parece desenhado, e não aleatório.

2. Verifique o contraste antes de publicar

Texto claro sobre fundo claro é a falha de acessibilidade mais comum na web. Use a amostra para avaliar de relance, e prefira texto escuro sobre cores pálidas e texto branco sobre cores escuras saturadas.

3. Corrija cores a partir de capturas de ecrã

Os seletores de cores muitas vezes reportam valores RGB. Cole-os aqui para obter o código hex para a sua folha de estilos, ou os valores HSL para afinar o tom sem adivinhar canal a canal.

Uma nota final sobre precisão: converter entre RGB e HSL envolve arredondamento, porque as percentagens HSL são números inteiros aqui enquanto os canais RGB são inteiros. Converter uma cor para HSL e de volta pode deslocar um canal numa unidade, o que é invisível a olho nu e normal em qualquer conversor. Se precisar de reprodução perfeita para impressão, guarde os valores hex ou RGB originais como cópia principal. Tudo aqui funciona em privado no seu navegador, por isso as suas cores de marca e paletas nunca são carregadas nem guardadas.

Perguntas frequentes (FAQ)

O que é um código de cor HEX?
Um código HEX é uma abreviatura hexadecimal de seis dígitos para valores RGB, escrita com um cardinal inicial, como #FF0000 para vermelho puro. Cada par de dígitos representa vermelho, verde e azul, de 00 (nenhum) a FF (total, ou 255). Códigos de três dígitos como F00 são uma abreviatura que duplica cada dígito para FF0000.
Como converto HEX para RGB?
Divida os seis dígitos hex em três pares e converta cada par de hexadecimal para decimal. Para #2563EB, 25 torna-se 37, 63 torna-se 99 e EB torna-se 235, dando rgb(37, 99, 235). Este conversor faz essa aritmética por si em qualquer direção.
O que significam H, S e L em HSL?
H é a matiz, a posição na roda de cores de 0 a 360 graus, onde 0 é vermelho, 120 é verde e 240 é azul. S é a saturação, de 0% cinzento a 100% totalmente vívido. L é a luminosidade, de 0% preto através de 50% cor pura até 100% branco.
Porque é que converter para trás e para a frente altera um valor em 1?
As percentagens HSL são arredondadas para números inteiros aqui, e os canais RGB são inteiros, por isso uma ida e volta pode deslocar um canal numa unidade. A diferença é invisível a olho nu. Guarde o seu valor HEX ou RGB original como cópia principal para trabalho perfeito ao pixel.
Posso usar este conversor para cores de impressão?
Para design de ecrã, sim. A impressão usa CMYK, um modelo diferente baseado em tinta em vez de luz, por isso uma cor de ecrã convertida para impressão terá um aspeto diferente no papel. Prove sempre as cores de impressão com os valores CMYK da sua impressora.
Os meus dados de cor ficam guardados?
Não. Todas as conversões funcionam no seu navegador. Nada do que introduz é enviado para um servidor nem guardado.
