Como usar o gerador Lorem Ipsum

Lorem Ipsum é o espaço reservado que designers e escritores de texto usam há séculos para preencher uma página antes que as palavras finais estejam prontas. Ele permite que você julgue um layout, uma fonte ou uma estrutura de página sem que o conteúdo real distraia os olhos. Com este gerador gratuito, pode criar exatamente a quantidade de texto de preenchimento de que precisa em segundos e, em seguida, copiá-lo diretamente para o seu documento, modelo de site ou ficheiro de design.

  1. Escolha quanto texto você precisaInsira um número, por exemplo, 3 parágrafos, 10 frases ou 100 palavras. Os parágrafos são melhores para modelos de página inteira, frases para blocos curtos e palavras para espaços precisos, como botões, cartões ou títulos.
  2. Escolha o tipo de saídaSelecione parágrafos, frases ou palavras no menu suspenso. Cada parágrafo contém quatro frases variadas, de modo que as gerações repetidas não se parecem com uma frase copiada repetidamente.
  3. Clique em Gerar TextoSeu texto aparece instantaneamente na caixa abaixo, juntamente com uma contagem de palavras ao vivo e contagem de caracteres para que você possa verificar se ele se encaixa no seu espaço.
  4. Copie e cole em qualquer lugarPressione Copiar texto e cole o resultado no Word, Figma, Canva, WordPress ou em qualquer editor. O texto é simples, por isso assume a formatação de onde quer que você o cole.

O que é Lorem Ipsum e de onde veio?

Lorem Ipsum não é um jargão aleatório. Vem de uma verdadeira obra latina, "De Finibus Bonorum et Malorum" (Sobre os Fins do Bem e do Mal), escrita pelo estadista e filósofo romano Cícero em 45 a.C. A famosa abertura, "Lorem ipsum dolor sit amet, consectetur adipiscing elit", é uma versão embaralhada de uma passagem desse livro, na qual Cícero discute a natureza do prazer e da dor. Ao longo dos séculos, os tipógrafos mantiveram o texto porque sua mistura de comprimentos de palavras se parece com o inglês natural ou a prosa latina, embora os leitores não possam realmente lê-lo como frases significativas.

O texto tornou-se um padrão da indústria de impressão nos anos 1500, quando uma impressora desconhecida misturou as palavras de Cícero em um livro de espécimes de fontes. Ele sobreviveu à era digital com o software de editoração eletrônica na década de 1980 e hoje está embutido em ferramentas de design em todos os lugares. A razão pela qual persiste é simples: quando um cliente ou revisor olha para um modelo, o texto legível chama sua atenção para as próprias palavras. Eles começam a revisar em vez de julgar o espaçamento, a hierarquia e o equilíbrio visual. O texto do espaço reservado remove essa distração, para que o próprio design receba o feedback.

É também por isso que o bom Lorem Ipsum é variado. Uma única frase repetida vinte vezes parece obviamente falsa e quebra a ilusão de uma página terminada. Um banco adequado de frases, com diferentes comprimentos e ritmos, imita a textura da escrita real: frases curtas e vigorosas misturadas com frases mais longas e fluidas. Este gerador usa quatorze frases clássicas extraídas da passagem tradicional de Lorem Ipsum, giradas para que cada parágrafo tenha uma combinação diferente.

Quando você deve usar texto de espaço reservado?

O texto de espaço reservado é útil muito além do design gráfico. Os desenvolvedores da Web o usam para testar como uma página se comporta quando o conteúdo é longo ou curto, e se o texto envolve ou transborda em pequenas telas de telefone. Os escritores de conteúdo o usam para reservar espaço em um esboço de artigo enquanto a pesquisa ainda está em andamento. Os professores usam-no para criar exercícios de formatação sem dar respostas, e os programadores de aplicações usam-no para testar campos de base de dados, resultados de pesquisa e perfis de utilizador antes de existirem dados de utilizador reais.

Os mecanismos de pesquisa também penalizam as páginas que publicam o texto de preenchimento como se fosse conteúdo, portanto, trate a geração como uma etapa de elaboração, nunca o produto acabado.

Dicas para modelos realistas

Primeiro, corresponda ao tamanho do conteúdo real que você espera. Se a descrição de um produto tiver cerca de cinquenta palavras, gerar quinhentas palavras fará com que o layout pareça apertado e dê uma falsa impressão do design final. Em segundo lugar, misture os tamanhos dos cabeçalhos com o corpo do texto em vez de preencher todos os blocos de forma idêntica, porque as páginas reais têm uma hierarquia clara. Em terceiro lugar, teste seu layout com uma versão curta e longa do texto: um design que só funciona com exatamente três linhas de texto interromperá o momento em que um usuário real escrever quatro. Por fim, lembre-se de que este gerador é executado inteiramente no seu navegador. Nada do que você gera é enviado para um servidor ou armazenado em qualquer lugar, para que você possa usá-lo livremente para maquetes comerciais, apresentações de clientes e trabalhos em sala de aula sem se inscrever ou pagar nada.

Perguntas frequentes (FAQ)

O que é Lorem Ipsum?
Lorem Ipsum é um texto de espaço reservado padrão usado em design e publicação desde os anos 1500. É derivado de uma obra do filósofo romano Cícero, embaralhada para que pareça prosa natural sem carregar significado legível, permitindo que os revisores julguem um layout em vez de revisá-lo.
Quantos parágrafos devo gerar para um modelo?
Para um modelo de página inteira, 3 a 5 parágrafos geralmente preenchem as seções principais de forma realista. Para um único cartão ou seção, 1 parágrafo ou um punhado de frases é suficiente. Combine o comprimento com o conteúdo real que você espera, para que o layout seja testado honestamente.
Posso usar Lorem Ipsum em um projeto comercial?
Sim. Lorem Ipsum é de domínio público e é usado livremente em modelos comerciais, apresentações e protótipos. Basta substituí-lo por uma cópia real antes que qualquer coisa seja publicada para usuários reais.
Por que este gerador usa muitas frases diferentes?
Uma única frase repetida parece obviamente falsa e quebra a ilusão de uma página terminada. Este gerador gira quatorze frases clássicas, de modo que cada parágrafo tem uma mistura diferente de frases curtas e longas, imitando a escrita real.
Meu texto gerado é salvo em algum lugar?
Não. Tudo é executado no seu navegador. O texto nunca é enviado para um servidor, armazenado ou rastreado, e você não precisa de uma conta para usar o gerador.
