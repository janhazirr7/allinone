Cara Menggunakan Pemformat JSON

Pemformat JSON OmniTools menyusun JSON yang berselerak menjadi struktur yang kemas dan mudah dibaca, mengecilkan JSON untuk penghantaran yang cekap, dan mengesahkan sintaks dengan mesej ralat yang jelas. Tampal JSON anda, tekan Format atau Kecilkan, dan hasilnya muncul serta-merta. Jika JSON tidak sah, alat ini menunjukkan jenis ralat dan kedudukan anggaran supaya anda dapat membetulkannya dengan cepat.

  1. Tampal atau taip JSON anda ke dalam kotak input.
  2. Tekan Format untuk paparan kemas dengan inden, atau Kecilkan untuk satu baris.
  3. Tekan Sahkan untuk menyemak sintaks tanpa mengubah teks.
  4. Betulkan ralat yang dilaporkan dan format semula.

Alat ini direka untuk menjadi pantas dan mudah: tiada pendaftaran, tiada pemasangan dan tiada menunggu. Masukkan nilai anda, semak hasilnya, dan laraskan input untuk membandingkan senario yang berbeza. Semua pengiraan berlaku serta-merta di dalam pelayar anda, jadi anda boleh mencuba seberapa banyak nilai yang anda mahu tanpa kos.

Mengapa Pemformat JSON Berguna

Pembangun menggunakan pemformat JSON setiap hari untuk membaca respons API, fail konfigurasi dan data ujian. JSON yang diformat memudahkan untuk melihat struktur bersarang, mencari kunci yang hilang dan mengesan koma yang tertinggal. JSON yang dikecilkan pula berguna untuk menghantar data melalui rangkaian kerana ia lebih kecil. Peraturan JSON yang ketat — koma tertinggal tidak dibenarkan, kunci mesti dalam tanda petik berganda, dan petik tunggal tidak sah — adalah punca ralat yang paling biasa.

Selain kegunaan harian, alat ini membantu anda mengelakkan kesilapan pengiraan manual yang biasa berlaku apabila membahagi, membundar atau menukar unit dengan cepat. Dengan menunjukkan formula dan langkah pengiraan, ia juga berfungsi sebagai alat pembelajaran: anda bukan sahaja mendapat jawapan, tetapi memahami bagaimana jawapan itu diperoleh, jadi anda boleh menyemak dan mempercayainya.

Contoh Pengiraan

Contohnya, JSON {"nama":"Ali","umur":30} yang dikecilkan menjadi format kemas: { "nama": "Ali", "umur": 30 } Koma tertinggal selepas pasangan terakhir, seperti {"nama":"Ali",}, akan ditolak dengan ralat yang menunjukkan koma itu sebagai punca.

Contoh di atas menunjukkan prinsip asasnya, tetapi kekuatan sebenar alat ini ialah anda boleh menguji nilai anda sendiri. Cuba kes ekstrem yang kecil dan besar, bandingkan dua senario bersebelahan, dan perhatikan bagaimana perubahan kecil pada input boleh mengubah hasil dengan ketara — terutamanya untuk pengiraan yang melibatkan peratus, faedah atau tempoh yang panjang.

Ketepatan dan Privasi

Semua pengiraan dilakukan sepenuhnya di dalam pelayar anda. Tiada data yang anda masukkan dihantar ke pelayan, disimpan dalam pangkalan data atau dikongsi dengan pihak ketiga. Anda boleh menggunakan alat ini tanpa akaun, tanpa mendaftar dan tanpa memasang apa-apa, pada telefon, tablet atau komputer.

Ketepatan bergantung pada input anda: masukkan nilai yang tepat dan semak unit sebelum mengira. Hasil dibundarkan untuk paparan, tetapi pengiraan dalaman menggunakan ketepatan penuh, jadi ralat pembundaran tidak terkumpul. Untuk keputusan kewangan, kesihatan atau undang-undang yang penting, sahkan hasil dengan profesional atau sumber rasmi yang berkaitan sebelum membuat komitmen.

Petua Praktikal

  • Gunakan Format untuk membaca, Kecilkan untuk menghantar.
  • Betulkan koma tertinggal dahulu: ia adalah ralat JSON yang paling biasa.
  • Gunakan tanda petik berganda untuk kunci dan nilai rentetan, bukan petik tunggal.
  • Sahkan semula selepas setiap pembetulan sehingga tiada ralat.

Soalan Lazim (FAQ)

Apakah perbezaan antara Format dan Kecilkan?
Format menambah pemisah baris dan inden supaya JSON mudah dibaca oleh manusia. Kecilkan membuang semua ruang yang tidak perlu supaya JSON menjadi satu baris yang padat dan lebih kecil untuk penghantaran atau penyimpanan.
Mengapakah JSON saya gagal dengan ralat koma tertinggal?
JSON tidak membenarkan koma selepas elemen terakhir dalam objek atau tatasusunan. Banyak bahasa pengaturcaraan membenarkannya, tetapi JSON tidak. Buang koma terakhir sebelum kurungan penutup.
Bolehkah saya menggunakan petik tunggal dalam JSON?
Tidak. JSON memerlukan tanda petik berganda untuk kunci dan nilai rentetan. Petik tunggal adalah sah dalam JavaScript tetapi tidak dalam JSON piawai, jadi ia akan ditolak oleh pengesah.
Adakah data JSON saya disimpan atau dihantar ke mana-mana?
Tidak. Semua pemformatan dan pengesahan dilakukan di dalam pelayar anda. Data anda tidak pernah meninggalkan peranti anda.
Adakah pemformatan mengubah data saya?
Tidak. Pemformatan hanya mengubah ruang dan pemisah baris. Nilai, kunci dan strukturnya kekal sama. Pengecilan juga mengekalkan data, hanya membuang ruang yang tidak perlu.
