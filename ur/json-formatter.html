JSON فارمیٹر استعمال کرنے کا طریقہ

  1. اپنا JSON پیسٹ کریںAPI، کنفیگ فائل یا ٹیوٹوریل سے JSON کاپی کریں اور اسے بڑے باکس میں پیسٹ کریں۔
  2. عمل چنیںپڑھنے کے قابل بنانے کے لیے انڈینٹیشن کے ساتھ فارمیٹ دبائیں، ایک لائن میں سکیڑنے کے لیے منی فائی، یا بغیر بدلے چیک کرنے کے لیے صرف توثیق کریں۔
  3. اگر کوئی غلطی ہو تو اسے پڑھیںاگر JSON غلط ہو تو ٹول پارسر کی عین غلطی سادہ الفاظ میں دکھاتا ہے، تاکہ آپ جان سکیں کہ کیا ٹھیک کرنا ہے۔
  4. نتیجہ کاپی کریںفارمیٹ شدہ یا منی فائی شدہ JSON کو اپنے کوڈ، کنفیگ یا API ٹول میں واپس لے جانے کے لیے آؤٹ پٹ کاپی کریں استعمال کریں۔

JSON کیا ہے اور فارمیٹنگ کیوں اہم ہے

JSON، جو JavaScript Object Notation کا مخفف ہے، ویب پر کمپیوٹرز کے سٹرکچرڈ ڈیٹا تبادلے کا سب سے عام طریقہ ہے۔ APIs، کنفیگ فائلیں اور بہت سی ایپس JSON بولتی ہیں کیونکہ یہ پڑھنا سادہ اور مشینوں کے لیے پارس کرنا آسان ہے۔ درست JSON دستاویز کرلی بریکٹس میں آبجیکٹس، اسکوائر بریکٹس میں اریز، ڈبل کوٹس میں اسٹرنگز، اعداد، اور true، false اور null قدروں سے بنتی ہے۔ فارمیٹنگ ڈیٹا کا مطلب نہیں بدلتی، لیکن یہ بدلتی ہے کہ انسان کے لیے پڑھنا کتنا آسان ہے۔ منی فائی شدہ JSON، تمام اسپیسز ہٹا کر، چھوٹا اور نیٹ ورک پر بھیجنے میں تیز ہے، اسی لیے APIs اسے استعمال کرتی ہیں، لیکن اسے پڑھنا یا ڈیبگ کرنا تقریباً ناممکن ہے۔ خوبصورت بنایا گیا JSON، دو اسپیس انڈینٹیشن اور فی لائن ایک قدر کے ساتھ، بڑا ہے لیکن آپ کو سیکنڈوں میں غائب کوما یا غلط بریکٹ پکڑنے دیتا ہے۔

سب سے عام JSON غلطیاں

  • غائب یا اضافی کومے: آبجیکٹ یا اری میں آخری کے سوا ہر آئٹم کو کوما چاہیے، اور آخری آئٹم کے بعد ٹریلنگ کوما سخت JSON میں اجازت نہیں ہے۔
  • ڈبل کوٹس کے بجائے سنگل کوٹس: JSON اسٹرنگز میں ڈبل کوٹس ہونے چاہئیں، چاہے JavaScript کوڈ اکثر سنگل کوٹس کی اجازت دیتا ہو۔
  • بغیر کوٹس کیز: آبجیکٹ کیز کوٹس والی اسٹرنگز ہونی چاہئیں، اس لیے {name: "Ana"} غلط ہے اور {"name": "Ana"} ہونا چاہیے۔
  • تبصرے: JSON تبصروں کی اجازت نہیں دیتا، اس لیے // سے شروع ہونے والی لائنیں پارسنگ توڑ دیں گی چاہے وہ بے ضرر لگیں۔
  • اضافی متن یا متعدد دستاویزات: دو JSON آبجیکٹس ایک کے بعد ایک پیسٹ کرنا غلط ہے؛ انہیں اری میں لپیٹیں یا ایک وقت میں ایک ٹھیک کریں۔

فارمیٹنگ بمقابلہ منی فائنگ: ہر ایک کب استعمال کریں

فارمیٹ اس وقت استعمال کریں جب آپ JSON پڑھ رہے ہوں، ڈیبگ کر رہے ہوں یا اس سے سیکھ رہے ہوں، کیونکہ انڈینٹیشن ایک نظر میں سٹرکچر ظاہر کرتی ہے اور نیسٹنگ واضح کرتی ہے۔ منی فائی اس وقت استعمال کریں جب آپ کو JSON کو URL، کمپیکٹ کنفیگ فیلڈ، ٹیسٹ ریکویسٹ یا پیغام میں پیسٹ کرنا ہو جہاں سائز اہم ہے اور پڑھنے کی اہلیت نہیں۔ صرف توثیق اس وقت استعمال کریں جب آپ کو صرف ہاں یا نہ جواب چاہیے، مثال کے طور پر کنفیگ فائل محفوظ کرنے سے پہلے، کیونکہ یہ آپ کا اصل متن بدلے بغیر چیک کرتا ہے۔ تینوں صورتوں میں ٹول پہلے JSON پارس کرتا ہے، اس لیے منی فائی شدہ یا فارمیٹ شدہ نتیجہ درست ہونے کی ضمانت ہے؛ اگر پارسنگ ناکام ہو تو آپ کو خاموشی سے ٹوٹی آؤٹ پٹ کے بجائے غلطی ملتی ہے، جو کوڈ بھیجنے سے پہلے آپ بالکل چاہتے ہیں۔

پرائیویسی اور حدود

یہ فارمیٹر مکمل طور پر آپ کے براؤزر میں چلتا ہے۔ آپ کا JSON کبھی اپ لوڈ، لاگ یا شیئر نہیں ہوتا، جو اہم ہے کیونکہ JSON میں اکثر API کیز، ذاتی ڈیٹا یا اندرونی کنفیگریشن ہوتی ہے۔ کبھی کسی آن لائن فارمیٹر میں جس پر آپ بھروسہ نہ کریں راز پیسٹ نہ کریں، اور غلطی سے ظاہر کی گئی کسی بھی کی کو بدل دیں۔ یہ ٹول عام API جوابات اور کنفیگ فائلیں آسانی سے سنبھالتا ہے، لیکن بہت بڑی دستاویزات، دسیوں میگا بائٹس، براؤزر ٹیب میں سست ہو سکتی ہیں کیونکہ پارسنگ اور دوبارہ اسٹرنگ بنانے میں میموری لگتی ہے۔ یہ سخت JSON قواعد کی پیروی بھی کرتا ہے، اس لیے یہ JavaScript طرز کی اضافی چیزیں جیسے ٹریلنگ کومے، سنگل کوٹس اور تبصرے مسترد کر دے گا، چاہے کچھ ٹولز انہیں ڈھیلے طور پر قبول کریں۔

اکثر پوچھے جانے والے سوالات

فارمیٹ اور منی فائی میں کیا فرق ہے؟
فارمیٹ انڈینٹیشن اور لائن بریکس شامل کرتا ہے تاکہ JSON انسانوں کے لیے پڑھنا آسان ہو۔ منی فائی تمام غیر ضروری اسپیسز اور لائن بریکس ہٹا دیتا ہے تاکہ JSON بھیجنے یا محفوظ کرنے کے لیے جتنا ممکن ہو چھوٹا ہو۔
میرا JSON ٹریلنگ کوما غلطی سے کیوں ناکام ہوتا ہے؟
سخت JSON آبجیکٹ یا اری میں آخری آئٹم کے بعد کوما کی اجازت نہیں دیتا۔ وہ آخری کوما ہٹا دیں اور JSON پارس ہو جائے گا۔
کیا میں JSON میں سنگل کوٹس استعمال کر سکتا ہوں؟
نہیں۔ JSON اسٹرنگز اور کیز میں ڈبل کوٹس ہونے چاہئیں۔ سنگل کوٹس JavaScript کوڈ میں کام کرتے ہیں، لیکن وہ درست JSON نہیں ہیں اور یہ ٹول انہیں درست طور پر مسترد کر دے گا۔
کیا میرا JSON ڈیٹا کہیں محفوظ یا بھیجا جاتا ہے؟
نہیں۔ فارمیٹنگ اور توثیق مکمل طور پر آپ کے براؤزر میں چلتی ہے، اس لیے آپ کا ڈیٹا کبھی آپ کے آلے سے باہر نہیں جاتا۔
کیا فارمیٹنگ میرا ڈیٹا بدل دیتی ہے؟
نہیں۔ فارمیٹنگ اور منی فائنگ صرف اسپیسنگ اور لائن بریکس بدلتے ہیں۔ قدریں، کیز اور سٹرکچر بالکل وہی رہتے ہیں، بشرطیکہ JSON شروع سے درست ہو۔
