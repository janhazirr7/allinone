怎样使用进制换算器

计算机、程序员和电子工程师不断在进制之间切换：硬件用二进制，老系统和文件权限用八进制，日常算术用十进制，十六进制则是二进制的紧凑简写。本换算器接受四个进制中任何一个进制的数字，并立即一次显示全部四种值，所以你永远不必换算两次，也不用怀疑某个数字在你选择的进制中是否合法。

  1. 输入你的数字在第一个框中输入值，例如 255、1010 或 FF。只接受非负整数；符号和小数点不属于这些整数进制。
  2. 告诉换算器它属于哪个进制从下拉菜单中选择二进制、八进制、十进制或十六进制。这很重要：1010 在二进制中意味着十，在十进制中意味着一千零一十。
  3. 点击“换算”并查看全部四个结果二进制、八进制、十进制和十六进制的值一起出现，十进制值突出显示，这样你就可以复制你的代码或作业需要的任何形式。
  4. 如果出现错误，检查你的数字每个进制只允许特定的数字。二进制只允许 0 和 1，所以 102 会被拒绝；八进制只允许 0 到 7，所以 89 会被拒绝；十六进制只允许 0 到 9 和 A 到 F，所以 G 会被拒绝。

什么是进制，为什么有不止一种？

进制（也称为基数）只不过是一个计数系统在进位到新位之前使用多少个不同的数字。十进制是我们小时候学的系统，使用十个数字（0 到 9），因为人类有十根手指。每一位的值是它右边一位的十倍：在 255 中，各位数字意味着 2 个百 + 5 个十 + 5 个一。二进制只使用两个数字 0 和 1，因为计算机硬件由开或关的开关构成。每个二进制位的值是它右边一位的两倍，所以 1010 意味着 8 + 0 + 2 + 0 = 10。八进制使用八个数字 0 到 7，十六进制使用十六个：0 到 9 加上字母 A 到 F，代表十到十五的值。

十六进制的存在主要是为了方便人类阅读二进制。一个十六进制数字恰好对应四个二进制数字，所以像 11111111 这样的长二进制串可以整齐地缩合为 FF。这就是为什么你在计算中到处都能看到十六进制：网页上的颜色代码如 #FF5733 实际上是红、绿、蓝三个十六进制字节；内存地址用十六进制显示；网络工程师用十六进制读取设备地址。八进制在早期计算中扮演过类似的角色，当时机器的字长能被三位整除，它至今仍出现在 Unix 文件权限中，例如值 755 编码了所有者、组和其他人的读、写、执行权限。

手工换算：两个示例

手工把二进制换算为十进制比任何定义都更能教会位值的概念。以 101101 为例。从右边读起，各位的值分别是 1、2、4、8、16 和 32。从右边起数字是 1、0、1、1、0、1，所以这个值是 1 + 4 + 8 + 32 = 45。十进制换算为二进制则反向进行：反复除以 2 并记录余数。对于 45，余数是 1、0、1、1、0、1，倒读就得到 101101，证实了第一次换算。十六进制用十六的幂以同样的方式工作：1A3 意味着 1 乘以 256，加上 A（10）乘以 16，再加上 3，即 256 + 160 + 3 = 419。

有一个快捷方法可以在不经过十进制的情况下连接二进制、八进制和十六进制。从右边起，把二进制数字三个一组分给八进制、四个一组分给十六进制，然后换算每一组。例如，101011110 分为八进制组 101 011 110，即 5 3 6，分成十六进制组 1 0101 1110，即 1 5 E，所以这个值八进制为 536，十六进制为 15E。学生在这里常犯两个错误：忘记在最左边的组前面补零，以及从左边而不是右边开始分组。两者都会改变答案，所以一定要从最右边的数字开始分组。

实用提示和常见错误

第一，分享可能含糊的数字时一定要说明进制：只写 1010 无法告诉任何人你指的是十还是一千零一十，这就是程序员写 0b1010 表示二进制、0xFF 表示十六进制这样的前缀的原因。第二，记住前导零不会改变值，所以二进制的 0001010 仍然是十；它们常常纯粹是为了把数字补足到整齐的宽度，例如八位。第三，本换算器只处理整数。其他进制的分数、负数和超过 64 位的超长输入都不在它的范围内，换算器会明确告诉你而不是猜测。最后，一切都在你的浏览器中运行，没有任何数据发送到别处，所以你可以私密地、任意多次地换算作业答案、代码常量和权限值。

常见问题

255 的二进制、八进制和十六进制是什么？
255 的二进制是 11111111，八进制是 377，十六进制是 FF。四种形式代表同一个值；变化的只是计数系统。
为什么二进制 102 会报错？
二进制只使用数字 0 和 1，所以数字 2 在 2 进制中是非法的。如果你指的是十进制数一百零二，请先选择十进制作为输入进制。
十六进制字母 A 到 F 是什么？
十六进制需要十六个数字，但我们只有十个数字符号，所以字母 A 到 F 代表 10、11、12、13、14 和 15 的值。这就是 FF 意味着 15 乘以 16 加上 15，即 255 的原因。
怎样快速把二进制换算为十六进制？
从右边起把二进制数字四个一组分组，最左边的组用零补足，然后把每组四个换算为一个十六进制数字。例如，11111111 分组为 1111 1111，即 F F。
本换算器处理负数或分数吗？
不。它换算最多 64 位的非负整数。其他进制的负数和分数需要不同的表示方法，例如二进制补码或小数点，本工具不涵盖。
