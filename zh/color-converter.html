如何使用颜色转换器

设计师、开发人员和印刷商都用不同的语言描述相同的颜色。网页开发人员编写#2563EB，印刷设计师考虑青色和洋红色的百分比，CSS 作者调整亮度达到 HSL。手动在这些格式之间进行转换既缓慢又容易出错，尤其是 HSL 背后的数学原理。该转换器可以立即完成此操作：以任何一种格式输入颜色，然后使用实时样本立即查看所有三种颜色，这样您就可以用眼睛判断结果，而不仅仅是数字。

  1. 从十六进制开始键入带有或不带有哈希值的十六进制代码，例如 #FF0000 或 2563EB，然后按“从十六进制转换”。像 F00 这样的三位数简写也可以使用并扩展为 FF0000。
  2. 或者从RGB开始输入红色、绿色和蓝色通道，每个通道的范围为 0 到 255，然后按“从 RGB 转换”。当设计工具或屏幕截图选择器为您提供 RGB 值时，这会很方便。
  3. 或者从HSL开始输入 0 到 360 度的色调，加上百分比形式的饱和度和亮度，然后按从 HSL 转换。 HSL 是创建较浅或较深颜色版本的最简单格式。
  4. 复制您需要的内容转换后的值与可复制的 CSS 一起显示在下面。预览样本会根据任何输入进行更新，因此您可以自由实验并观察颜色变化。

HEX、RGB 和 HSL 解释

HEX 是网络上 RGB 的简写。每对十六进制数字代表一个通道：第一对是红色，第二对是绿色，第三对是蓝色。因此，FF0000 是纯红色，00FF00 是纯绿色，000000 是黑色，而 FFFFFF 是白色。十六进制使用数字 0 到 9 加上字母 A 到 F，其中 A 表示 10，F 表示 15，这就是为什么两个十六进制数字可以表示 0 到 255 之间的每个值。三位数简写只是将每个数字加倍，因此 F00 变为 FF0000，369 变为 336699。

RGB 将颜色描述为光：混合多少红、绿、蓝光。屏幕会发光，因此全力添加所有三个通道会产生白色，将它们全部关闭会产生黑色。这种附加模型对于屏幕来说很直观，但对于尝试调整颜色的人类来说很尴尬，因为改变亮度意味着同时改变所有三个数字。 HSL 通过描述人们对颜色的看法来解决这个问题：色调是色轮周围的位置（以度为单位），其中 0 为红色，120 为绿色，240 为蓝色；饱和度是指颜色的鲜艳程度，从 0% 的灰色到 100% 的全彩；亮度从 0% 的黑色到 50% 的纯色再到 100% 的白色。

HEX #RRGGBB = RGB（红、绿、蓝），每个 0-255
HSL（色调0-360，饱和度0-100%，亮度0-100%）
示例：纯红色为 #FF0000 = rgb(255, 0, 0) = hsl(0, 100%, 50%)。纯绿色为 #00FF00 = rgb(0, 255, 0) = hsl(120, 100%, 50%)。灰色在任何色调下的饱和度都是 0%。

实际用途和辅助功能提示

最常见的转换任务是在工具之间移动品牌颜色。徽标文件可能会为您提供十六进制代码，开发人员的样式表需要 RGB 来实现 rgba(37, 99, 235, 0.5) 等透明效果，而创建悬停状态的设计人员需要 HSL 通过将亮度提高 10 个点来使相同的颜色变亮。在这里执行这些步骤可以保留一个事实来源：输入品牌颜色一次，每种格式都保持一致，而不是因手动重新输入和舍入错误而漂移。

1. 用一种颜色构建调色板

从 HSL 中的主颜色开始，然后保持色调固定并改变亮度：深色文本为 30%，主颜色为 50%，浅背景色调为 85%。结果看起来是经过设计的，而不是随机的。

2. 发货前检查对比度

浅色背景上的浅色文本是网络上最常见的可访问性失败。使用样本一目了然地判断，并且更喜欢浅色上的深色文本和饱和深色上的白色文本。

3.修复屏幕截图的颜色

颜色选择器通常会报告 RGB 值。将它们粘贴到此处以获取样式表的十六进制代码，或 HSL 值以微调阴影，而无需逐个通道猜测。

关于精度的最后一点说明：RGB 和 HSL 之间的转换涉及舍入，因为此处 HSL 百分比是整数，而 RGB 通道是整数。将颜色转换为 HSL 并转换回来可能会将通道移动一个单位，这对于肉眼来说是不可见的，但对于每个转换器来说都是正常的。如果您需要完美像素的打印复制，请将原始十六进制或 RGB 值保留为主副本。这里的所有内容都在您的浏览器中私下运行，因此您的品牌颜色和调色板永远不会上传或存储。

常见问题 (FAQ)

什么是十六进制颜色代码？
十六进制代码是 RGB 值的六位十六进制简写，用前导哈希编写，例如表示纯红色的 #FF0000。每对数字代表红色、绿色和蓝色，从 00（无）到 FF（完整，或 255）。 F00 等三位数代码是将每个数字加倍为 FF0000 的简写形式。
如何将 HEX 转换为 RGB？
将六个十六进制数字分成三对，并将每对从十六进制转换为十进制。对于#2563EB，25 变为 37，63 变为 99，EB 变为 235，得到 rgb(37, 99, 235)。该转换器可以在任一方向上为您执行该算术。
HSL 中的 H、S 和 L 是什么意思？
H是色调，色轮上从0到360度的位置，其中0是红色，120是绿色，240是蓝色。 S 是饱和度，从 0% 灰色到 100% 完全鲜艳。 L 是亮度，从 0% 黑色到 50% 纯色再到 100% 白色。
为什么来回转换值会改变 1？
这里，HSL 百分比四舍五入为整数，而 RGB 通道是整数，因此往返可以将通道移动一个单位。差异是肉眼看不见的。将原始 HEX 或 RGB 值保留为主副本，以实现像素完美的工作。
我可以使用此转换器来打印颜色吗？
对于屏幕设计，是的。打印使用 CMYK，这是一种基于墨水而不是光线的不同模型，因此转换为打印的屏幕颜色在纸张上看起来会有所不同。始终使用打印机的 CMYK 值校样打印颜色。
我的颜色数据是否已存储？
不会。所有转换都在您的浏览器中运行。您输入的任何内容都不会发送到服务器或存储。
