怎样使用颜色换算器

设计师、开发者和印刷商都用不同的语言描述同一种颜色。网页开发者写 #2563EB，印刷设计师用青色和品红的百分比思考，而调整亮度的 CSS 作者会用 HSL。手工在这些格式之间换算既慢又容易出错，尤其是 HSL 背后的数学。本换算器即时完成：以任何一种格式输入颜色，同时查看三种格式，还有实时色板，让你用眼睛而不是只用数字判断结果。

  1. 从 HEX 开始输入带或不带井号的十六进制代码，例如 #FF0000 或 2563EB，然后点击“从 HEX 换算”。像 F00 这样的三位简写也可以，会扩展为 FF0000。
  2. 或从 RGB 开始输入红、绿、蓝通道，每个 0 到 255，然后点击“从 RGB 换算”。当设计工具或截图取色器给你 RGB 值时，这很方便。
  3. 或从 HSL 开始输入 0 到 360 度的色相，加上以百分比表示的饱和度和亮度，然后点击“从 HSL 换算”。HSL 是创建颜色更浅或更深版本最容易的格式。
  4. 复制你需要的换算后的值显示在下方，附带可复制的 CSS。预览色板会随任何输入更新，所以你可以自由尝试并看着颜色变化。

HEX、RGB 和 HSL 详解

HEX 是网络上 RGB 的简写。每对十六进制数字代表一个通道：第一对是红色，第二对是绿色，第三对是蓝色。因此 FF0000 是纯红，00FF00 是纯绿，000000 是黑色，而 FFFFFF 是白色。十六进制使用数字 0 到 9 加上字母 A 到 F，其中 A 表示 10，F 表示 15，这就是为什么两位十六进制数字可以表示 0 到 255 的每个值。三位简写只是把每个数字加倍，所以 F00 变成 FF0000，369 变成 336699。

RGB 把颜色描述为光：要混合多少红光、绿光和蓝光。屏幕发光，所以三个通道都满强度相加产生白色，全部关闭产生黑色。这种加色模型对屏幕来说很直观，但对想要调整颜色的人来说很别扭，因为改变亮度意味着同时改变三个数字。HSL 解决了这个问题，它按人们思考颜色的方式描述颜色：色相是色轮上的位置（以度为单位），其中 0 是红色，120 是绿色，240 是蓝色；饱和度是颜色多鲜艳，从 0% 的灰色到 100% 的全彩；亮度从 0% 的黑色经 50% 的纯色到 100% 的白色。

HEX #RRGGBB = RGB（红、绿、蓝），每个 0-255
HSL（色相 0-360，饱和度 0-100%，亮度 0-100%）
示例：纯红是 #FF0000 = rgb(255, 0, 0) = hsl(0, 100%, 50%)。纯绿是 #00FF00 = rgb(0, 255, 0) = hsl(120, 100%, 50%)。灰色在任何色相下饱和度都是 0%。

实际用途和无障碍提示

最常见的换算任务是在工具之间转移品牌颜色。标志文件可能给你一个十六进制代码，开发者的样式表需要 RGB 来做像 rgba(37, 99, 235, 0.5) 这样的透明效果，而创建悬停状态的设计师需要 HSL，通过提高亮度十个点来让同一种颜色变浅。在这里完成这些步骤可以保持唯一真实来源：品牌颜色输入一次，每种格式都保持一致，而不是在手工重输和四舍五入误差中漂移。

1. 从一种颜色构建调色板

从 HSL 中的主色开始，然后固定色相、改变亮度：30% 用于深色文字，50% 用于主色，85% 用于浅色背景色调。结果看起来是经过设计的，而不是随机的。

2. 发布前检查对比度

浅色背景上的浅色文字是网络上最常见的无障碍失败。用色板一眼判断，浅色上优先用深色文字，饱和深色上优先用白色文字。

3. 修复截图中的颜色

取色器常常报告 RGB 值。把它们粘贴在这里，得到样式表用的十六进制代码，或者得到 HSL 值，无需逐个通道猜测就能微调色调。

关于精度的最后一点说明：在 RGB 和 HSL 之间换算涉及四舍五入，因为这里的 HSL 百分比是整数，RGB 通道也是整数。把一种颜色换算成 HSL 再换回来可能让一个通道偏移一个单位，这肉眼看不出来，对每个换算器来说都是正常的。如果印刷需要像素级精确还原，请保留原始十六进制或 RGB 值作为母本。这里的一切都在你的浏览器中私密运行，所以你的品牌颜色和调色板绝不会被上传或存储。

常见问题

什么是 HEX 颜色代码？
HEX 代码是用前导井号书写的 RGB 值的六位十六进制简写，例如纯红色的 #FF0000。每对数字分别代表红、绿、蓝，从 00（无）到 FF（满，即 255）。像 F00 这样的三位代码是简写，把每个数字加倍得到 FF0000。
怎样把 HEX 换算成 RGB？
把六位十六进制数字分成三对，每对从十六进制换算成十进制。对于 #2563EB，25 变成 37，63 变成 99，EB 变成 235，得到 rgb(37, 99, 235)。本换算器在两个方向上都为你完成这个计算。
HSL 中的 H、S、L 是什么意思？
H 是色相，即色轮上 0 到 360 度的位置，其中 0 是红色，120 是绿色，240 是蓝色。S 是饱和度，从 0% 的灰色到 100% 的完全鲜艳。L 是亮度，从 0% 的黑色经 50% 的纯色到 100% 的白色。
为什么来回换算会让一个值变化 1？
这里的 HSL 百分比四舍五入为整数，RGB 通道也是整数，所以一次来回换算可能让一个通道偏移一个单位。这种差异肉眼看不出来。如需像素级精确，请保留原始 HEX 或 RGB 值作为母本。
我能用这个换算器换算印刷颜色吗？
用于屏幕设计，可以。印刷使用 CMYK，一种基于油墨而非光线的不同模型，所以为印刷换算的屏幕颜色在纸上看起来会不同。印刷颜色请始终用你打印机的 CMYK 值打样。
我的颜色数据会被存储吗？
不会。所有换算都在你的浏览器中运行。你输入的任何内容都不会发送到服务器或存储。
