كيفية استخدام منسق JSON

  1. الصق ملف JSON الخاص بكانسخ JSON من واجهة برمجة التطبيقات أو ملف التكوين أو البرنامج التعليمي والصقه في المربع الكبير.
  2. اختر إجراءًاضغط على "تنسيق" لجعله قابلاً للقراءة مع المسافة البادئة، أو "تصغير" لتقليصه إلى سطر واحد، أو "التحقق من الصحة فقط" للتحقق منه دون تغييره.
  3. اقرأ الخطأ إذا كان هناك واحدإذا كان JSON غير صالح، فستعرض الأداة الخطأ الدقيق من المحلل اللغوي بكلمات واضحة، حتى تعرف ما يجب إصلاحه.
  4. انسخ النتيجةاستخدم Copy Output لإعادة JSON المنسق أو المصغر إلى التعليمات البرمجية أو أداة التكوين أو واجهة برمجة التطبيقات (API).

ما هو JSON ولماذا يعتبر التنسيق مهمًا؟

تعد JSON، وهي اختصار لـ JavaScript Object Notation، الطريقة الأكثر شيوعًا لتبادل أجهزة الكمبيوتر للبيانات المنظمة على الويب. تتحدث واجهات برمجة التطبيقات وملفات التكوين والعديد من التطبيقات جميعها لغة JSON لأنها سهلة القراءة ويسهل على الأجهزة تحليلها. يتم إنشاء مستند JSON الصالح من كائنات بين أقواس متعرجة، ومصفوفات بين أقواس مربعة، وسلاسل بين علامات اقتباس مزدوجة، وأرقام، والقيم صحيحة وخاطئة وخالية. لا يغير التنسيق معنى البيانات، ولكنه يغير مدى سهولة قراءتها بالنسبة للإنسان. يعد Miniified JSON، مع إزالة جميع المسافات، أصغر حجمًا وأسرع في الإرسال عبر الشبكة، ولهذا السبب تستخدمه واجهات برمجة التطبيقات (APIs)، ولكن يكاد يكون من المستحيل قراءته أو تصحيحه. يعد Beautified JSON، مع مسافة بادئة ذات مسافتين وقيمة واحدة لكل سطر، أكبر ولكنه يتيح لك اكتشاف فاصلة مفقودة أو قوس خاطئ في ثوانٍ.

أخطاء JSON الأكثر شيوعًا

  • الفواصل المفقودة أو الإضافية: كل عنصر في كائن أو مصفوفة باستثناء العنصر الأخير يحتاج إلى فاصلة، ولا يُسمح بالفاصلة اللاحقة بعد العنصر الأخير في JSON الصارم.
  • علامات الاقتباس المفردة بدلاً من علامات الاقتباس المزدوجة: يجب أن تستخدم سلاسل JSON علامات الاقتباس المزدوجة، على الرغم من أن كود JavaScript يسمح غالبًا بعلامات الاقتباس المفردة.
  • المفاتيح غير المقتبسة: يجب أن تكون مفاتيح الكائنات عبارة عن سلاسل مقتبسة، لذا فإن {name: "Ana"} غير صالح ويجب أن يكون {"name": "Ana"}.
  • التعليقات: لا يسمح JSON بالتعليقات، لذا فإن الأسطر التي تبدأ بـ // ستؤدي إلى انقطاع التحليل حتى لو بدت غير ضارة.
  • نص زائد أو مستندات متعددة: يعد لصق كائنين JSON واحدًا تلو الآخر غير صالح؛ لفها في مصفوفة أو قم بإصلاحها واحدة تلو الأخرى.

التنسيق مقابل التصغير: متى يجب استخدام كل منهما

استخدم التنسيق عند القراءة أو تصحيح الأخطاء أو التعلم من JSON، لأن المسافة البادئة تكشف البنية في لمحة وتجعل التداخل واضحًا. استخدم Minify عندما تحتاج إلى لصق JSON في عنوان URL أو حقل تكوين مضغوط أو طلب اختبار أو رسالة لا يهم فيها الحجم وإمكانية القراءة. استخدم التحقق من الصحة فقط عندما تحتاج فقط إلى إجابة بنعم أو لا، على سبيل المثال قبل حفظ ملف التكوين، لأنه يتحقق من JSON دون استبدال النص الأصلي. في جميع الحالات الثلاث، تقوم الأداة أولاً بتحليل JSON، لذلك يتم ضمان صحة النتيجة المصغرة أو المنسقة؛ إذا فشل التحليل، فستحصل على خطأ بدلاً من إخراج معطل بصمت، وهو بالضبط ما تريده قبل رمز الشحن.

الخصوصية والحدود

يعمل هذا المنسق بالكامل في متصفحك. لا يتم تحميل JSON الخاص بك أو تسجيله أو مشاركته مطلقًا، وهو أمر مهم لأن JSON غالبًا ما يحتوي على مفاتيح API أو بيانات شخصية أو تكوين داخلي. لا تقم أبدًا بلصق الأسرار في أي منسق عبر الإنترنت لا تثق به، وقم بتدوير أي مفتاح تكشفه عن طريق الخطأ. تتعامل الأداة مع استجابات واجهة برمجة التطبيقات النموذجية وملفات التكوين بسهولة، ولكن المستندات الكبيرة للغاية، عشرات الميجابايت، قد تكون بطيئة في علامة تبويب المتصفح لأن تحليلها وإعادة تنظيمها يتطلب ذاكرة. كما أنه يتبع قواعد JSON الصارمة، لذلك سيرفض الإضافات على نمط JavaScript مثل الفواصل اللاحقة وعلامات الاقتباس المفردة والتعليقات، على الرغم من أن بعض الأدوات تقبلها بشكل فضفاض.

الأسئلة المتداولة (الأسئلة الشائعة)

ما هو الفرق بين التنسيق والتصغير؟
يضيف التنسيق مسافة بادئة وفواصل أسطر حتى يسهل على البشر قراءة JSON. يقوم Miniify بإزالة جميع المسافات وفواصل الأسطر غير الضرورية بحيث يكون JSON صغيرًا قدر الإمكان للإرسال أو التخزين.
لماذا يفشل JSON الخاص بي بسبب خطأ فاصلة زائدة؟
لا يسمح Strict JSON بفاصلة بعد العنصر الأخير في كائن أو صفيف. قم بإزالة تلك الفاصلة النهائية وسيتم تحليل JSON.
هل يمكنني استخدام علامات الاقتباس المفردة في JSON؟
لا. يجب أن تستخدم سلاسل ومفاتيح JSON علامات الاقتباس المزدوجة. تعمل علامات الاقتباس المفردة في كود JavaScript، ولكنها ليست صالحة بتنسيق JSON وسترفضها هذه الأداة بشكل صحيح.
هل يتم تخزين بيانات JSON الخاصة بي أو إرسالها إلى أي مكان؟
لا. يتم إجراء التنسيق والتحقق بالكامل في متصفحك، لذلك لا تترك بياناتك جهازك أبدًا.
هل التنسيق يغير بياناتي؟
لا. التنسيق والتصغير يؤديان فقط إلى تغيير المسافات وفواصل الأسطر. تظل القيم والمفاتيح والبنية كما هي تمامًا، طالما كان JSON صالحًا للبدء به.
