# OmniTools - Free Fast Online Multi-Tool Platform ⚡

A lightweight, modern, and privacy-first multi-tool platform built with semantic HTML5, responsive CSS, and pure Vanilla JavaScript (zero external dependencies). Designed to be hosted for free on **GitHub Pages** and optimized for **Google AdSense**.

- **Spanish Platform (/es/)**: `https://janhazirr7.github.io/allinone/es/`

## 🚀 Key Features
- **100% Client-Side Privacy**: All mathematical operations and text parsing occur exclusively in the user's browser. No data ever touches a remote server.
- **Zero Heavy Dependencies**: Pure Vanilla JS, lightweight modern CSS with design tokens. Near-instant first contentful paint (FCP).
- **Google AdSense Ready**: Pre-styled CLS-guarded `.ad-slot` containers, mandatory compliance pages (`privacy-policy.html`, `terms.html`, `about.html`, `contact.html`), and 500+ word educational guides on each tool.
- **Advanced Technical SEO**: Rich structured data (`WebApplication`, `FAQPage`, `BreadcrumbList`, `WebSite`), Open Graph, Twitter cards, and bidirectional `hreflang` tags.
