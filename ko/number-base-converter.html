숫자 변환기를 사용하는 방법

컴퓨터, 프로그래머 및 전자 엔지니어는 하드웨어의 경우 2진수, 이전 시스템 및 파일 권한의 경우 8진수, 일상적인 산술의 경우 10진수, 2진수의 축약형 약칭인 16진수 사이를 끊임없이 전환합니다. 이 변환기는 네 가지 진수 중 하나의 숫자를 가져와 즉시 네 가지 값을 모두 한 번에 표시하므로 두 번 변환할 필요가 없으며 선택한 진수에 숫자가 적합한지 궁금해할 필요가 없습니다.

  1. 전화번호를 입력하세요첫 번째 상자에 값(예: 255, 1010, FF)을 입력합니다. 음수가 아닌 정수만; 부호와 소수점은 이러한 정수 기수의 일부가 아닙니다.
  2. 어떤 베이스에 있는지 변환기에게 알려주십시오.드롭다운에서 2진수, 8진수, 10진수 또는 16진수를 선택하세요. 이것이 중요합니다. 1010은 이진수로 10을 의미하지만 십진수로 1000을 의미합니다.
  3. 변환을 누르고 네 가지 결과를 모두 읽습니다.2진수, 8진수, 10진수 및 16진수 값이 함께 표시되고 10진수 값이 강조 표시되므로 코드나 과제에 필요한 형식을 복사할 수 있습니다.
  4. 오류가 나타나면 숫자를 확인하세요.각 베이스는 특정 숫자만 허용합니다. 바이너리는 0과 1만 허용하므로 102는 거부됩니다. 8진수는 0부터 7까지 허용하므로 89는 거부됩니다. 16진수는 0~9, A~F를 허용하므로 G는 거부됩니다.

숫자 베이스란 무엇이며, 왜 둘 이상입니까?

기수라고도 불리는 수진은 단순히 계산 시스템이 새로운 위치로 넘어가기 전에 사용하는 고유 자릿수를 나타냅니다. 우리가 어릴 때 배우는 십진법은 인간의 손가락이 10개이기 때문에 10개의 숫자(0~9)를 사용합니다. 각 위치는 오른쪽 위치의 10배 가치가 있습니다. 255에서 숫자는 200 + 5 10 + 5 1을 의미합니다. 바이너리는 0과 1이라는 두 자리 숫자만 사용합니다. 왜냐하면 컴퓨터 하드웨어는 꺼져 있거나 켜져 있는 스위치로 구성되어 있기 때문입니다. 각 이진수 위치는 오른쪽에 있는 값의 두 배 가치가 있으므로 1010은 8 + 0 + 2 + 0 = 10을 의미합니다. 8진수는 0~7의 8자리 숫자를 사용하고 16진수는 16자리를 사용합니다. 즉 0~9에 문자 A~F를 사용하여 10~15의 값을 나타냅니다.

16진수는 주로 인간이 이진수를 읽을 때 편의를 위해 존재합니다. 16진수 한 자리는 정확히 4개의 이진수에 해당하므로 11111111과 같은 긴 이진수 문자열은 깔끔하게 FF로 축소됩니다. 이것이 컴퓨팅의 모든 곳에서 16진수를 볼 수 있는 이유입니다. #FF5733과 같은 웹의 색상 코드는 실제로 빨간색, 녹색 및 파란색에 대한 3개의 16진수 바이트입니다. 메모리 주소는 16진수로 표시됩니다. 네트워크 엔지니어는 16진수로 장치 주소를 읽습니다. Octal은 기계가 3비트로 나눌 수 있는 단어 크기를 사용했던 초기 컴퓨팅에서 유사한 역할을 수행했으며 755와 같은 값이 소유자, 그룹 및 다른 사람의 읽기, 쓰기 및 실행 권한을 인코딩하는 Unix 파일 권한에 여전히 나타납니다.

손으로 변환하기: 두 가지 실제 사례

손으로 이진수를 십진수로 변환하면 어떤 정의보다 자리값 개념을 더 잘 배울 수 있습니다. 101101을 가져옵니다. 오른쪽에서 읽으면 위치는 1, 2, 4, 8, 16, 32입니다. 숫자는 오른쪽에서 1, 0, 1, 1, 0, 1이므로 값은 1 + 4 + 8 + 32 = 45입니다. 10진수를 2진수로 변환하는 것은 다른 방법으로 진행됩니다. 2로 반복해서 나누고 나머지를 기록합니다. 45의 경우 나머지는 1, 0, 1, 1, 0, 1이고 이를 거꾸로 읽으면 101101이 되어 첫 번째 변환을 확인합니다. 16진수는 16의 거듭제곱과 동일한 방식으로 작동합니다. 1A3은 1 곱하기 256, 더하기 A(10) 곱하기 16, 더하기 3, 즉 256 + 160 + 3 = 419를 의미합니다.

빠른 단축키는 10진수를 거치지 않고 2진수, 8진수, 16진수를 연결합니다. 8진수는 오른쪽부터 3개, 16진수는 4개로 이진수를 그룹화한 후 각 그룹을 변환합니다. 예를 들어 101011110은 8진수 그룹(5 3 6)에서는 101 011 110이 되고, 16진수 그룹(1 5 E)에서는 1 0101 1110이 되므로 값은 8진수에서는 536, 16진수에서는 15E가 됩니다. 학생들은 여기서 종종 두 가지 실수를 범합니다. 가장 왼쪽 그룹에 앞에 0을 붙이는 것을 잊어버린 것과 오른쪽 대신 왼쪽에서 그룹을 읽는 것입니다. 둘 다 답을 바꾸므로 항상 가장 오른쪽 숫자부터 그룹화를 시작하세요.

실용적인 팁과 일반적인 실수

첫째, 모호할 수 있는 숫자를 공유할 때는 항상 기본을 명시하십시오. 1010만 쓴다고 해서 10인지 1000인지는 아무에게도 알 수 없습니다. 이것이 바로 프로그래머가 2진수에 0b1010, 16진수에 0xFF와 같은 접두사를 쓰는 이유입니다. 둘째, 앞에 오는 0은 값을 변경하지 않으므로 이진수 0001010은 여전히 ​​10입니다. 8비트와 같이 깔끔한 너비로 숫자를 채우기 위해 순전히 추가되는 경우가 많습니다. 셋째, 이 변환기는 정수만 처리합니다. 다른 진수의 분수, 음수 및 64자리를 초과하는 매우 긴 입력은 해당 범위를 벗어나므로 변환기는 추측하기보다는 이를 알려줍니다. 마지막으로 데이터가 어디에도 전송되지 않고 모든 것이 브라우저에서 실행되므로 숙제 답변, 코드 상수 및 권한 값을 원하는 만큼 자주 비공개로 변환할 수 있습니다.

자주 묻는 질문(FAQ)

2진수, 8진수, 16진수로 255는 무엇인가요?
2진수 255는 11111111, 8진수는 377, 16진수는 FF입니다. 네 가지 형식은 모두 동일한 값을 나타냅니다. 계산 시스템만 변경됩니다.
바이너리 102에서 오류가 발생하는 이유는 무엇입니까?
2진수는 숫자 0과 1만 사용하므로 숫자 2는 2진법에 적합하지 않습니다. 10진수 120을 의미하는 경우 먼저 10진수를 입력 기수로 선택하세요.
16진수 문자 A부터 F까지 무엇인가요?
16진수에는 16자리가 필요하지만 숫자는 10개뿐입니다. 따라서 A부터 F까지의 문자는 10, 11, 12, 13, 14, 15의 값을 나타냅니다. 이것이 바로 FF가 15 곱하기 16 더하기 15, 즉 255를 의미하는 이유입니다.
2진수를 16진수로 빠르게 변환하려면 어떻게 해야 합니까?
이진수를 오른쪽부터 4개로 그룹화하고 가장 왼쪽 그룹을 0으로 채운 다음 4개의 각 그룹을 16진수로 변환합니다. 예를 들어 11111111은 1111 1111, 즉 F F로 그룹화됩니다.
이 변환기는 음수나 분수를 처리합니까?
아니요. 음수가 아닌 전체 정수를 최대 64자리까지 변환합니다. 다른 진법의 음수 및 분수에는 2의 보수 또는 분수와 같은 다른 표현이 필요하지만 이 도구에서는 다루지 않습니다.
