수 체계 변환기 사용 방법

컴퓨터, 프로그래머, 전자공학 엔지니어는 수 체계를 끊임없이 오갑니다. 하드웨어에는 이진법, 오래된 시스템과 파일 권한에는 팔진법, 일상 계산에는 십진법, 이진법의 간결한 줄임말로는 십육진법을 씁니다. 이 변환기는 네 가지 진법 중 어느 하나로 된 숫자를 받아 네 가지 값을 한 번에 즉시 보여주므로, 두 번 변환하거나 선택한 진법에서 숫자가 허용되는지 고민할 필요가 없습니다.

  1. 숫자 입력첫 번째 상자에 값을 입력하세요. 예를 들어 255, 1010, FF입니다. 음이 아닌 정수만 가능합니다. 부호와 소수점은 이 정수 진법의 일부가 아닙니다.
  2. 변환기에 어떤 진법인지 알려주기드롭다운에서 이진법, 팔진법, 십진법, 십육진법 중 하나를 선택하세요. 이는 중요합니다. 1010은 이진법에서는 10이지만 십진법에서는 1010입니다.
  3. 변환을 누르고 네 가지 결과를 모두 읽기이진법, 팔진법, 십진법, 십육진법 값이 함께 나타나며, 십진법 값이 강조 표시되므로 코드나 숙제에 필요한 형태를 복사할 수 있습니다.
  4. 오류가 나타나면 숫자를 확인하세요각 진법마다 허용되는 숫자만 쓸 수 있습니다. 이진법은 0과 1만 허용하므로 102는 거부되고, 팔진법은 0부터 7까지 허용하므로 89는 거부되며, 십육진법은 0부터 9와 A부터 F까지 허용하므로 G는 거부됩니다.

수 진법이란 무엇이고 왜 하나보다 많은가?

수 체계의 밑수, 즉 진법은 자리올림이 일어나기 전에 한 수 세는 방식이 사용하는 서로 다른 숫자의 개수입니다. 어릴 때 배우는 십진법은 사람이 손가락이 열 개라서 0부터 9까지 열 개의 숫자를 씁니다. 각 자리는 오른쪽 자리보다 열 배의 값을 가집니다. 255에서 각 숫자는 2개의 백 단위 + 5개의 십 단위 + 5개의 일 단위를 뜻합니다. 이진법은 컴퓨터 하드웨어가 켜짐과 꺼짐 중 하나의 상태인 스위치로 만들어지기 때문에 0과 1 두 숫자만 씁니다. 이진법의 각 자리는 오른쪽 자리보다 두 배의 값을 가지므로, 1010은 8 + 0 + 2 + 0 = 10을 뜻합니다. 팔진법은 0부터 7까지 여덟 개의 숫자를 쓰고, 십육진법은 열여섯 개를 씁니다. 0부터 9에, 10부터 15를 나타내는 문자 A부터 F를 더한 것입니다.

십육진법은 주로 이진법을 읽는 사람을 위해 편의를 제공하려고 존재합니다. 16진수 숫자 하나는 정확히 이진수 숫자 네 개에 대응하므로, 11111111 같은 긴 이진 문자열은 깔끔하게 FF로 줄어듭니다. 그래서 컴퓨팅 곳곳에서 십육진법을 볼 수 있습니다. 웹의 #FF5733 같은 색상 코드는 실제로 빨간색, 초록색, 파란색을 나타내는 16진수 바이트 세 개이고, 메모리 주소는 16진법으로 표시되며, 네트워크 엔지니어는 기기 주소를 16진법으로 읽습니다. 팔진법은 초창기 컴퓨팅에서 기계가 3비트로 나누어떨어지는 워드 크기를 사용했을 때 비슷한 역할을 했고, 지금도 Unix 파일 권한에서 나타나는데, 755 같은 값은 소유자, 그룹, 기타 사용자의 읽기, 쓰기, 실행 권한을 인코딩합니다.

손으로 변환하기: 풀이가 있는 예시 두 가지

이진법을 손으로 십진법으로 바꾸는 연습은 어떤 정의보다 자리값 개념을 잘 가르쳐줍니다. 101101을 예로 들어보세요. 오른쪽부터 읽으면 각 자리의 값은 1, 2, 4, 8, 16, 32입니다. 오른쪽부터 숫자는 1, 0, 1, 1, 0, 1이므로, 값은 1 + 4 + 8 + 32 = 45입니다. 십진법을 이진법으로 바꾸는 것은 반대 방향입니다. 2로 반복해서 나누며 나머지를 기록하세요. 45의 나머지는 1, 0, 1, 1, 0, 1이며, 이를 거꾸로 읽으면 101101이 되어 첫 번째 변환을 확인해줍니다. 십육진법도 16의 거듭제곱으로 같은 방식으로 동작합니다. 1A3은 1 × 256에 A(10) × 16, 그리고 3을 더한 것으로, 256 + 160 + 3 = 419입니다.

십진법을 거치지 않고 이진법, 팔진법, 십육진법을 바로 연결하는 빠른 방법이 있습니다. 팔진법으로 바꿀 때는 오른쪽부터 이진수 숫자를 세 개씩 묶고, 십육진법으로 바꿀 때는 네 개씩 묶은 뒤 각 묶음을 변환하세요. 예를 들어 101011110은 팔진법 묶음으로 101 011 110이 되어 5 3 6이 되고, 십육진법 묶음으로 1 0101 1110이 되어 1 5 E가 되므로, 값은 팔진법으로 536, 십육진법으로 15E입니다. 학생들이 흔히 저지르는 실수는 두 가지입니다. 가장 왼쪽 묶음 앞에 0을 채우는 것을 잊는 것과, 오른쪽이 아니라 왼쪽부터 묶음을 읽는 것입니다. 두 실수 모두 답을 바꾸므로, 항상 가장 오른쪽 숫자부터 묶기 시작하세요.

실용적인 팁과 흔한 실수

첫째, 모호할 수 있는 숫자를 공유할 때는 항상 진법을 명시하세요. 1010만 쓰면 10을 뜻하는지 1010을 뜻하는지 알 수 없기 때문에, 프로그래머는 이진법에는 0b1010, 십육진법에는 0xFF 같은 접두사를 씁니다. 둘째, 앞자리 0은 값을 바꾸지 않는다는 점을 기억하세요. 이진법의 0001010도 여전히 10입니다. 앞자리 0은 8비트처럼 깔끔한 너비로 맞추기 위해 순전히 채우는 용도로 더해지는 경우가 많습니다. 셋째, 이 변환기는 정수만 처리합니다. 다른 진법의 분수, 음수, 64자리를 초과하는 매우 긴 입력은 범위를 벗어나며, 변환기는 추측하지 않고 그 사실을 알려줍니다. 마지막으로, 모든 처리는 데이터 전송 없이 브라우저에서 이루어지므로, 숙제 답, 코드 상수, 권한 값을 비공개로 원하는 만큼 자주 변환할 수 있습니다.

자주 묻는 질문(FAQ)

255를 2진법, 8진법, 16진법으로 나타내면?
255를 이진법으로 쓰면 11111111, 팔진법으로 쓰면 377, 십육진법으로 쓰면 FF입니다. 네 가지 형태 모두 같은 값을 나타냅니다. 달라지는 것은 수 세는 방식뿐입니다.
2진법 102가 오류를 일으키는 이유는?
이진법은 0과 1 두 숫자만 사용하므로, 숫자 2는 밑수 2에서는 허용되지 않습니다. 십진수 102를 뜻한 것이라면, 먼저 입력 밑수로 십진법을 선택하세요.
16진수 문자 A부터 F란 무엇인가?
십육진법에는 열여섯 개의 숫자가 필요하지만, 숫자 기호는 열 개뿐이므로 문자 A부터 F가 10, 11, 12, 13, 14, 15의 값을 대신합니다. 그래서 FF는 15 × 16 + 15, 즉 255를 뜻합니다.
이진법을 십육진법으로 빠르게 변환하려면 어떻게 하나요?
이진수 숫자를 오른쪽부터 네 개씩 묶되, 가장 왼쪽 묶음은 0으로 채운 뒤, 네 개씩 묶은 각 그룹을 하나의 16진수 숫자로 변환하세요. 예를 들어 11111111은 1111 1111로 묶이며, 이는 F F입니다.
이 변환기가 음수나 분수를 처리하나요?
아니요. 최대 64자리까지의 음이 아닌 정수만 변환합니다. 다른 진법의 음수나 분수는 2의 보수나 소수점 같은 다른 표현이 필요하며, 이 도구는 이를 다루지 않습니다.
