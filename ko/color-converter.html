색상 변환기를 사용하는 방법

디자이너, 개발자, 프린터는 모두 같은 색상을 다른 언어로 설명합니다. 웹 개발자는 #2563EB를 쓰고, 인쇄 디자이너는 청록색과 자홍색의 백분율로 생각하며, 밝기를 조정하는 CSS 작성자는 HSL에 도달합니다. 이러한 형식을 직접 변환하는 것은 속도가 느리고 오류가 발생하기 쉽습니다. 특히 HSL의 수학에서는 더욱 그렇습니다. 이 변환기는 즉시 수행됩니다. 하나의 형식으로 색상을 입력하고 실시간 견본을 통해 세 가지를 동시에 볼 수 있으므로 숫자뿐만 아니라 눈으로 결과를 판단할 수 있습니다.

  1. HEX에서 시작해시가 있거나 없는 16진수 코드(예: #FF0000 또는 2563EB)를 입력하고 HEX에서 변환을 누릅니다. F00과 같은 세 자리 약어도 작동하며 FF0000으로 확장됩니다.
  2. 아니면 RGB부터 시작하세요각각 0부터 255까지 빨간색, 녹색, 파란색 채널을 입력하고 RGB에서 변환을 누릅니다. 이는 디자인 도구나 스크린샷 선택기가 RGB 값을 제공할 때 유용합니다.
  3. 또는 HSL에서 시작0~360도 범위의 색조와 채도 및 밝기를 백분율로 입력하고 HSL에서 변환을 누릅니다. HSL은 더 밝거나 더 어두운 버전의 색상을 만드는 가장 쉬운 형식입니다.
  4. 필요한 것을 복사하세요변환된 값은 복사 가능한 CSS와 함께 아래에 표시됩니다. 미리보기 견본은 모든 입력에서 업데이트되므로 자유롭게 실험하고 색상 변경을 확인할 수 있습니다.

HEX, RGB 및 HSL 설명

HEX는 RGB의 웹 약어입니다. 각 16진수 쌍은 하나의 채널을 나타냅니다. 첫 번째 쌍은 빨간색, 두 번째 녹색, 세 번째 파란색입니다. 따라서 FF0000은 순수한 빨간색, 00FF00은 순수한 녹색, 000000은 검은색이고 FFFFFF는 흰색입니다. 16진수는 숫자 0~9와 문자 A~F를 사용합니다. 여기서 A는 10을 의미하고 F는 15를 의미하므로 2개의 16진수는 0~255의 모든 값을 나타낼 수 있습니다. 3자리 약칭은 단순히 각 숫자를 두 배로 늘리므로 F00은 FF0000이 되고 369는 336699가 됩니다.

RGB는 색상을 빛으로 표현합니다. 즉, 혼합할 빨간색, 녹색, 파란색 빛의 양입니다. 화면은 빛을 방출하므로 세 채널을 모두 최대 강도로 추가하면 흰색이 생성되고 모두 끄면 검정색이 생성됩니다. 이 추가 모델은 화면에서는 직관적이지만 색상을 조정하려는 사람에게는 어색합니다. 밝기를 변경하면 세 숫자가 모두 동시에 변경되기 때문입니다. HSL은 사람들이 생각하는 방식으로 색상을 설명함으로써 이를 수정합니다. 색상은 색상환 주위의 위치(도)로, 0은 빨간색, 120은 녹색, 240은 파란색입니다. 채도는 0% 회색부터 100% 풀 컬러까지 색상이 얼마나 생생한지를 나타냅니다. 밝기는 0%의 검은색부터 50%의 순수 색상, 100%의 흰색까지 이어집니다.

HEX #RRGGBB = RGB(빨간색, 녹색, 파란색), 각 0-255
HSL(색조 0-360, 채도 0-100%, 밝기 0-100%)
예: 순수한 빨간색은 #FF0000 = rgb(255, 0, 0) = hsl(0, 100%, 50%)입니다. 순수한 녹색은 #00FF00 = rgb(0, 255, 0) = hsl(120, 100%, 50%)입니다. 회색은 모든 색상에서 채도가 0%입니다.

실용적인 사용 및 접근성 팁

가장 일반적인 변환 작업은 도구 간에 브랜드 색상을 이동하는 것입니다. 로고 파일은 16진수 코드를 제공할 수 있고, 개발자의 스타일시트에는 rgba(37, 99, 235, 0.5)와 같은 투명도 효과를 위해 RGB가 필요하며, 호버 상태를 만드는 디자이너는 밝기를 10포인트 높여 동일한 색상을 밝게 하려면 HSL이 필요합니다. 여기에서 이러한 단계를 수행하면 하나의 정보 소스가 유지됩니다. 즉, 브랜드 색상을 한 번 입력하면 수동으로 다시 입력하거나 반올림 오류를 겪는 대신 모든 형식이 일관되게 유지됩니다.

1. 한 가지 색상으로 팔레트 만들기

HSL의 기본 색상에서 시작한 다음 색조를 고정하고 밝기를 변경합니다. 어두운 텍스트의 경우 30%, 기본 색상의 경우 50%, 연한 배경 색조의 경우 85%입니다. 결과는 무작위가 아닌 디자인된 것처럼 보입니다.

2. 배송 전 대비를 확인하세요.

밝은 배경의 밝은 텍스트는 웹에서 가장 흔한 접근성 오류입니다. 견본을 사용하여 한눈에 판단하고, 연한 색상에 어두운 텍스트를, 포화된 어두운 색상에 흰색 텍스트를 선호합니다.

3. 스크린샷의 색상 수정

색상 선택기는 종종 RGB 값을 보고합니다. 스타일시트의 16진수 코드를 얻으려면 여기에 붙여넣거나, 채널별로 추측하지 않고 셰이드를 미세 조정하려면 HSL 값을 얻으세요.

정밀도에 대한 마지막 참고 사항: RGB와 HSL 간 변환에는 반올림이 포함됩니다. 여기서 HSL 백분율은 정수이고 RGB 채널은 정수이기 때문입니다. 색상을 HSL로 변환하고 그 반대로 변환하면 채널이 한 단위씩 이동할 수 있습니다. 이는 눈에 보이지 않으며 모든 변환기에서 정상입니다. 인쇄를 위해 픽셀 단위까지 완벽한 재현이 필요한 경우 원본 16진수 또는 RGB 값을 마스터 복사본으로 유지하세요. 여기에 있는 모든 내용은 브라우저에서 비공개로 실행되므로 브랜드 색상과 팔레트가 업로드되거나 저장되지 않습니다.

자주 묻는 질문(FAQ)

HEX 색상 코드란 무엇입니까?
HEX 코드는 RGB 값에 대한 6자리 16진수 약칭으로, 순수한 빨간색을 나타내는 #FF0000과 같이 선행 해시로 작성됩니다. 각 숫자 쌍은 빨간색, 녹색, 파란색을 나타내며 00(없음)부터 FF(전체 또는 255)까지입니다. F00과 같은 세 자리 코드는 각 자릿수를 두 배로 늘려 FF0000으로 만든 약어입니다.
HEX를 RGB로 어떻게 변환합니까?
6개의 16진수를 3개의 쌍으로 나누고 각 쌍을 16진수에서 10진수로 변환합니다. #2563EB의 경우 25는 37이 되고, 63은 99가 되고, EB는 235가 되어 rgb(37, 99, 235)가 됩니다. 이 변환기는 어느 방향으로든 해당 연산을 수행합니다.
HSL에서 H, S, L은 무엇을 의미하나요?
H는 색상환의 0~360도 위치를 의미하며, 0은 빨간색, 120은 녹색, 240은 파란색입니다. S는 채도(0% 회색부터 100% 완전 선명함)를 나타냅니다. L은 0% 검정색부터 50% 순색, 100% 흰색까지의 밝기입니다.
앞뒤로 변환하면 값이 1씩 변경되는 이유는 무엇입니까?
HSL 백분율은 여기에서 정수로 반올림되었으며 RGB 채널은 정수이므로 왕복으로 인해 채널이 한 단위씩 이동할 수 있습니다. 그 차이는 눈에 보이지 않습니다. 픽셀 단위까지 완벽한 작업을 위해 원본 HEX 또는 RGB 값을 마스터 복사본으로 유지하세요.
인쇄 색상에 이 변환기를 사용할 수 있습니까?
화면 디자인의 경우 그렇습니다. 인쇄는 빛이 아닌 잉크를 기반으로 하는 다른 모델인 CMYK를 사용하므로 인쇄용으로 변환된 화면 색상이 종이에서는 다르게 보입니다. 항상 프린터의 CMYK 값으로 인쇄 색상을 교정하십시오.
내 색상 데이터가 저장되나요?
아니요. 모든 전환은 브라우저에서 실행됩니다. 입력한 내용은 서버로 전송되거나 저장되지 않습니다.
