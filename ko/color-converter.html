색상 변환기 사용 방법

디자이너, 개발자, 인쇄업자는 모두 같은 색상을 서로 다른 언어로 설명합니다. 웹 개발자는 #2563EB라고 쓰고, 인쇄 디자이너는 청록색과 자홍색의 백분율로 생각하며, 밝기를 조정하는 CSS 작성자는 HSL을 찾습니다. 이런 형식 사이를 손으로 변환하는 것은 느리고 오류가 나기 쉬우며, 특히 HSL 뒤에 있는 수학 때문에 그렇습니다. 이 변환기는 즉시 변환합니다. 어느 한 형식으로 색상을 입력하면 세 형식을 한 번에 볼 수 있고, 실시간 견본으로 숫자뿐만 아니라 눈으로도 결과를 판단할 수 있습니다.

  1. HEX에서 시작하기# 포함 여부와 관계없이 HEX 코드를 입력하세요. 예를 들어 #FF0000이나 2563EB입니다. 'HEX에서 변환'을 누르세요. F00 같은 세 자리 줄임말도 동작하며 FF0000으로 확장됩니다.
  2. 또는 RGB에서 시작하기빨간색, 초록색, 파란색 채널을 각각 0에서 255 사이로 입력하고 'RGB에서 변환'을 누르세요. 디자인 도구나 스크린샷 색상 선택기가 RGB 값을 제공할 때 유용합니다.
  3. 또는 HSL에서 시작하기색상을 0에서 360도 사이로 입력하고, 채도와 명도를 백분율로 입력한 뒤 'HSL에서 변환'을 누르세요. HSL은 색상의 더 밝거나 더 어두운 버전을 만드는 데 가장 쉬운 형식입니다.
  4. 필요한 부분 복사하기변환된 값은 바로 복사할 수 있는 CSS와 함께 아래에 나타납니다. 미리보기 견본은 어떤 입력에서도 업데이트되므로, 자유롭게 실험하며 색상이 바뀌는 것을 지켜볼 수 있습니다.

HEX, RGB, HSL 설명

HEX는 웹에서 RGB를 줄여 쓰는 방식입니다. 16진수 숫자 두 자리씩이 하나의 채널을 나타냅니다. 첫 번째 쌍은 빨간색, 두 번째는 초록색, 세 번째는 파란색입니다. 따라서 FF0000은 순수한 빨간색, 00FF00은 순수한 초록색, 000000은 검은색, FFFFFF는 흰색입니다. 십육진법은 0부터 9까지의 숫자에 A부터 F까지의 문자를 더해 쓰는데, A는 10, F는 15를 뜻합니다. 그래서 16진수 두 자리로 0부터 255까지의 모든 값을 나타낼 수 있습니다. 세 자리 줄임말은 각 자리를 단순히 두 배로 늘린 것으로, F00은 FF0000이 되고 369는 336699가 됩니다.

RGB는 색상을 빛으로 설명합니다. 빨간색, 초록색, 파란색 빛을 얼마나 섞을 것인지입니다. 화면은 빛을 내뿜으므로, 세 채널을 모두 최대로 더하면 흰색이 되고, 모두 끄면 검은색이 됩니다. 이 가산 모델은 화면에는 직관적이지만, 색상을 조정하려는 사람에게는 어색합니다. 밝기를 바꾸려면 세 숫자를 한 번에 바꿔야 하기 때문입니다. HSL은 색상을 사람이 생각하는 방식으로 설명해 이를 해결합니다. 색상은 색상환상의 위치를 도 단위로 나타낸 것으로, 0은 빨간색, 120은 초록색, 240은 파란색입니다. 채도는 색상이 얼마나 생생한지를 나타내며, 0%의 회색에서 100%의 완전한 색까지입니다. 명도는 0%의 검은색에서 50%의 순수한 색을 거쳐 100%의 흰색까지 이어집니다.

HEX #RRGGBB = RGB (red, green, blue), each 0-255
HSL(색상 0~360, 채도 0~100%, 명도 0~100%)
예시: 순수한 빨간색은 #FF0000 = rgb(255, 0, 0) = hsl(0, 100%, 50%)입니다. 순수한 초록색은 #00FF00 = rgb(0, 255, 0) = hsl(120, 100%, 50%)입니다. 회색은 어떤 색상에서도 채도가 0%입니다.

실용적인 용도와 접근성 팁

가장 흔한 변환 작업은 브랜드 색상을 도구 사이에서 옮기는 것입니다. 로고 파일은 HEX 코드를 제공할 수 있고, 개발자의 스타일시트는 rgba(37, 99, 235, 0.5) 같은 투명 효과를 위해 RGB가 필요하며, 호버 상태를 만드는 디자이너는 같은 색상을 명도를 10포인트 올려 밝게 하기 위해 HSL이 필요합니다. 여기서 이 단계를 수행하면 하나의 원본이 유지됩니다. 브랜드 색상을 한 번만 입력하면, 수동으로 다시 입력하고 반올림 오류로 흐트러지는 대신 모든 형식이 일관되게 유지됩니다.

1. 하나의 색상에서 팔레트 만들기

HSL의 주 색상에서 시작해, 색상은 고정하고 명도를 바꾸세요. 어두운 텍스트는 30%, 주 색상은 50%, 옅은 배경 색조는 85%입니다. 결과는 무작위가 아니라 디자인된 것처럼 보입니다.

2. 공개하기 전에 대비 확인하기

밝은 배경에 밝은 텍스트는 웹에서 가장 흔한 접근성 실패입니다. 견본으로 한눈에 판단하고, 옅은 색상에는 어두운 텍스트를, 채도가 높은 어두운 색상에는 흰색 텍스트를 선호하세요.

3. 스크린샷에서 색상 바로잡기

색상 선택 도구는 보통 RGB 값을 보고합니다. 여기에 붙여넣으면 스타일시트용 HEX 코드를 얻거나, 채널마다 추측하지 않고 색조를 미세 조정할 수 있는 HSL 값을 얻을 수 있습니다.

정밀도에 대한 마지막 참고입니다. RGB와 HSL 사이의 변환에는 반올림이 따릅니다. 여기서는 HSL 백분율이 정수이고 RGB 채널도 정수이기 때문입니다. 색상을 HSL로 바꿨다가 다시 되돌리면 한 채널이 1만큼 달라질 수 있는데, 눈으로는 보이지 않고 모든 변환기에서 정상적인 현상입니다. 인쇄용으로 픽셀 단위까지 정확하게 재현해야 한다면 원래의 HEX나 RGB 값을 원본으로 보관하세요. 모든 처리는 브라우저에서 비공개로 이루어지므로, 브랜드 색상과 팔레트가 업로드되거나 저장되는 일은 없습니다.

자주 묻는 질문(FAQ)

HEX 색상 코드란 무엇인가?
HEX 코드는 RGB 값을 여섯 자리 16진수로 줄여 쓴 것으로, 앞에 #을 붙입니다. 예를 들어 순수한 빨간색은 #FF0000입니다. 두 자리씩 나눈 각 쌍은 빨간색, 초록색, 파란색을 나타내며, 00(없음)에서 FF(최대, 즉 255)까지의 값을 가집니다. F00 같은 세 자리 코드는 각 자리를 두 배로 늘린 줄임말로, FF0000이 됩니다.
HEX를 RGB로 어떻게 변환하나요?
6자리 16진수를 세 쌍으로 나누고 각 쌍을 16진법에서 10진법으로 변환하세요. #2563EB의 경우 25는 37이 되고, 63은 99가 되며, EB는 235가 되어 rgb(37, 99, 235)가 됩니다. 이 변환기는 어느 방향으로든 그 계산을 대신해줍니다.
HSL에서 H, S, L은 무엇을 뜻하는가?
H는 0에서 360도 사이의 색상환에서의 위치인 색상으로, 0은 빨간색, 120은 초록색, 240은 파란색입니다. S는 채도로, 0%의 회색에서 100%의 완전히 생생한 색까지입니다. L은 명도로, 0%의 검은색에서 50%의 순수한 색을 거쳐 100%의 흰색까지입니다.
왕복 변환이 값을 1만큼 바꾸는 이유는?
여기서는 HSL 백분율이 정수로 반올림되고 RGB 채널도 정수이므로, 왕복 변환 시 한 채널이 1만큼 달라질 수 있습니다. 그 차이는 눈으로 보이지 않습니다. 픽셀 단위까지 정확한 작업을 위해 원래의 HEX나 RGB 값을 원본으로 보관하세요.
이 변환기를 인쇄 색상에 사용할 수 있나요?
화면 디자인에는 그렇습니다. 인쇄는 빛이 아니라 잉크를 기반으로 하는 다른 모델인 CMYK를 사용하므로, 인쇄용으로 변환된 화면 색상은 종이에서 다르게 보입니다. 인쇄 색상은 항상 프린터의 CMYK 값으로 교정하세요.
내 색상 데이터가 저장되나요?
아니요. 모든 변환은 브라우저에서 이루어집니다. 입력한 내용이 서버로 전송되거나 저장되지 않습니다.
