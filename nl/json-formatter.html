Wat JSON is en waarom opmaak belangrijk is

JSON, een afkorting van JavaScript Object Notation, is de meest gebruikelijke manier waarop computers gestructureerde gegevens op internet uitwisselen. API's, configuratiebestanden en veel apps spreken allemaal JSON omdat het eenvoudig te lezen is en door machines gemakkelijk kan worden geparseerd. Een geldig JSON-document is opgebouwd uit objecten tussen accolades, arrays tussen vierkante haakjes, tekenreeksen tussen dubbele aanhalingstekens, getallen en de waarden true, false en null. Het formatteren verandert niet wat de gegevens betekenen, maar wel hoe gemakkelijk het voor een mens is om te lezen. Geminimaliseerde JSON, waarbij alle spaties zijn verwijderd, is kleiner en kan sneller over een netwerk worden verzonden. Daarom gebruiken API's het, maar het is bijna onmogelijk om te lezen of fouten op te sporen. Verfraaide JSON, met inspringing van twee spaties en één waarde per regel, is groter, maar laat je binnen enkele seconden een ontbrekende komma of een verkeerd haakje zien.

De meest voorkomende JSON-fouten

  • Ontbrekende of extra komma's: elk item in een object of array, behalve de laatste, heeft een komma nodig, en een volgkomma na het laatste item is niet toegestaan ​​in strikte JSON.
  • Enkele aanhalingstekens in plaats van dubbele aanhalingstekens: JSON-tekenreeksen moeten dubbele aanhalingstekens gebruiken, ook al staat JavaScript-code vaak enkele aanhalingstekens toe.
  • Sleutels zonder aanhalingstekens: objectsleutels moeten tekenreeksen tussen aanhalingstekens zijn, dus {naam: "Ana"} is ongeldig en moet {"naam": "Ana"} zijn.
  • Opmerkingen: JSON staat geen opmerkingen toe, dus regels die beginnen met // zullen het parseren verbreken, zelfs als ze er onschadelijk uitzien.
  • Achterliggende tekst of meerdere documenten: het achter elkaar plakken van twee JSON-objecten is ongeldig; wikkel ze in een array of repareer ze één voor één.

Opmaak versus verkleinen: wanneer moet u ze gebruiken?

Gebruik Format wanneer u JSON leest, debugt of ervan leert, omdat inspringen de structuur in één oogopslag onthult en nesten duidelijk maakt. Gebruik Minify wanneer u JSON in een URL, een compact configuratieveld, een testverzoek of een bericht moet plakken waarbij de grootte ertoe doet en de leesbaarheid niet. Gebruik Validate Only als u alleen een ja-of-nee-antwoord nodig heeft, bijvoorbeeld voordat u een configuratiebestand opslaat, omdat het de JSON controleert zonder uw originele tekst te vervangen. In alle drie de gevallen parseert de tool eerst de JSON, zodat een verkleind of opgemaakt resultaat gegarandeerd geldig is; als het parseren mislukt, krijg je een foutmelding in plaats van een stilzwijgend afgebroken uitvoer, wat precies is wat je wilt voordat je de code verzendt.

Privacy en grenzen

Deze formatter draait volledig in uw browser. Je JSON wordt nooit geüpload, gelogd of gedeeld, wat belangrijk is omdat JSON vaak API-sleutels, persoonlijke gegevens of interne configuratie bevat. Plak nooit geheimen in een online formatter die u niet vertrouwt, en draai de sleutel die u per ongeluk blootlegt. De tool kan typische API-reacties en configuratiebestanden gemakkelijk verwerken, maar extreem grote documenten, tientallen megabytes, kunnen traag zijn in een browsertabblad, omdat het parseren en opnieuw stringificeren ervan geheugen kost. Het volgt ook strikte JSON-regels, dus het zal JavaScript-achtige extra's zoals volgkomma's, enkele aanhalingstekens en opmerkingen afwijzen, ook al accepteren sommige tools deze losjes.

Veelgestelde vragen (FAQ's)

Wat is het verschil tussen formatteren en verkleinen?
Opmaak voegt inspringing en regeleinden toe, zodat JSON gemakkelijk te lezen is voor mensen. Minify verwijdert alle onnodige spaties en regeleinden, zodat JSON zo klein mogelijk is voor verzending of opslag.
Waarom mislukt mijn JSON met een volgkommafout?
Strikte JSON staat geen komma toe na het laatste item in een object of array. Verwijder die laatste komma en de JSON zal parseren.
Kan ik enkele aanhalingstekens gebruiken in JSON?
Nee. JSON-tekenreeksen en -sleutels moeten dubbele aanhalingstekens gebruiken. Enkele aanhalingstekens werken in JavaScript-code, maar zijn geen geldige JSON en deze tool zal ze correct afwijzen.
Worden mijn JSON-gegevens ergens opgeslagen of verzonden?
Nee. Het formatteren en valideren gebeurt volledig in uw browser, zodat uw gegevens uw apparaat nooit verlaten.
Verandert het formatteren mijn gegevens?
Nee. Door opmaak en verkleining worden alleen de spatiëring en regeleinden gewijzigd. De waarden, sleutels en structuur blijven precies hetzelfde, zolang de JSON in het begin geldig was.
