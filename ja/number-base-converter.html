数値基数変換ツールの使い方

コンピューター、プログラマー、電子工学エンジニアは、ハードウェアのための2進数、古いシステムやファイルパーミッションのための8進数、日常の計算のための10進数、2進数のコンパクトな省略形としての16進数といった数値の基数を絶えず切り替えています。この変換ツールは、4つの基数のいずれかでの数値を受け取り、4つの値をすべて瞬時に一度に表示するため、2度変換したり、選んだ基数で数字が有効かどうか悩んだりする必要がありません。

  1. 数値を入力する最初のボックスに値を入力します。たとえば、255、1010、FFです。非負の整数のみです。符号や小数点はこれらの整数基数の一部ではありません。
  2. 変換ツールにどの基数であるかを伝えるドロップダウンから2進数、8進数、10進数、16進数を選びます。これは重要です。1010は2進数では10を意味しますが、10進数では1010を意味します。
  3. 「変換」を押して4つの結果をすべて読む2進数、8進数、10進数、16進数の値が一緒に表示され、10進数値が強調されるため、コードや宿題に必要な形式をコピーできます。
  4. エラーが表示されたら、数字を確認する各基数では特定の数字しか許可されていません。2進数は0と1のみが許可されるため、102は拒否されます。8進数は0から7が許可されるため、89は拒否されます。16進数は0から9とAからFが許可されるため、Gは拒否されます。

数値の基数とは何か、なぜ複数あるのか?

数値の基数(ラディックスとも呼ばれます)とは、単に、数え方のシステムが新しい位に繰り上がる前に使う異なる数字の数のことです。子供の頃に学ぶ10進法は、人間には指が10本あるため、10個の数字(0から9)を使います。各位は右隣の位の10倍の価値があります。255では、数字は2つの100 + 5つの10 + 5つの1を意味します。2進法は、コンピューターのハードウェアがオフかオンかのスイッチから構築されているため、0と1の2つの数字だけを使います。各2進位は右隣の位の2倍の価値があるため、1010は8 + 0 + 2 + 0 = 10を意味します。8進法は8個の数字(0から7)を使い、16進法は16個を使います。0から9に加え、10から15の値のための文字AからFです。

16進数は、主に人間が2進数を読むための便宜として存在します。1つの16進数字は正確に4つの2進数字に対応するため、11111111のような長い2進文字列はきれいにFFにまとまります。そのため、コンピューティングのあらゆる場所で16進数を見かけます。#FF5733のようなWeb上のカラーコードは、実際には赤、緑、青のための3つの16進バイトです。メモリアドレスは16進数で表示され、ネットワークエンジニアはデバイスアドレスを16進数で読みます。8進数は初期のコンピューティングで似た役割を果たしました。マシンのワードサイズが3ビットで割り切れた時代のことです。現在でもUnixのファイルパーミッションに現れ、755のような値は所有者、グループ、その他に対する読み取り、書き込み、実行の権限をエンコードしています。

手計算による変換:2つの計算例

2進数を10進数に手で変換することは、位取りの考えをどんな定義よりもよく教えてくれます。101101を取り上げます。右から読むと、位の価値は1、2、4、8、16、32です。右からの数字は1、0、1、1、0、1であるため、値は1 + 4 + 8 + 32 = 45です。10進数を2進数に変換するのは逆の手順です。2で繰り返し割り、余りを記録します。45の場合、余りは1、0、1、1、0、1であり、逆向きに読むと101101となり、最初の変換が確認されます。16進数も16の累乗で同じように機能します。1A3は1 × 256に、A(10) × 16に、3を加えたもので、256 + 160 + 3 = 419です。

10進数を経由せずに2進数、8進数、16進数を結ぶ手早い近道があります。8進数の場合は右から3つずつ、16進数の場合は4つずつ2進数字をグループ化し、各グループを変換します。たとえば、101011110は8進グループでは101 011 110となり、これは5 3 6であり、16進グループでは1 0101 1110となり、これは1 5 Eであるため、値は8進数で536、16進数で15Eとなります。学生はここで2つの間違いをよく犯します。左端のグループに先行ゼロを埋めるのを忘れることと、右ではなく左からグループを読むことです。どちらも答えを変えるため、常に右端の数字からグループ化を始めましょう。

実用的なヒントとよくある間違い

まず、あいまいになりうる数値を共有するときは、常に基数を明記します。1010だけを書いても、10を意味するのか1010を意味するのか誰にもわかりません。そのため、プログラマーは2進数には0b1010、16進数には0xFFといった接頭辞を書きます。次に、先行ゼロは値を変えないことを覚えておきます。2進数の0001010は依然として10です。先行ゼロは、8ビットといったきりの良い幅に数値を揃えるためだけに追加されることがよくあります。第三に、この変換ツールは整数のみを扱います。他の基数での分数、負の数、64桁を超える極めて長い入力は対象外であり、変換ツールは推測するのではなく、その旨を伝えます。最後に、すべてはブラウザ内で動作し、データはどこにも送信されないため、宿題の答え、コードの定数、パーミッション値をプライベートに、何度でも変換できます。

よくある質問 (FAQ)

255は2進数、8進数、16進数では何ですか?
255は、2進数では11111111、8進数では377、16進数ではFFです。4つの形式はすべて同じ値を表します。変わるのは数え方のシステムだけです。
2進数の102がエラーになるのはなぜですか?
2進法は0と1の数字しか使わないため、数字2は基数2では無効です。10進数の102を意味していた場合は、まず入力基数として10進数を選んでください。
16進数の文字AからFとは何ですか?
16進法は16個の数字を必要としますが、数字は10個しかないため、文字AからFが10、11、12、13、14、15の値を表します。そのため、FFは15 × 16 + 15、つまり255を意味します。
2進数を16進数に素早く変換するにはどうすればいいですか?
2進数字を右から4つずつグループ化し、左端のグループにゼロを埋めてから、4つの各グループを1つの16進数字に変換します。たとえば、11111111は1111 1111とグループ化され、これはF Fとなります。
この変換ツールは負の数や分数を扱えますか?
いいえ。64桁までの非負の整数全体を変換します。負の数や他の基数での分数は、2の補数や小数点といった異なる表現が必要であり、このツールではカバーしていません。
