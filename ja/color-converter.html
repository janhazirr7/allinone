カラーコンバーターの使用方法

デザイナー、開発者、印刷者は皆、同じ色を異なる言語で説明します。 Web 開発者は #2563EB を作成し、印刷デザイナーはシアンとマゼンタの割合を考え、明るさを調整する CSS 作成者は HSL に手を伸ばします。これらの形式間の変換を手作業で行うと、特に HSL の背後にある数学を使用する場合、時間がかかり、エラーが発生しやすくなります。このコンバーターはそれを即座に実行します。いずれかの形式で色を入力すると、ライブ スウォッチで 3 つすべてが一度に表示されるため、数値だけでなく目で結果を判断できます。

  1. 16 進数から開始#FF0000 や 2563EB など、ハッシュの有無にかかわらず 16 進コードを入力し、「16 進数から変換」を押します。 F00 のような 3 桁の短縮表記も機能し、FF0000 まで拡張されます。
  2. または RGB から開始します赤、緑、青のチャンネルをそれぞれ 0 ～ 255 の範囲で入力し、[RGB から変換] を押します。これは、デザイン ツールまたはスクリーンショット ピッカーが RGB 値を提供する場合に便利です。
  3. または HSL から開始します0 ～ 360 度の色相、彩度と明度をパーセンテージで入力し、[HSL から変換] を押します。 HSL は、色の明るいバージョンまたは暗いバージョンを作成するための最も簡単な形式です。
  4. 必要なものをコピーする変換された値は、コピー可能な CSS とともに以下に表示されます。プレビュー スウォッチはあらゆる入力から更新されるため、自由に実験して色の変化を観察できます。

HEX、RGB、HSL の説明

HEX は、Web における RGB の短縮形です。 16 進数の各ペアは 1 つのチャネルを表します。最初のペアは赤、2 番目は緑、3 番目は青です。したがって、FF0000 は純粋な赤、00FF00 は純粋な緑、000000 は黒であり、FFFFFF は白です。 16 進数では、0 ～ 9 の数字と A ～ F の文字が使用されます。A は 10 を意味し、F は 15 を意味します。これが、2 つの 16 進数で 0 ～ 255 のすべての値を表すことができる理由です。3 桁の短縮表記は各桁を単純に 2 倍にするため、F00 は FF0000 になり、369 は 336699 になります。

RGB は色を光として表し、赤、緑、青の光をどれだけ混ぜるかを表します。画面は光を発するため、3 つのチャネルをすべて最大強度で追加すると白が生成され、すべてをオフにすると黒が生成されます。この加算モデルは画面にとっては直感的ですが、明るさを変更することは 3 つの数値すべてを一度に変更することを意味するため、色を調整しようとする人間にとっては厄介です。 HSL は、人々が色について考える方法で色を記述することで、この問題を解決します。色相は、カラー ホイールの周囲の位置を度単位で表し、0 が赤、120 が緑、240 が青です。彩度は、0% のグレーから 100% のフルカラーまでの色の鮮やかさです。明度は 0% の黒から 50% の純粋な色、100% の白まで続きます。

HEX #RRGGBB = RGB (赤、緑、青)、それぞれ 0 ～ 255
HSL (色相 0 ～ 360、彩度 0 ～ 100%、明度 0 ～ 100%)
例: 純粋な赤は #FF0000 = rgb(255, 0, 0) = hsl(0, 100%, 50%) です。純粋な緑は #00FF00 = rgb(0, 255, 0) = hsl(120, 100%, 50%) です。グレーはどの色相でも彩度が 0% です。

実用的な使い方とアクセシビリティのヒント

最も一般的な変換タスクは、ツール間でブランド カラーを移動することです。ロゴ ファイルには 16 進数のコードが含まれる場合があり、開発者のスタイルシートには rgba(37, 99, 235, 0.5) のような透明効果を得るために RGB が必要で、ホバー状態を作成するデザイナーには明度を 10 ポイント上げて同じ色を明るくする HSL が必要です。ここでこれらの手順を実行すると、信頼できる情報源が 1 つ確保されます。つまり、ブランド カラーを 1 回入力すると、手動による再入力や丸めエラーによって変動することなく、すべての形式が一貫性を保ちます。

1. 1 つの色からパレットを作成する

HSL のメインカラーから始めて、色相を固定したまま、明度を変化させます。暗いテキストの場合は 30%、メインカラーの場合は 50%、淡い背景の色合いの場合は 85% となります。結果はランダムではなく、設計されたように見えます。

2.出荷前にコントラストを確認してください

明るい背景に明るいテキストが表示されるのは、Web 上で最も一般的なアクセシビリティの問題です。見本を使用して一目で判断し、淡い色には濃い色のテキストを、飽和した暗い色には白いテキストを優先します。

3. スクリーンショットから色を修正する

カラー ピッカーは RGB 値を報告することがよくあります。これらをここに貼り付けて、スタイルシートの 16 進コードを取得するか、チャネルごとに推測せずにシェードを微調整するための HSL 値を取得します。

精度に関する最後の注意: RGB と HSL の間の変換には丸めが含まれます。これは、ここでは HSL パーセンテージが整数であるのに対し、RGB チャネルは整数であるためです。カラーを HSL に変換して逆に変換すると、チャネルが 1 単位だけシフトする場合がありますが、これは目には見えず、どのコンバータでも正常です。印刷用にピクセル完璧な再現が必要な場合は、元の 16 進値または RGB 値をマスター コピーとして保存してください。ここにあるものはすべてブラウザ内で非公開で実行されるため、ブランドのカラーやパレットがアップロードされたり保存されたりすることはありません。

よくある質問 (FAQ)

HEXカラーコードとは何ですか?
HEX コードは、RGB 値の 6 桁の 16 進数の短縮形であり、純粋な赤を表す #FF0000 のように、先頭にハッシュを付けて記述されます。数字の各ペアは、00 (なし) から FF (フル、または 255) までの赤、緑、青を表します。 F00 のような 3 桁のコードは、各桁を 2 倍して FF0000 にする短縮形です。
HEX を RGB に変換するにはどうすればよいですか?
6 つの 16 進数を 3 つのペアに分割し、各ペアを 16 進数から 10 進数に変換します。 #2563EB の場合、25 は 37 になり、63 は 99 になり、EB は 235 になり、rgb(37, 99, 235) になります。このコンバータは、どちらの方向でもその演算を実行します。
HSL の H、S、L は何を意味しますか?
H は色相、カラー ホイール上の 0 ～ 360 度の位置で、0 は赤、120 は緑、240 は青です。 S は彩度で、0% グレーから 100% 完全に鮮やかな値までです。 L は、0% 黒から 50% 純色、100% 白までの明度です。
前後に変換すると値が 1 ずつ変化するのはなぜですか?
ここでは、HSL パーセンテージは整数に四捨五入されており、RGB チャネルは整数であるため、往復によりチャネルが 1 単位シフトされる可能性があります。違いは目には見えません。ピクセル完璧な作業のため、元の HEX または RGB 値をマスター コピーとして保持します。
このコンバーターを印刷カラーに使用できますか?
画面デザインに関してはそうですね。印刷では、光ではなくインクに基づいた異なるモデルである CMYK が使用されるため、印刷用に変換されたスクリーン カラーは紙上では異なって見えます。印刷カラーは必ずプリンターの CMYK 値で校正してください。
私のカラーデータは保存されていますか?
いいえ。すべての変換はブラウザーで実行されます。入力した内容はサーバーに送信されたり、保存されたりすることはありません。
