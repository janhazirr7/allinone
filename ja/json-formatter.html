JSON フォーマッタの使用方法

  1. JSON を貼り付けますAPI、構成ファイル、またはチュートリアルから JSON をコピーし、大きなボックスに貼り付けます。
  2. アクションを選択してくださいインデントを付けて読みやすくするには「フォーマット」を押し、1 行に縮小するには「縮小」を押し、変更せずに確認するには「検証のみ」を押します。
  3. エラーがある場合はそれを読みますJSON が無効な場合、ツールはパーサーからの正確なエラーを平易な言葉で表示するため、何を修正すべきかがわかります。
  4. 結果をコピーする出力のコピーを使用して、フォーマットまたは縮小された JSON をコード、構成、または API ツールに戻します。

JSON とは何か、そしてなぜ書式設定が重要なのか

JSON (JavaScript Object Notation の略) は、コンピューターが Web 上で構造化データを交換する最も一般的な方法です。 API、構成ファイル、および多くのアプリはすべて、JSON を使用します。これは、JSON が読みやすく、マシンが解析しやすいためです。有効な JSON ドキュメントは、中括弧で囲まれたオブジェクト、角括弧で囲まれた配列、二重引用符で囲まれた文字列、数値、および値 true、false、null から構築されます。書式設定によってデータの意味は変わりませんが、人間にとっての読みやすさは変わります。すべてのスペースが削除された縮小された JSON は、サイズが小さく、ネットワーク経由で送信するのが速いため、API で使用されますが、読み取りやデバッグはほとんど不可能です。 2 つのスペースのインデントと 1 行あたり 1 つの値を備えた美しい JSON はサイズが大きくなりますが、欠落しているカンマや間違った括弧を数秒で見つけることができます。

最も一般的な JSON エラー

  • カンマの欠落または余分: オブジェクトまたは配列内の最後の項目を除くすべての項目にはカンマが必要ですが、厳密な JSON では最後の項目の後の末尾のカンマは許可されません。
  • 二重引用符の代わりに一重引用符を使用する: JavaScript コードでは一重引用符が許可される場合が多いですが、JSON 文字列では二重引用符を使用する必要があります。
  • 引用符で囲まれていないキー: オブジェクト キーは引用符で囲まれた文字列である必要があるため、{name: "Ana"} は無効であり、{"name": "Ana"} である必要があります。
  • コメント: JSON ではコメントが許可されていないため、// で始まる行は、一見無害に見えても解析が中断されます。
  • 末尾のテキストまたは複数のドキュメント: 2 つの JSON オブジェクトを続けて貼り付けることは無効です。それらを配列でラップするか、一度に 1 つずつ修正します。

フォーマットと縮小: それぞれをいつ使用するか

JSON の読み取り、デバッグ、学習を行う場合は、Format を使用します。これは、インデントによって構造が一目でわかり、ネストが明確になるためです。サイズが重要で読みやすさは重要ではない URL、コンパクトな構成フィールド、テスト リクエスト、またはメッセージに JSON を貼り付ける必要がある場合は、Minify を使用します。 Validate Only は、元のテキストを置換せずに JSON をチェックするため、構成ファイルを保存する前など、はいまたはいいえの回答のみが必要な場合に使用します。 3 つのケースすべてにおいて、ツールは最初に JSON を解析するため、縮小またはフォーマットされた結果が有効であることが保証されます。解析が失敗すると、出力が壊れる代わりにエラーが表示されます。これは、コードを出荷する前に望んでいることです。

プライバシーと制限

このフォーマッタは完全にブラウザ内で実行されます。 JSON はアップロード、記録、共有されることはありません。JSON には API キー、個人データ、内部設定が含まれることが多いため、これは重要です。信頼できないオンライン フォーマッタにシークレットを貼り付けたり、誤って公開したキーをローテーションしたりしないでください。このツールは一般的な API 応答と構成ファイルを簡単に処理しますが、数十メガバイトの非常に大きなドキュメントは、解析と再文字列化にメモリが必要となるため、ブラウザー タブでは遅くなる可能性があります。また、厳密な JSON ルールに従っているため、一部のツールでは大まかに受け入れられる場合でも、末尾のカンマ、一重引用符、コメントなどの JavaScript スタイルの追加要素は拒否されます。

よくある質問 (FAQ)

フォーマットと縮小の違いは何ですか?
形式によりインデントと改行が追加されるため、人間が JSON を読みやすくなります。 Minify は不要なスペースと改行をすべて削除し、送信または保存するために JSON ができるだけ小さくなるようにします。
JSON が末尾のカンマ エラーで失敗するのはなぜですか?
厳密な JSON では、オブジェクトまたは配列内の最後の項目の後にカンマを使用することはできません。最後のカンマを削除すると、JSON が解析されます。
JSON で一重引用符を使用できますか?
いいえ。JSON 文字列とキーには二重引用符を使用する必要があります。一重引用符は JavaScript コードでは機能しますが、有効な JSON ではないため、このツールは正しく拒否します。
私の JSON データはどこかに保存または送信されますか?
いいえ。フォーマットと検証は完全にブラウザ内で実行されるため、データがデバイスから流出することはありません。
フォーマットするとデータが変更されますか?
いいえ。書式設定と縮小は、間隔と改行を変更するだけです。 JSON が最初から有効である限り、値、キー、構造はまったく同じままです。
