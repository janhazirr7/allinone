Πώς να χρησιμοποιήσετε τον κωδικοποιητή Base64

  1. Εισαγάγετε το κείμενό σαςΠληκτρολογήστε ή επικολλήστε απλό κείμενο για κωδικοποίηση, ή επικολλήστε μια συμβολοσειρά Base64 για αποκωδικοποίηση.
  2. Επιλέξτε κωδικοποίηση ή αποκωδικοποίησηΠατήστε «Κωδικοποίηση» για να μετατρέψετε κείμενο σε Base64, ή «Αποκωδικοποίηση» για να μετατρέψετε το Base64 πίσω σε αναγνώσιμο κείμενο.
  3. Ελέγξτε το σφάλμα αν υπάρχειΜη έγκυρο Base64 εμφανίζει ένα φιλικό σφάλμα που εξηγεί το πρόβλημα, αντί για ένα κενό ή αλλοιωμένο αποτέλεσμα.
  4. Αντιγράψτε το αποτέλεσμαΧρησιμοποιήστε «Αντιγραφή εξόδου» για να πάρετε το αποτέλεσμα σε ένα email, αρχείο ρυθμίσεων, αίτημα API ή μήνυμα.

Τι είναι το Base64 και γιατί υπάρχει

Το Base64 είναι ένας τρόπος να αναπαραστήσετε οποιαδήποτε bytes, συμπεριλαμβανομένων κειμένου, εικόνων και αρχείων, χρησιμοποιώντας μόνο 64 ασφαλείς χαρακτήρες: κεφαλαία και μικρά γράμματα, ψηφία, συν και κάθετο, με σύμβολα ίσον ως συμπλήρωμα στο τέλος. Οι υπολογιστές συχνά χρειάζεται να στείλουν δυαδικά δεδομένα μέσω συστημάτων που χειρίζονται με ασφάλεια μόνο απλό κείμενο, όπως επικεφαλίδες email, διευθύνσεις ιστού, πεδία JSON και αρχεία ρυθμίσεων. Τα ακατέργαστα bytes σε αυτά τα μέρη θα μπορούσαν να καταστραφούν, να διαβαστούν λάθος ή να απορριφθούν, οπότε το Base64 τα μεταφράζει σε κείμενο που επιβιώνει του ταξιδιού αμετάβλητο. Το τίμημα είναι το μέγεθος: η έξοδος Base64 είναι περίπου κατά ένα τρίτο μεγαλύτερη από τα αρχικά δεδομένα, επειδή τρία bytes γίνονται τέσσερις χαρακτήρες. Αυτό είναι αποδεκτό για tokens, μικρές εικόνες και σύντομες συμβολοσειρές, αλλά σπάταλο για πολύ μεγάλα αρχεία, γι' αυτό το Base64 δεν χρησιμοποιείται για ροή βίντεο ή μεγάλες λήψεις.

Γιατί το Unicode χρειάζεται ειδική φροντίδα

Ένα συνηθισμένο σφάλμα σε απλά εργαλεία Base64 είναι ότι σπάνε σε μη αγγλικό κείμενο. Οι παλιές συναρτήσεις browser btoa και atob χειρίζονται μόνο λατινικούς χαρακτήρες, οπότε μια λέξη όπως café, ένα όνομα στα ούρντου ή στα ελληνικά, ή ένα emoji μπορεί να παράγει σφάλμα ή σκουπίδια. Αυτό το εργαλείο αποφεύγει εντελώς αυτό το σφάλμα μετατρέποντας πρώτα το κείμενό σας σε bytes UTF-8 με έναν TextEncoder, κωδικοποιώντας αυτά τα bytes και αντιστρέφοντας τη διαδικασία με έναν TextDecoder στην αποκωδικοποίηση. Αυτό σημαίνει ότι τα Hola, Καλημέρα, مرحبا και ένα χαμογελαστό emoji κάνουν σωστά τη διαδρομή μετ' επιστροφής: κωδικοποιήστε τα, αποκωδικοποιήστε το αποτέλεσμα και παίρνετε πίσω ακριβώς το αρχικό κείμενο. Αν ένα άλλο εργαλείο σας δίνει σπασμένους χαρακτήρες για τονισμένο ή μη λατινικό κείμενο, σχεδόν σίγουρα χρησιμοποίησε σκέτο btoa και atob χωρίς χειρισμό UTF-8, και πρέπει να αλλάξετε σε ένα εργαλείο ασφαλές για Unicode όπως αυτό.

Συνηθισμένες χρήσεις και μια προειδοποίηση ασφαλείας

  • Data URLs: μικρές εικόνες και εικονίδια ενσωματώνονται συχνά απευθείας σε ιστοσελίδες ως Base64, ώστε μια σελίδα να μην χρειάζεται ξεχωριστό αρχείο εικόνας.
  • API tokens και βασική ταυτοποίηση: ονόματα χρήστη, κωδικοί και tokens κωδικοποιούνται μερικές φορές σε Base64 σε επικεφαλίδες, αλλά αυτό δεν είναι κρυπτογράφηση και πρέπει πάντα να ταξιδεύει μέσω HTTPS.
  • Συνημμένα email: τα συστήματα email κωδικοποιούν τα συνημμένα σε Base64, ώστε τα δυαδικά αρχεία να μπορούν να ταξιδέψουν μέσω διακομιστών αλληλογραφίας μόνο κειμένου.
  • Ρυθμίσεις και δοκιμές: οι προγραμματιστές κωδικοποιούν σύντομες συμβολοσειρές για να δοκιμάσουν APIs, να αποθηκεύσουν μικρά blobs σε JSON και να συγκρίνουν τιμές χωρίς να ανησυχούν για ειδικούς χαρακτήρες.

Ιδιωτικότητα και όρια

Το Base64 είναι κωδικοποίηση, όχι κρυπτογράφηση. Οποιοσδήποτε δει μια συμβολοσειρά Base64 μπορεί να την αποκωδικοποιήσει σε δευτερόλεπτα, οπότε μην το χρησιμοποιήσετε ποτέ για να κρύψετε έναν κωδικό, ένα μυστικό κλειδί ή ιδιωτικές πληροφορίες, και μην το αντιμετωπίσετε ποτέ ως ασφαλές. Αυτό το εργαλείο λειτουργεί εξ ολοκλήρου στον browser σας, οπότε το κείμενό σας δεν μεταφορτώνεται ούτε αποθηκεύεται ποτέ, αλλά η ίδια η έξοδος εξακολουθεί να είναι αναγνώσιμη από οποιονδήποτε την κοινοποιήσετε. Το εργαλείο δέχεται τυπικό Base64 και την παραλλαγή ασφαλή για URL που χρησιμοποιεί μείον και κάτω παύλα αντί για συν και κάθετο, και ανέχεται αλλαγές γραμμής και συμπλήρωμα που λείπει, πράγμα που το κάνει επιεικές με συμβολοσειρές αντιγραμμένες από email. Πολύ μεγάλες είσοδοι μπορεί να είναι αργές σε μια καρτέλα browser, οπότε για αρχεία πολλών megabyte χρησιμοποιήστε αντ' αυτού ένα εργαλείο επιφάνειας εργασίας.

Συχνές ερωτήσεις (FAQs)

Είναι το Base64 κρυπτογράφηση;
Όχι. Το Base64 είναι μόνο κωδικοποίηση, μια αναστρέψιμη αλλαγή μορφής. Οποιοσδήποτε μπορεί να αποκωδικοποιήσει μια συμβολοσειρά Base64 αμέσως, οπότε δεν πρέπει ποτέ να χρησιμοποιείται για να κρύψει κωδικούς ή μυστικά.
Γιατί το τονισμένο κείμενό μου σπάει σε ορισμένα εργαλεία Base64;
Αυτά τα εργαλεία χρησιμοποιούν σκέτο btoa και atob, που χειρίζονται μόνο λατινικούς χαρακτήρες. Αυτό το εργαλείο μετατρέπει πρώτα το κείμενο σε bytes UTF-8, οπότε τα τονισμένα γράμματα, τα ελληνικά, τα ούρντου και τα emoji λειτουργούν όλα σωστά.
Γιατί η έξοδος Base64 είναι μεγαλύτερη από το κείμενό μου;
Το Base64 μετατρέπει κάθε 3 bytes σε 4 χαρακτήρες, οπότε η έξοδος είναι περίπου 33 τοις εκατό μεγαλύτερη. Αυτό είναι το φυσιολογικό τίμημα για να γίνουν τα δυαδικά δεδομένα ασφαλή για συστήματα μόνο κειμένου.
Σε τι χρησιμεύει το σύμβολο ίσον στο τέλος;
Τα σύμβολα ίσον είναι συμπλήρωμα. Συμπληρώνουν την τελική ομάδα σε τέσσερις χαρακτήρες όταν το μήκος εισόδου δεν είναι πολλαπλάσιο του τρία, ώστε ο αποκωδικοποιητής να γνωρίζει ακριβώς πού τελειώνουν τα δεδομένα.
Αποστέλλεται το κείμενό μου σε διακομιστή;
Όχι. Η κωδικοποίηση και η αποκωδικοποίηση εκτελούνται εξ ολοκλήρου στον browser σας και τίποτα από όσα εισαγάγετε δεν φεύγει από τη συσκευή σας.
