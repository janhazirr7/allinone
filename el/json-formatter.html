Πώς να χρησιμοποιήσετε το Μορφοποιητής JSON

  1. Επικολλήστε το JSON σαςΑντιγράψτε το JSON από ένα API, ένα αρχείο διαμόρφωσης ή έναν οδηγό και επικολλήστε το στο μεγάλο πλαίσιο.
  2. Επιλέξτε μια ενέργειαΠατήστε Μορφοποίηση για να το κάνετε αναγνώσιμο με εσοχή, Ελαχιστοποίηση για να το συρρικνώσετε σε μία γραμμή ή Επικύρωση Μόνο για να το ελέγξετε χωρίς να το αλλάξετε.
  3. Διαβάστε το σφάλμα αν υπάρχειΕάν το JSON δεν είναι έγκυρο, το εργαλείο εμφανίζει το ακριβές σφάλμα από τον αναλυτή με απλά λόγια, ώστε να γνωρίζετε τι να διορθώσετε.
  4. Αντιγράψτε το αποτέλεσμαΧρησιμοποιήστε την έξοδο αντιγραφής για να επαναφέρετε το μορφοποιημένο ή ελαχιστοποιημένο JSON στον κώδικα, τη διαμόρφωση ή το εργαλείο API σας.

Τι είναι το JSON και γιατί έχει σημασία η μορφοποίηση

Το JSON, συντομογραφία για το JavaScript Object Notation, είναι ο πιο συνηθισμένος τρόπος με τον οποίο οι υπολογιστές ανταλλάσσουν δομημένα δεδομένα στον Ιστό. Τα API, τα αρχεία διαμόρφωσης και πολλές εφαρμογές μιλούν JSON επειδή είναι απλό στην ανάγνωση και εύκολη ανάλυση από τα μηχανήματα. Ένα έγκυρο έγγραφο JSON δημιουργείται από αντικείμενα σε σγουρές αγκύλες, πίνακες σε αγκύλες, συμβολοσειρές σε διπλά εισαγωγικά, αριθμούς και τις τιμές true, false και null. Η μορφοποίηση δεν αλλάζει τη σημασία των δεδομένων, αλλά αλλάζει το πόσο εύκολο είναι να διαβάσει ένας άνθρωπος. Το Minified JSON, με όλα τα κενά που έχουν αφαιρεθεί, είναι μικρότερο και ταχύτερο για αποστολή μέσω δικτύου, γι' αυτό το χρησιμοποιούν τα API, αλλά είναι σχεδόν αδύνατο να διαβαστούν ή να εντοπιστούν σφάλματα. Το Beautified JSON, με εσοχή δύο διαστημάτων και μία τιμή ανά γραμμή, είναι μεγαλύτερο, αλλά σας επιτρέπει να εντοπίσετε ένα κόμμα που λείπει ή μια λανθασμένη αγκύλη σε δευτερόλεπτα.

Τα πιο συνηθισμένα σφάλματα JSON

  • Λείπουν ή επιπλέον κόμματα: κάθε στοιχείο σε ένα αντικείμενο ή πίνακα εκτός από το τελευταίο χρειάζεται κόμμα και ένα κόμμα μετά το τελευταίο στοιχείο δεν επιτρέπεται σε αυστηρά JSON.
  • Μονά εισαγωγικά αντί για διπλά εισαγωγικά: Οι συμβολοσειρές JSON πρέπει να χρησιμοποιούν διπλά εισαγωγικά, παρόλο που ο κώδικας JavaScript συχνά επιτρέπει μεμονωμένα εισαγωγικά.
  • Κλειδιά χωρίς εισαγωγικά: τα κλειδιά αντικειμένων πρέπει να είναι συμβολοσειρές εισαγωγικών, επομένως το {name: "Ana"} δεν είναι έγκυρο και πρέπει να είναι {"name": "Ana"}.
  • Σχόλια: Το JSON δεν επιτρέπει σχόλια, επομένως οι γραμμές που ξεκινούν με // θα σπάσουν την ανάλυση ακόμα κι αν φαίνονται αβλαβείς.
  • Κείμενο που ακολουθεί ή πολλά έγγραφα: η επικόλληση δύο αντικειμένων JSON το ένα μετά το άλλο δεν είναι έγκυρη. τυλίξτε τα σε μια σειρά ή διορθώστε τα ένα-ένα.

Μορφοποίηση έναντι ελαχιστοποίησης: Πότε να χρησιμοποιείται το καθένα

Χρησιμοποιήστε το Format όταν διαβάζετε, διορθώνετε σφάλματα ή μαθαίνετε από το JSON, επειδή η εσοχή αποκαλύπτει τη δομή με μια ματιά και κάνει προφανή την ένθεση. Χρησιμοποιήστε το Minify όταν χρειάζεται να επικολλήσετε το JSON σε μια διεύθυνση URL, ένα συμπαγές πεδίο διαμόρφωσης, ένα αίτημα δοκιμής ή ένα μήνυμα όπου το μέγεθος έχει σημασία και η αναγνωσιμότητα όχι. Χρησιμοποιήστε το Validate Only όταν χρειάζεστε μόνο μια απάντηση ναι ή όχι, για παράδειγμα πριν αποθηκεύσετε ένα αρχείο διαμόρφωσης, επειδή ελέγχει το JSON χωρίς να αντικαθιστά το αρχικό σας κείμενο. Και στις τρεις περιπτώσεις το εργαλείο αναλύει πρώτα το JSON, επομένως ένα ελαχιστοποιημένο ή μορφοποιημένο αποτέλεσμα είναι εγγυημένο ότι είναι έγκυρο. Εάν η ανάλυση αποτύχει, λαμβάνετε ένα σφάλμα αντί για μια αθόρυβα σπασμένη έξοδο, το οποίο είναι ακριβώς αυτό που θέλετε πριν από τον κωδικό αποστολής.

Απόρρητο και Όρια

Αυτός ο μορφοποιητής εκτελείται εξ ολοκλήρου στο πρόγραμμα περιήγησής σας. Το JSON σας δεν μεταφορτώνεται, καταγράφεται ή κοινοποιείται ποτέ, κάτι που έχει σημασία επειδή το JSON συχνά περιέχει κλειδιά API, προσωπικά δεδομένα ή εσωτερική διαμόρφωση. Ποτέ μην επικολλάτε μυστικά σε κανένα διαδικτυακό μορφοποιητή που δεν εμπιστεύεστε και περιστρέψτε οποιοδήποτε κλειδί εκθέσετε κατά λάθος. Το εργαλείο χειρίζεται εύκολα τυπικές αποκρίσεις API και αρχεία διαμόρφωσης, αλλά τα εξαιρετικά μεγάλα έγγραφα, δεκάδες megabyte, μπορεί να είναι αργά σε μια καρτέλα του προγράμματος περιήγησης επειδή η ανάλυση και η εκ νέου αυστηροποίηση τους απαιτεί μνήμη. Ακολουθεί επίσης αυστηρούς κανόνες JSON, επομένως θα απορρίψει πρόσθετα στοιχεία τύπου JavaScript, όπως κόμματα στο τέλος, μεμονωμένα εισαγωγικά και σχόλια, παρόλο που ορισμένα εργαλεία τα αποδέχονται χαλαρά.

Συχνές Ερωτήσεις (Συχνές Ερωτήσεις)

Ποια είναι η διαφορά μεταξύ Μορφοποίησης και Ελαχιστοποίησης;
Η μορφή προσθέτει εσοχές και αλλαγές γραμμής, ώστε το JSON να είναι εύκολο να το διαβάσει ο άνθρωπος. Το Minify αφαιρεί όλα τα περιττά κενά και τις αλλαγές γραμμής, ώστε το JSON να είναι όσο το δυνατόν μικρότερο για αποστολή ή αποθήκευση.
Γιατί το JSON μου αποτυγχάνει με ένα λάθος κόμμα;
Το αυστηρό JSON δεν επιτρέπει κόμμα μετά το τελευταίο στοιχείο σε ένα αντικείμενο ή πίνακα. Αφαιρέστε αυτό το τελικό κόμμα και το JSON θα αναλύσει.
Μπορώ να χρησιμοποιήσω μεμονωμένα εισαγωγικά σε JSON;
Όχι. Οι συμβολοσειρές και τα κλειδιά JSON πρέπει να χρησιμοποιούν διπλά εισαγωγικά. Τα μεμονωμένα εισαγωγικά λειτουργούν σε κώδικα JavaScript, αλλά δεν είναι έγκυρα JSON και αυτό το εργαλείο θα τα απορρίψει σωστά.
Τα δεδομένα JSON μου αποθηκεύονται ή αποστέλλονται οπουδήποτε;
Όχι. Η μορφοποίηση και η επικύρωση εκτελούνται εξ ολοκλήρου στο πρόγραμμα περιήγησής σας, ώστε τα δεδομένα σας να μην φεύγουν ποτέ από τη συσκευή σας.
Αλλάζει η μορφοποίηση τα δεδομένα μου;
Όχι. Η μορφοποίηση και η ελαχιστοποίηση αλλάζουν μόνο το διάστημα και τις αλλαγές γραμμών. Οι τιμές, τα κλειδιά και η δομή παραμένουν ακριβώς οι ίδιες, εφόσον το JSON ήταν αρχικά έγκυρο.
