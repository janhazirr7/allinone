Πώς να χρησιμοποιήσετε τον μορφοποιητή JSON

  1. Επικολλήστε το JSON σαςΑντιγράψτε JSON από ένα API, ένα αρχείο ρυθμίσεων ή έναν οδηγό και επικολλήστε το στο μεγάλο κουτί.
  2. Επιλέξτε μια ενέργειαΠατήστε Μορφοποίηση για να το κάνετε ευανάγνωστο με εσοχές, Συμπύκνωση για να το συρρικνώσετε σε μία γραμμή, ή Μόνο επικύρωση για να το ελέγξετε χωρίς να το αλλάξετε.
  3. Διαβάστε το σφάλμα αν υπάρχειΑν το JSON είναι μη έγκυρο, το εργαλείο δείχνει το ακριβές σφάλμα από τον αναλυτή με απλά λόγια, ώστε να ξέρετε τι να διορθώσετε.
  4. Αντιγράψτε το αποτέλεσμαΧρησιμοποιήστε Αντιγραφή εξόδου για να πάρετε το μορφοποιημένο ή συμπυκνωμένο JSON πίσω στον κώδικα, τις ρυθμίσεις ή το εργαλείο API σας.

Τι είναι το JSON και γιατί έχει σημασία η μορφοποίηση

Το JSON, συντομογραφία του JavaScript Object Notation, είναι ο πιο συνηθισμένος τρόπος που οι υπολογιστές ανταλλάσσουν δομημένα δεδομένα στο διαδίκτυο. Τα API, τα αρχεία ρυθμίσεων και πολλές εφαρμογές μιλούν JSON επειδή είναι απλό στην ανάγνωση και εύκολο για τις μηχανές να το αναλύσουν. Ένα έγκυρο έγγραφο JSON χτίζεται από αντικείμενα σε άγκιστρα, πίνακες σε αγκύλες, συμβολοσειρές σε διπλά εισαγωγικά, αριθμούς και τις τιμές true, false και null. Η μορφοποίηση δεν αλλάζει τι σημαίνουν τα δεδομένα, αλλά αλλάζει πόσο εύκολο είναι για έναν άνθρωπο να τα διαβάσει. Το συμπυκνωμένο JSON, με όλα τα κενά αφαιρεμένα, είναι μικρότερο και ταχύτερο να σταλεί μέσω δικτύου, γι' αυτό το χρησιμοποιούν τα API, αλλά είναι σχεδόν αδύνατο να διαβαστεί ή να αποσφαλματωθεί. Το ομορφοποιημένο JSON, με εσοχή δύο κενών και μία τιμή ανά γραμμή, είναι μεγαλύτερο, αλλά σας επιτρέπει να εντοπίσετε ένα κόμμα που λείπει ή μια λάθος αγκύλη σε δευτερόλεπτα.

Τα πιο συνηθισμένα σφάλματα JSON

  • Κόμματα που λείπουν ή περισσεύουν: κάθε στοιχείο σε ένα αντικείμενο ή πίνακα εκτός από το τελευταίο χρειάζεται κόμμα, και ένα κόμμα στο τέλος μετά το τελευταίο στοιχείο δεν επιτρέπεται σε αυστηρό JSON.
  • Μονά εισαγωγικά αντί για διπλά: οι συμβολοσειρές JSON πρέπει να χρησιμοποιούν διπλά εισαγωγικά, παρόλο που ο κώδικας JavaScript συχνά επιτρέπει μονά εισαγωγικά.
  • Κλειδιά χωρίς εισαγωγικά: τα κλειδιά αντικειμένων πρέπει να είναι συμβολοσειρές με εισαγωγικά, οπότε το {name: "Ana"} είναι μη έγκυρο και πρέπει να είναι {"name": "Ana"}.
  • Σχόλια: το JSON δεν επιτρέπει σχόλια, οπότε γραμμές που ξεκινούν με // θα σπάσουν την ανάλυση, ακόμη κι αν φαίνονται αβλαβείς.
  • Κείμενο στο τέλος ή πολλαπλά έγγραφα: η επικόλληση δύο αντικειμένων JSON το ένα μετά το άλλο είναι μη έγκυρη· τυλίξτε τα σε έναν πίνακα ή διορθώστε τα ένα κάθε φορά.

Μορφοποίηση έναντι συμπύκνωσης: πότε να χρησιμοποιήσετε καθεμία

Χρησιμοποιήστε Μορφοποίηση όταν διαβάζετε, αποσφαλματώνετε ή μαθαίνετε από JSON, επειδή η εσοχή αποκαλύπτει τη δομή με μια ματιά και κάνει τη φωλιά εμφανή. Χρησιμοποιήστε Συμπύκνωση όταν χρειάζεται να επικολλήσετε JSON σε ένα URL, ένα συμπαγές πεδίο ρυθμίσεων, ένα δοκιμαστικό αίτημα ή ένα μήνυμα όπου το μέγεθος έχει σημασία και η αναγνωσιμότητα όχι. Χρησιμοποιήστε Μόνο επικύρωση όταν χρειάζεστε μόνο μια απάντηση ναι-ή-όχι, για παράδειγμα πριν αποθηκεύσετε ένα αρχείο ρυθμίσεων, επειδή ελέγχει το JSON χωρίς να αντικαταστήσει το αρχικό σας κείμενο. Και στις τρεις περιπτώσεις το εργαλείο πρώτα αναλύει το JSON, οπότε ένα συμπυκνωμένο ή μορφοποιημένο αποτέλεσμα είναι εγγυημένα έγκυρο· αν η ανάλυση αποτύχει, παίρνετε ένα σφάλμα αντί για μια σιωπηλά χαλασμένη έξοδο, πράγμα που είναι ακριβώς αυτό που θέλετε πριν παραδώσετε κώδικα.

Ιδιωτικότητα και όρια

Αυτός ο μορφοποιητής τρέχει εξ ολοκλήρου στον browser σας. Το JSON σας δεν ανεβαίνει, καταγράφεται ή κοινοποιείται ποτέ, πράγμα που έχει σημασία επειδή το JSON συχνά περιέχει κλειδιά API, προσωπικά δεδομένα ή εσωτερικές ρυθμίσεις. Μην επικολλάτε ποτέ μυστικά σε οποιονδήποτε διαδικτυακό μορφοποιητή δεν εμπιστεύεστε, και αλλάξτε οποιοδήποτε κλειδί εκθέσετε κατά λάθος. Το εργαλείο χειρίζεται εύκολα τυπικές αποκρίσεις API και αρχεία ρυθμίσεων, αλλά εξαιρετικά μεγάλα έγγραφα, δεκάδων megabyte, μπορεί να είναι αργά σε μια καρτέλα browser, επειδή η ανάλυση και η επαναδημιουργία συμβολοσειράς τους παίρνει μνήμη. Ακολουθεί επίσης αυστηρούς κανόνες JSON, οπότε θα απορρίψει πρόσθετα τύπου JavaScript όπως κόμματα στο τέλος, μονά εισαγωγικά και σχόλια, παρόλο που μερικά εργαλεία τα δέχονται χαλαρά.

Συχνές ερωτήσεις (FAQs)

Ποια είναι η διαφορά μεταξύ Μορφοποίησης και Συμπύκνωσης;
Η Μορφοποίηση προσθέτει εσοχές και αλλαγές γραμμής, ώστε το JSON να είναι εύκολο να διαβαστεί από ανθρώπους. Η Συμπύκνωση αφαιρεί όλα τα περιττά κενά και τις αλλαγές γραμμής, ώστε το JSON να είναι όσο το δυνατόν μικρότερο για αποστολή ή αποθήκευση.
Γιατί το JSON μου αποτυγχάνει με σφάλμα κόμματος στο τέλος;
Το αυστηρό JSON δεν επιτρέπει κόμμα μετά το τελευταίο στοιχείο σε ένα αντικείμενο ή πίνακα. Αφαιρέστε αυτό το τελικό κόμμα και το JSON θα αναλυθεί.
Μπορώ να χρησιμοποιήσω μονά εισαγωγικά σε JSON;
Όχι. Οι συμβολοσειρές και τα κλειδιά JSON πρέπει να χρησιμοποιούν διπλά εισαγωγικά. Τα μονά εισαγωγικά δουλεύουν σε κώδικα JavaScript, αλλά δεν είναι έγκυρο JSON και αυτό το εργαλείο θα τα απορρίψει σωστά.
Αποθηκεύονται ή αποστέλλονται πουθενά τα δεδομένα JSON μου;
Όχι. Η μορφοποίηση και η επικύρωση τρέχουν εξ ολοκλήρου στον browser σας, οπότε τα δεδομένα σας δεν φεύγουν ποτέ από τη συσκευή σας.
Αλλάζει η μορφοποίηση τα δεδομένα μου;
Όχι. Η μορφοποίηση και η συμπύκνωση αλλάζουν μόνο τα κενά και τις αλλαγές γραμμής. Οι τιμές, τα κλειδιά και η δομή παραμένουν ακριβώς ίδια, αρκεί το JSON να ήταν έγκυρο από την αρχή.
