วิธีใช้เครื่องจัดรูปแบบ JSON

  1. วาง JSON ของคุณคัดลอก JSON จาก API ไฟล์ตั้งค่า หรือบทช่วยสอนแล้ววางลงในช่องขนาดใหญ่
  2. เลือกการดำเนินการกดจัดรูปแบบเพื่อให้อ่านง่ายด้วยการเยื้อง ย่อขนาดเพื่อย่อให้เหลือบรรทัดเดียว หรือตรวจสอบเท่านั้นเพื่อตรวจสอบโดยไม่เปลี่ยนแปลง
  3. อ่านข้อผิดพลาดถ้ามีถ้า JSON ไม่ถูกต้อง เครื่องมือจะแสดงข้อผิดพลาดที่แน่นอนจากตัวแยกวิเคราะห์ด้วยภาษาง่ายๆ คุณจึงรู้ว่าต้องแก้อะไร
  4. คัดลอกผลลัพธ์ใช้คัดลอกผลลัพธ์เพื่อนำ JSON ที่จัดรูปแบบหรือย่อขนาดแล้วกลับไปยังโค้ด ไฟล์ตั้งค่า หรือเครื่องมือ API ของคุณ

JSON คืออะไรและทำไมการจัดรูปแบบจึงสำคัญ

JSON ย่อมาจาก JavaScript Object Notation เป็นวิธีที่พบบ่อยที่สุดที่คอมพิวเตอร์แลกเปลี่ยนข้อมูลที่มีโครงสร้างบนเว็บ API ไฟล์ตั้งค่า และแอปหลายตัวล้วนพูด JSON เพราะอ่านง่ายและเครื่องแยกวิเคราะห์ได้ง่าย เอกสาร JSON ที่ถูกต้องสร้างจากออบเจกต์ในวงเล็บปีกกา อาร์เรย์ในวงเล็บเหลี่ยม สตริงในเครื่องหมายอัญประกาศคู่ ตัวเลข และค่า true, false และ null การจัดรูปแบบไม่เปลี่ยนความหมายของข้อมูล แต่เปลี่ยนว่าอ่านง่ายแค่ไหนสำหรับมนุษย์ JSON ที่ย่อขนาดแล้วโดยลบช่องว่างทั้งหมดจะเล็กกว่าและส่งผ่านเครือข่ายได้เร็วกว่า นั่นคือเหตุผลที่ API ใช้มัน แต่อ่านหรือดีบักแทบเป็นไปไม่ได้ ส่วน JSON ที่ทำให้สวยงามด้วยการเยื้องสองช่องว่างและหนึ่งค่าต่อบรรทัดจะใหญ่กว่า แต่ทำให้คุณเห็นจุลภาคที่หายไปหรือวงเล็บที่ผิดได้ในไม่กี่วินาที

ข้อผิดพลาด JSON ที่พบบ่อยที่สุด

  • จุลภาคที่หายไปหรือเกิน: ทุกรายการในออบเจกต์หรืออาร์เรย์ยกเว้นรายการสุดท้ายต้องการจุลภาค และจุลภาคต่อท้ายหลังรายการสุดท้ายไม่ได้รับอนุญาตใน JSON แบบเคร่งครัด
  • เครื่องหมายอัญประกาศเดี่ยวแทนอัญประกาศคู่: สตริง JSON ต้องใช้เครื่องหมายอัญประกาศคู่ แม้ว่าโค้ด JavaScript มักจะอนุญาตเครื่องหมายอัญประกาศเดี่ยว
  • คีย์ที่ไม่มีเครื่องหมายอัญประกาศ: คีย์ออบเจกต์ต้องเป็นสตริงที่มีเครื่องหมายอัญประกาศ ดังนั้น {name: "Ana"} ไม่ถูกต้องและต้องเป็น {"name": "Ana"}
  • ความคิดเห็น: JSON ไม่อนุญาตความคิดเห็น ดังนั้นบรรทัดที่ขึ้นต้นด้วย // จะทำให้การแยกวิเคราะห์เสียหายแม้ว่าจะดูไม่เป็นอันตราย
  • ข้อความต่อท้ายหรือเอกสารหลายฉบับ: การวางออบเจกต์ JSON สองตัวติดกันไม่ถูกต้อง ให้ห่อหุ้มไว้ในอาร์เรย์หรือแก้ทีละตัว

การจัดรูปแบบเทียบกับการย่อขนาด: เมื่อใดควรใช้แต่ละอย่าง

ใช้จัดรูปแบบเมื่อคุณกำลังอ่าน ดีบัก หรือเรียนรู้จาก JSON เพราะการเยื้องจะเผยโครงสร้างในพริบตาและทำให้การซ้อนกันชัดเจน ใช้ย่อขนาดเมื่อคุณต้องการวาง JSON ลงใน URL ช่องตั้งค่าที่กะทัดรัด คำขอทดสอบ หรือข้อความที่ขนาดสำคัญและการอ่านไม่สำคัญ ใช้ตรวจสอบเท่านั้นเมื่อคุณต้องการเพียงคำตอบใช่หรือไม่ใช่ เช่น ก่อนบันทึกไฟล์ตั้งค่า เพราะมันจะตรวจสอบ JSON โดยไม่แทนที่ข้อความต้นฉบับของคุณ ในทั้งสามกรณี เครื่องมือจะแยกวิเคราะห์ JSON ก่อน ดังนั้นผลลัพธ์ที่ย่อขนาดหรือจัดรูปแบบแล้วรับประกันว่าถูกต้อง ถ้าการแยกวิเคราะห์ล้มเหลว คุณจะได้รับข้อผิดพลาดแทนผลลัพธ์ที่เสียหายอย่างเงียบๆ ซึ่งเป็นสิ่งที่คุณต้องการอย่างแท้จริงก่อนส่งโค้ด

ความเป็นส่วนตัวและข้อจำกัด

เครื่องจัดรูปแบบนี้ทำงานในเบราว์เซอร์ของคุณทั้งหมด JSON ของคุณไม่เคยถูกอัปโหลด บันทึก หรือแชร์ ซึ่งสำคัญเพราะ JSON มักมีคีย์ API ข้อมูลส่วนตัว หรือการตั้งค่าภายใน อย่าวางความลับลงในเครื่องจัดรูปแบบออนไลน์ใดที่คุณไม่ไว้ใจ และเปลี่ยนคีย์ใดที่คุณเผลอเปิดเผย เครื่องมือจัดการการตอบสนอง API และไฟล์ตั้งค่าทั่วไปได้ง่าย แต่เอกสารที่ใหญ่มาก หลายสิบเมกะไบต์ อาจช้าในแท็บเบราว์เซอร์เพราะการแยกวิเคราะห์และการแปลงเป็นสตริงใหม่ใช้หน่วยความจำ มันยังปฏิบัติตามกฎ JSON แบบเคร่งครัด ดังนั้นมันจะปฏิเสธส่วนเพิ่มเติมแบบ JavaScript อย่างจุลภาคต่อท้าย เครื่องหมายอัญประกาศเดี่ยว และความคิดเห็น แม้ว่าเครื่องมือบางตัวจะยอมรับอย่างหลวมๆ

คำถามที่พบบ่อย

จัดรูปแบบกับย่อขนาดต่างกันอย่างไร?
จัดรูปแบบจะเพิ่มการเยื้องและการขึ้นบรรทัดใหม่เพื่อให้ JSON อ่านง่ายสำหรับมนุษย์ ย่อขนาดจะลบช่องว่างและการขึ้นบรรทัดใหม่ที่ไม่จำเป็นทั้งหมดเพื่อให้ JSON เล็กที่สุดเท่าที่จะเป็นไปได้สำหรับการส่งหรือเก็บ
ทำไม JSON ของฉันจึงล้มเหลวด้วยข้อผิดพลาดจุลภาคต่อท้าย?
JSON แบบเคร่งครัดไม่อนุญาตจุลภาคหลังรายการสุดท้ายในออบเจกต์หรืออาร์เรย์ ลบจุลภาคสุดท้ายนั้นออกแล้ว JSON จะแยกวิเคราะห์ได้
ฉันใช้เครื่องหมายอัญประกาศเดี่ยวใน JSON ได้หรือไม่?
ไม่ได้ สตริงและคีย์ JSON ต้องใช้เครื่องหมายอัญประกาศคู่ เครื่องหมายอัญประกาศเดี่ยวใช้ได้ในโค้ด JavaScript แต่ไม่ใช่ JSON ที่ถูกต้องและเครื่องมือนี้จะปฏิเสธอย่างถูกต้อง
ข้อมูล JSON ของฉันถูกเก็บหรือส่งไปที่ใดหรือไม่?
ไม่ การจัดรูปแบบและการตรวจสอบทำงานในเบราว์เซอร์ของคุณทั้งหมด ข้อมูลของคุณจึงไม่เคยออกจากอุปกรณ์ของคุณ
การจัดรูปแบบเปลี่ยนข้อมูลของฉันหรือไม่?
ไม่ การจัดรูปแบบและการย่อขนาดเปลี่ยนเพียงช่องว่างและการขึ้นบรรทัดใหม่ ค่า คีย์ และโครงสร้างยังคงเหมือนเดิมทุกประการ ตราบเท่าที่ JSON ถูกต้องตั้งแต่แรก
