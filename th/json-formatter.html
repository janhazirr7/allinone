วิธีใช้ฟอร์แมต JSON

  1. วาง JSON ของคุณคัดลอก JSON จาก API, ไฟล์กำหนดค่า หรือบทช่วยสอน และวางลงในช่องขนาดใหญ่
  2. เลือกการกระทำกดรูปแบบเพื่อให้สามารถอ่านได้โดยมีการเยื้อง ย่อขนาดเพื่อย่อขนาดให้เหลือหนึ่งบรรทัด หรือตรวจสอบความถูกต้องเท่านั้นเพื่อตรวจสอบโดยไม่ต้องเปลี่ยนแปลง
  3. อ่านข้อผิดพลาดหากมีหาก JSON ไม่ถูกต้อง เครื่องมือจะแสดงข้อผิดพลาดที่แน่นอนจาก Parser ด้วยคำพูดธรรมดา เพื่อให้คุณรู้ว่าต้องแก้ไขอย่างไร
  4. คัดลอกผลลัพธ์ใช้ Copy Output เพื่อนำ JSON ที่จัดรูปแบบหรือย่อขนาดแล้วกลับไปเป็นโค้ด การกำหนดค่า หรือเครื่องมือ API ของคุณ

JSON คืออะไร และเหตุใดการจัดรูปแบบจึงมีความสำคัญ

JSON ย่อมาจาก JavaScript Object Notation เป็นวิธีที่ใช้กันมากที่สุดที่คอมพิวเตอร์แลกเปลี่ยนข้อมูลที่มีโครงสร้างบนเว็บ API, ไฟล์การกำหนดค่า และแอปจำนวนมากต่างพูดได้กับ JSON เนื่องจากอ่านง่ายและง่ายสำหรับเครื่องในการแยกวิเคราะห์ เอกสาร JSON ที่ถูกต้องสร้างขึ้นจากวัตถุที่อยู่ในวงเล็บปีกกา อาร์เรย์ในวงเล็บเหลี่ยม สตริงในเครื่องหมายคำพูดคู่ ตัวเลข และค่าจริง เท็จ และค่าว่าง การจัดรูปแบบไม่ได้เปลี่ยนความหมายของข้อมูล แต่เปลี่ยนความง่ายในการอ่านของมนุษย์ JSON แบบย่อซึ่งนำช่องว่างทั้งหมดออกนั้นมีขนาดเล็กลงและเร็วกว่าในการส่งผ่านเครือข่าย ซึ่งเป็นสาเหตุที่ API ใช้ แต่แทบจะเป็นไปไม่ได้เลยที่จะอ่านหรือแก้ไขจุดบกพร่อง JSON ที่สวยงามซึ่งมีการเว้นวรรค 2 ช่องและ 1 ค่าต่อบรรทัด มีขนาดใหญ่กว่า แต่ช่วยให้คุณมองเห็นเครื่องหมายจุลภาคที่หายไปหรือวงเล็บที่ไม่ถูกต้องได้ภายในไม่กี่วินาที

ข้อผิดพลาด JSON ที่พบบ่อยที่สุด

  • เครื่องหมายจุลภาคหายไปหรือเกินมา: ทุกรายการในออบเจ็กต์หรืออาร์เรย์ยกเว้นรายการสุดท้ายต้องมีเครื่องหมายจุลภาค และไม่อนุญาตให้ใช้เครื่องหมายจุลภาคต่อท้ายรายการสุดท้ายใน JSON แบบเข้มงวด
  • เครื่องหมายคำพูดเดี่ยวแทนที่จะเป็นเครื่องหมายคำพูดคู่: สตริง JSON ต้องใช้เครื่องหมายคำพูดคู่ แม้ว่าโค้ด JavaScript มักจะอนุญาตให้ใช้เครื่องหมายคำพูดเดี่ยวก็ตาม
  • คีย์ที่ไม่มีเครื่องหมายคำพูด: คีย์ออบเจ็กต์จะต้องเป็นสตริงเครื่องหมายคำพูด ดังนั้น {name: "Ana"} จึงไม่ถูกต้องและต้องเป็น {"name": "Ana"}
  • ความคิดเห็น: JSON ไม่อนุญาตให้แสดงความคิดเห็น ดังนั้นบรรทัดที่ขึ้นต้นด้วย // จะทำให้การแยกวิเคราะห์ไม่ทำงาน แม้ว่าจะดูไม่เป็นอันตรายก็ตาม
  • ข้อความต่อท้ายหรือเอกสารหลายรายการ: การวางออบเจ็กต์ JSON สองรายการติดกันไม่ถูกต้อง ล้อมไว้ในอาร์เรย์หรือแก้ไขทีละรายการ

การจัดรูปแบบเทียบกับการลดขนาด: เมื่อใดควรใช้แต่ละรายการ

ใช้รูปแบบเมื่อคุณอ่าน ดีบัก หรือเรียนรู้จาก JSON เนื่องจากการเยื้องจะเผยให้เห็นโครงสร้างได้อย่างรวดเร็ว และทำให้การซ้อนชัดเจน ใช้ Minify เมื่อคุณต้องการวาง JSON ลงใน URL, ช่องการกำหนดค่าแบบย่อ, คำขอทดสอบ หรือข้อความที่ขนาดไม่สำคัญและความสามารถในการอ่านไม่สำคัญ ใช้ตรวจสอบความถูกต้องเฉพาะเมื่อคุณต้องการเพียงคำตอบใช่หรือไม่ใช่เท่านั้น เช่น ก่อนที่จะบันทึกไฟล์กำหนดค่า เนื่องจากจะตรวจสอบ JSON โดยไม่ต้องแทนที่ข้อความต้นฉบับของคุณ ในทั้งสามกรณี เครื่องมือจะแยกวิเคราะห์ JSON ก่อน ดังนั้นผลลัพธ์ที่ย่อขนาดหรือจัดรูปแบบจึงรับประกันได้ว่าจะใช้ได้ หากการแยกวิเคราะห์ล้มเหลว คุณจะได้รับข้อผิดพลาดแทนที่จะเป็นเอาต์พุตที่ใช้งานไม่ได้ซึ่งเป็นสิ่งที่คุณต้องการก่อนจัดส่งโค้ด

ความเป็นส่วนตัวและข้อจำกัด

ฟอร์แมตเตอร์นี้ทำงานได้ทั้งหมดในเบราว์เซอร์ของคุณ JSON ของคุณจะไม่มีการอัปโหลด บันทึก หรือแชร์ ซึ่งมีความสำคัญเนื่องจาก JSON มักจะมีคีย์ API ข้อมูลส่วนบุคคล หรือการกำหนดค่าภายใน อย่าวางความลับลงในฟอร์แมตเตอร์ออนไลน์ใดๆ ที่คุณไม่เชื่อถือ และสับเปลี่ยนคีย์ใดๆ ที่คุณเปิดเผยโดยไม่ได้ตั้งใจ เครื่องมือนี้จัดการการตอบสนอง API ทั่วไปและไฟล์กำหนดค่าได้อย่างง่ายดาย แต่เอกสารที่มีขนาดใหญ่มากซึ่งมีขนาดหลายสิบเมกะไบต์อาจทำงานช้าในแท็บเบราว์เซอร์เนื่องจากการแยกวิเคราะห์และสตริงใหม่ต้องใช้หน่วยความจำ นอกจากนี้ยังปฏิบัติตามกฎ JSON ที่เข้มงวด ดังนั้นจึงปฏิเสธสิ่งพิเศษสไตล์ JavaScript เช่น เครื่องหมายจุลภาคต่อท้าย เครื่องหมายคำพูดเดี่ยว และความคิดเห็น แม้ว่าเครื่องมือบางอย่างจะยอมรับสิ่งเหล่านั้นอย่างหลวมๆ ก็ตาม

คำถามที่พบบ่อย (FAQ)

ความแตกต่างระหว่างรูปแบบและย่อขนาดคืออะไร?
รูปแบบเพิ่มการเยื้องและการขึ้นบรรทัดใหม่เพื่อให้มนุษย์อ่าน JSON ได้ง่าย ย่อขนาดจะลบช่องว่างและตัวแบ่งบรรทัดที่ไม่จำเป็นทั้งหมด เพื่อให้ JSON มีขนาดเล็กที่สุดเท่าที่จะเป็นไปได้สำหรับการส่งหรือจัดเก็บ
เหตุใด JSON ของฉันจึงล้มเหลวโดยมีข้อผิดพลาดลูกน้ำต่อท้าย
JSON แบบเข้มงวดไม่อนุญาตให้ใช้เครื่องหมายจุลภาคหลังรายการสุดท้ายในวัตถุหรืออาร์เรย์ ลบเครื่องหมายจุลภาคสุดท้ายนั้นออก จากนั้น JSON จะแยกวิเคราะห์
ฉันสามารถใช้เครื่องหมายคำพูดเดี่ยวใน JSON ได้หรือไม่
ไม่ สตริงและคีย์ JSON ต้องใช้เครื่องหมายคำพูดคู่ เครื่องหมายคำพูดเดี่ยวทำงานในโค้ด JavaScript แต่ไม่ใช่ JSON ที่ถูกต้อง และเครื่องมือนี้จะปฏิเสธอย่างถูกต้อง
ข้อมูล JSON ของฉันถูกจัดเก็บหรือส่งไปที่ใดหรือไม่
ไม่ การจัดรูปแบบและการตรวจสอบความถูกต้องจะทำงานทั้งหมดในเบราว์เซอร์ของคุณ ดังนั้นข้อมูลของคุณจะไม่มีวันออกจากอุปกรณ์ของคุณ
การจัดรูปแบบทำให้ข้อมูลของฉันเปลี่ยนแปลงหรือไม่
ไม่ การจัดรูปแบบและย่อขนาดจะเปลี่ยนเพียงระยะห่างและตัวแบ่งบรรทัดเท่านั้น ค่า คีย์ และโครงสร้างจะยังคงเหมือนเดิมทุกประการ ตราบใดที่ JSON นั้นถูกต้องตั้งแต่แรก
