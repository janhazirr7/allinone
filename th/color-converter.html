วิธีใช้เครื่องแปลงสี

นักออกแบบ นักพัฒนา และช่างพิมพ์ล้วนอธิบายสีเดียวกันด้วยภาษาที่ต่างกัน นักพัฒนาเว็บเขียน #2563EB นักออกแบบสิ่งพิมพ์คิดเป็นเปอร์เซ็นต์ของสีฟ้าและสีม่วงแดง ส่วนผู้เขียน CSS ที่ปรับความสว่างจะใช้ HSL การแปลงระหว่างรูปแบบเหล่านี้ด้วยมือช้าและผิดพลาดง่าย โดยเฉพาะคณิตศาสตร์เบื้องหลัง HSL เครื่องแปลงนี้ทำได้ทันที ป้อนสีในรูปแบบใดรูปแบบหนึ่งแล้วดูทั้งสามรูปแบบพร้อมกัน พร้อมตัวอย่างสีแบบสดเพื่อให้คุณตัดสินผลลัพธ์ด้วยสายตา ไม่ใช่แค่ตัวเลข

  1. เริ่มจาก HEXพิมพ์รหัส hex โดยมีหรือไม่มีเครื่องหมาย # เช่น #FF0000 หรือ 2563EB แล้วกดแปลงจาก HEX รหัสย่อสามหลักอย่าง F00 ก็ใช้ได้และจะขยายเป็น FF0000
  2. หรือเริ่มจาก RGBป้อนช่องแดง เขียว และน้ำเงิน แต่ละช่องตั้งแต่ 0 ถึง 255 แล้วกดแปลงจาก RGB วิธีนี้สะดวกเมื่อเครื่องมือออกแบบหรือตัวเลือกสีจากภาพหน้าจอให้ค่า RGB แก่คุณ
  3. หรือเริ่มจาก HSLป้อนเฉดสีตั้งแต่ 0 ถึง 360 องศา บวกความอิ่มตัวและความสว่างเป็นเปอร์เซ็นต์ แล้วกดแปลงจาก HSL HSL เป็นรูปแบบที่ง่ายที่สุดสำหรับการสร้างสีเวอร์ชันที่สว่างขึ้นหรือเข้มขึ้น
  4. คัดลอกสิ่งที่คุณต้องการค่าที่แปลงแล้วจะปรากฏด้านล่างพร้อม CSS ที่พร้อมคัดลอก ตัวอย่างสีจะอัปเดตจากข้อมูลป้อนใดๆ คุณจึงทดลองได้อย่างอิสระและดูสีที่เปลี่ยนไป

HEX, RGB และ HSL อธิบายไว้

HEX คือรหัสย่อของเว็บสำหรับ RGB ตัวเลขฐานสิบหกแต่ละคู่แทนหนึ่งช่อง คู่แรกคือแดง คู่ที่สองคือเขียว คู่ที่สามคือน้ำเงิน ดังนั้น FF0000 คือแดงล้วน 00FF00 คือเขียวล้วน และ 000000 คือดำ ส่วน FFFFFF คือขาว เลขฐานสิบหกใช้ตัวเลข 0 ถึง 9 บวกตัวอักษร A ถึง F โดย A หมายถึง 10 และ F หมายถึง 15 นั่นคือเหตุผลที่ตัวเลขฐานสิบหกสองหลักแทนค่าทุกค่าตั้งแต่ 0 ถึง 255 ได้ รหัสย่อสามหลักเพียงแค่เพิ่มตัวเลขแต่ละตัวเป็นสองเท่า ดังนั้น F00 จึงกลายเป็น FF0000 และ 369 กลายเป็น 336699

RGB อธิบายสีในรูปแสง คือผสมแสงแดง เขียว และน้ำเงินเท่าไร หน้าจอเปล่งแสง ดังนั้นการบวกทั้งสามช่องเต็มที่จะให้สีขาว และการปิดทั้งหมดจะให้สีดำ แบบจำลองแบบบวกนี้เข้าใจง่ายสำหรับหน้าจอแต่ไม่สะดวกสำหรับมนุษย์ที่พยายามปรับสี เพราะการเปลี่ยนความสว่างหมายถึงเปลี่ยนตัวเลขทั้งสามพร้อมกัน HSL แก้ปัญหานั้นด้วยการอธิบายสีตามวิธีที่คนคิด เฉดสีคือตำแหน่งรอบวงล้อสีเป็นองศา โดย 0 คือแดง 120 คือเขียว และ 240 คือน้ำเงิน ความอิ่มตัวคือสีสดแค่ไหน จากเทาที่ 0% ถึงสีเต็มที่ 100% และความสว่างวิ่งจากดำที่ 0% ผ่านสีล้วนที่ 50% ไปยังขาวที่ 100%

HEX #RRGGBB = RGB (แดง, เขียว, น้ำเงิน) แต่ละช่อง 0-255
HSL (เฉดสี 0-360, ความอิ่มตัว 0-100%, ความสว่าง 0-100%)
ตัวอย่าง: แดงล้วนคือ #FF0000 = rgb(255, 0, 0) = hsl(0, 100%, 50%) เขียวล้วนคือ #00FF00 = rgb(0, 255, 0) = hsl(120, 100%, 50%) สีเทามีความอิ่มตัว 0% ที่เฉดสีใดก็ได้

การใช้งานเชิงปฏิบัติและเคล็ดลับการเข้าถึง

งานแปลงที่พบบ่อยที่สุดคือการย้ายสีแบรนด์ระหว่างเครื่องมือ ไฟล์โลโก้อาจให้รหัส hex สไตล์ชีตของนักพัฒนาต้องการ RGB สำหรับเอฟเฟกต์โปร่งใสอย่าง rgba(37, 99, 235, 0.5) และนักออกแบบที่สร้างสถานะเมื่อชี้เมาส์ต้องการ HSL เพื่อทำให้สีเดียวกันสว่างขึ้นโดยเพิ่มความสว่างสิบจุด การทำขั้นตอนเหล่านั้นที่นี่จะคงแหล่งความจริงเดียวไว้ พิมพ์สีแบรนด์ครั้งเดียว แล้วทุกรูปแบบจะสอดคล้องกันแทนที่จะคลาดเคลื่อนจากการพิมพ์ซ้ำด้วยมือและข้อผิดพลาดจากการปัดเศษ

1. สร้างชุดสีจากสีเดียว

เริ่มจากสีหลักของคุณใน HSL แล้วคงเฉดสีไว้และเปลี่ยนความสว่าง: 30% สำหรับข้อความเข้ม 50% สำหรับสีหลัก 85% สำหรับสีพื้นหลังอ่อน ผลลัพธ์จะดูเหมือนออกแบบมา ไม่ใช่สุ่ม

2. ตรวจสอบความคมชัดก่อนส่งมอบ

ข้อความสีอ่อนบนพื้นหลังสีอ่อนคือความล้มเหลวด้านการเข้าถึงที่พบบ่อยที่สุดบนเว็บ ใช้ตัวอย่างสีตัดสินในพริบตา และเลือกข้อความเข้มบนสีอ่อนและข้อความขาวบนสีเข้มที่อิ่มตัว

3. แก้สีจากภาพหน้าจอ

ตัวเลือกสีมักรายงานค่า RGB วางค่าที่นี่เพื่อรับรหัส hex สำหรับสไตล์ชีตของคุณ หรือค่า HSL เพื่อปรับเฉดสีอย่างละเอียดโดยไม่ต้องเดาทีละช่อง

หมายเหตุสุดท้ายเรื่องความแม่นยำ: การแปลงระหว่าง RGB และ HSL เกี่ยวข้องกับการปัดเศษ เพราะเปอร์เซ็นต์ HSL ที่นี่เป็นจำนวนเต็ม ส่วนช่อง RGB เป็นจำนวนเต็ม การแปลงสีเป็น HSL แล้วกลับมาอาจเลื่อนช่องไปหนึ่งหน่วย ซึ่งมองไม่เห็นด้วยตาและเป็นเรื่องปกติสำหรับเครื่องแปลงทุกตัว ถ้าคุณต้องการการสร้างซ้ำที่สมบูรณ์แบบระดับพิกเซลสำหรับงานพิมพ์ ให้เก็บค่า hex หรือ RGB ต้นฉบับไว้เป็นสำเนาหลัก ทุกอย่างที่นี่ทำงานอย่างเป็นส่วนตัวในเบราว์เซอร์ของคุณ สีแบรนด์และชุดสีของคุณจึงไม่เคยถูกอัปโหลดหรือเก็บไว้

คำถามที่พบบ่อย

รหัสสี HEX คืออะไร?
รหัส HEX คือรหัสย่อฐานสิบหกหกหลักสำหรับค่า RGB เขียนโดยมีเครื่องหมาย # นำหน้า เช่น #FF0000 สำหรับแดงล้วน ตัวเลขแต่ละคู่แทนแดง เขียว และน้ำเงิน จาก 00 (ไม่มี) ถึง FF (เต็ม หรือ 255) รหัสสามหลักอย่าง F00 คือรหัสย่อที่เพิ่มตัวเลขแต่ละตัวเป็นสองเท่าเป็น FF0000
ฉันจะแปลง HEX เป็น RGB ได้อย่างไร?
แยกตัวเลขฐานสิบหกหกหลักเป็นสามคู่แล้วแปลงแต่ละคู่จากฐานสิบหกเป็นฐานสิบ สำหรับ #2563EB, 25 กลายเป็น 37, 63 กลายเป็น 99 และ EB กลายเป็น 235 ให้ rgb(37, 99, 235) เครื่องแปลงนี้คำนวณเลขคณิตนั้นให้คุณทั้งสองทิศทาง
H, S และ L ใน HSL หมายถึงอะไร?
H คือเฉดสี ตำแหน่งบนวงล้อสีตั้งแต่ 0 ถึง 360 องศา โดย 0 คือแดง 120 คือเขียว และ 240 คือน้ำเงิน S คือความอิ่มตัว จากเทา 0% ถึงสดเต็มที่ 100% L คือความสว่าง จากดำ 0% ผ่านสีล้วน 50% ถึงขาว 100%
ทำไมการแปลงไปกลับจึงเปลี่ยนค่าไป 1?
เปอร์เซ็นต์ HSL ถูกปัดเศษเป็นจำนวนเต็มที่นี่ และช่อง RGB เป็นจำนวนเต็ม การไปกลับจึงอาจเลื่อนช่องไปหนึ่งหน่วย ความแตกต่างมองไม่เห็นด้วยตา ให้เก็บค่า HEX หรือ RGB ต้นฉบับไว้เป็นสำเนาหลักสำหรับงานที่ต้องการความสมบูรณ์แบบระดับพิกเซล
ฉันใช้เครื่องแปลงนี้สำหรับสีงานพิมพ์ได้หรือไม่?
สำหรับการออกแบบหน้าจอ ได้ งานพิมพ์ใช้ CMYK ซึ่งเป็นแบบจำลองที่ต่างกันโดยอิงหมึกแทนแสง ดังนั้นสีหน้าจอที่แปลงเพื่องานพิมพ์จะดูต่างกันบนกระดาษ ให้พิสูจน์สีงานพิมพ์ด้วยค่า CMYK ของเครื่องพิมพ์ของคุณเสมอ
ข้อมูลสีของฉันถูกเก็บไว้หรือไม่?
ไม่ การแปลงทั้งหมดทำงานในเบราว์เซอร์ของคุณ ไม่มีสิ่งที่คุณป้อนถูกส่งไปยังเซิร์ฟเวอร์หรือเก็บไว้
