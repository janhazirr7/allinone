วิธีใช้ตัวแปลงสี

Designers, developers, and printers all describe the same color in different languages. นักพัฒนาเว็บเขียน #2563EB นักออกแบบสิ่งพิมพ์คิดเป็นเปอร์เซ็นต์ของสีฟ้าและสีม่วงแดง และผู้เขียน CSS ปรับความสว่างสำหรับ HSL Converting between these formats by hand is slow and error-prone, especially with the maths behind HSL. โปรแกรมแปลงไฟล์นี้ดำเนินการทันที: ป้อนสีในรูปแบบใดรูปแบบหนึ่งและดูทั้งสามสีพร้อมกัน พร้อมตัวอย่างสด เพื่อให้คุณสามารถตัดสินผลลัพธ์ด้วยตาของคุณ ไม่ใช่แค่ตัวเลข

  1. เริ่มจากฐานสิบหกพิมพ์รหัสฐานสิบหกโดยมีหรือไม่มีแฮช เช่น #FF0000 หรือ 2563EB แล้วกด Convert จาก HEX การจดชวเลขสามหลักเช่น F00 ก็ใช้ได้เช่นกันและขยายเป็น FF0000
  2. หรือเริ่มจาก RGBป้อนช่องสีแดง เขียว และน้ำเงิน แต่ละช่องตั้งแต่ 0 ถึง 255 แล้วกด Convert จาก RGB สิ่งนี้มีประโยชน์เมื่อเครื่องมือออกแบบหรือเครื่องมือเลือกภาพหน้าจอให้ค่า RGB แก่คุณ
  3. หรือเริ่มจาก HSLป้อนเฉดสีตั้งแต่ 0 ถึง 360 องศา บวกความอิ่มตัวและความสว่างเป็นเปอร์เซ็นต์ แล้วกด Convert จาก HSL HSL เป็นรูปแบบที่ง่ายที่สุดในการสร้างสีที่อ่อนกว่าหรือเข้มกว่า
  4. คัดลอกสิ่งที่คุณต้องการค่าที่แปลงแล้วจะปรากฏด้านล่าง พร้อมด้วย CSS ที่พร้อมสำหรับการคัดลอก ตัวอย่างแถบสีจะอัปเดตจากอินพุตใดๆ เพื่อให้คุณสามารถทดลองได้อย่างอิสระและดูการเปลี่ยนแปลงของสี

อธิบาย HEX, RGB และ HSL

HEX เป็นตัวย่อของเว็บสำหรับ RGB เลขฐานสิบหกแต่ละคู่แสดงถึงหนึ่งช่อง: คู่แรกคือสีแดง, สีเขียวที่สอง, สีน้ำเงินที่สาม ดังนั้น FF0000 จึงเป็นสีแดงบริสุทธิ์ 00FF00 สีเขียวบริสุทธิ์ และ 000000 สีดำ ในขณะที่ FFFFFF จึงเป็นสีขาว เลขฐานสิบหกใช้ตัวเลข 0 ถึง 9 บวกตัวอักษร A ถึง F โดยที่ A หมายถึง 10 และ F หมายถึง 15 ซึ่งเป็นสาเหตุที่เลขฐานสิบหกสองหลักสามารถแทนทุกค่าตั้งแต่ 0 ถึง 255 การจดชวเลขสามหลักจะเพิ่มเป็นสองเท่าในแต่ละหลัก ดังนั้น F00 จะกลายเป็น FF0000 และ 369 กลายเป็น 336699

RGB อธิบายสีว่าเป็นแสง: ปริมาณแสงสีแดง เขียว และน้ำเงินที่จะผสมกัน หน้าจอจะปล่อยแสง ดังนั้นการเพิ่มทั้งสามช่องให้เต็มกำลังจะสร้างสีขาว และการปิดช่องทั้งหมดจะทำให้เกิดสีดำ โมเดลเพิ่มเติมนั้นใช้งานง่ายสำหรับหน้าจอ แต่เป็นเรื่องที่ไม่สะดวกสำหรับมนุษย์ที่พยายามจะปรับสี เนื่องจากการเปลี่ยนความสว่างหมายถึงการเปลี่ยนตัวเลขทั้งสามพร้อมกัน HSL แก้ไขปัญหาดังกล่าวด้วยการอธิบายสีในแบบที่ผู้คนคิด: ฮิวคือตำแหน่งรอบวงล้อสีในหน่วยองศา โดย 0 คือสีแดง 120 คือสีเขียว และ 240 คือสีน้ำเงิน ความอิ่มตัวของสีคือความสดใสของสี ตั้งแต่สีเทาที่ 0% ไปจนถึงสีเต็มที่ 100% และความสว่างเริ่มจากสีดำที่ 0% ไปจนถึงสีบริสุทธิ์ที่ 50% ไปจนถึงสีขาวที่ 100%

HEX #RRGGBB = RGB (แดง เขียว น้ำเงิน) อย่างละ 0-255
HSL (เฉดสี 0-360, ความอิ่มตัวของสี 0-100%, ความสว่าง 0-100%)
ตัวอย่าง: สีแดงบริสุทธิ์คือ #FF0000 = rgb(255, 0, 0) = hsl(0, 100%, 50%) สีเขียวบริสุทธิ์คือ #00FF00 = rgb(0, 255, 0) = hsl(120, 100%, 50%) สีเทามีความอิ่มตัว 0% ในทุกเฉดสี

เคล็ดลับการใช้งานจริงและการเข้าถึง

งานการแปลงที่พบบ่อยที่สุดคือการย้ายสีของแบรนด์ระหว่างเครื่องมือต่างๆ ไฟล์โลโก้อาจให้รหัสฐานสิบหกแก่คุณ สไตล์ชีตของนักพัฒนาต้องใช้ RGB เพื่อให้เอฟเฟกต์โปร่งใส เช่น rgba (37, 99, 235, 0.5) และนักออกแบบที่สร้างสถานะโฮเวอร์ต้องใช้ HSL เพื่อทำให้สีเดียวกันจางลงโดยเพิ่มความสว่างขึ้นสิบจุด การทำตามขั้นตอนเหล่านี้ที่นี่จะรักษาแหล่งที่มาของความจริงไว้เพียงแหล่งเดียว นั่นคือ พิมพ์สีของแบรนด์เพียงครั้งเดียว และทุกรูปแบบจะมีความสอดคล้องกัน แทนที่จะต้องพิมพ์ซ้ำด้วยตนเองและข้อผิดพลาดในการปัดเศษ

1. สร้างจานสีจากสีเดียว

เริ่มจากสีหลักของคุณใน HSL จากนั้นคงเฉดสีคงที่และปรับความสว่าง: 30% สำหรับข้อความสีเข้ม 50% สำหรับสีหลัก 85% สำหรับพื้นหลังสีซีด ผลลัพธ์ดูได้รับการออกแบบมา ไม่ใช่แบบสุ่ม

2.ตรวจสอบความคมชัดก่อนจัดส่ง

ข้อความสีอ่อนบนพื้นหลังสีอ่อนถือเป็นความล้มเหลวในการเข้าถึงที่พบบ่อยที่สุดบนเว็บ ใช้ตัวอย่างเพื่อตัดสินอย่างรวดเร็ว และชอบข้อความสีเข้มบนสีอ่อน และชอบข้อความสีขาวบนสีเข้มอิ่มตัว

3. แก้ไขสีจากภาพหน้าจอ

ตัวเลือกสีมักจะรายงานค่า RGB วางที่นี่เพื่อรับรหัสฐานสิบหกสำหรับสไตล์ชีตของคุณ หรือค่า HSL เพื่อปรับแต่งเฉดสีอย่างละเอียดโดยไม่ต้องเดาทีละช่อง

หมายเหตุสุดท้ายเกี่ยวกับความแม่นยำ: การแปลงระหว่าง RGB และ HSL เกี่ยวข้องกับการปัดเศษ เนื่องจากเปอร์เซ็นต์ของ HSL เป็นตัวเลขทั้งหมด ในขณะที่ช่อง RGB เป็นจำนวนเต็ม การแปลงสีเป็น HSL และด้านหลังอาจเปลี่ยนช่องสัญญาณทีละหน่วย ซึ่งมองไม่เห็นด้วยตาเปล่าและเป็นเรื่องปกติสำหรับตัวแปลงทุกตัว หากคุณต้องการการสร้างภาพพิมพ์ที่สมบูรณ์แบบด้วยพิกเซล ให้เก็บค่าฐานสิบหกหรือ RGB ดั้งเดิมไว้เป็นสำเนาหลักของคุณ ทุกอย่างที่นี่ทำงานแบบส่วนตัวในเบราว์เซอร์ของคุณ ดังนั้นสีและจานสีของแบรนด์ของคุณจะไม่ถูกอัพโหลดหรือจัดเก็บ

คำถามที่พบบ่อย (FAQ)

รหัสสี HEX คืออะไร
รหัส HEX คือรหัสย่อเลขฐานสิบหกหกหลักสำหรับค่า RGB ซึ่งเขียนด้วยแฮชนำหน้า เช่น #FF0000 สำหรับสีแดงบริสุทธิ์ ตัวเลขแต่ละคู่หมายถึงสีแดง เขียว และน้ำเงิน ตั้งแต่ 00 (ไม่มี) ถึง FF (เต็ม หรือ 255) รหัสสามหลัก เช่น F00 เป็นการจดชวเลขที่จะเพิ่มแต่ละหลักเป็น FF0000
ฉันจะแปลง HEX เป็น RGB ได้อย่างไร
แบ่งเลขฐานสิบหกหกหลักออกเป็นสามคู่แล้วแปลงแต่ละคู่จากเลขฐานสิบหกเป็นทศนิยม สำหรับ #2563EB, 25 กลายเป็น 37, 63 กลายเป็น 99 และ EB กลายเป็น 235 โดยให้ rgb(37, 99, 235) ตัวแปลงนี้จะทำการคำนวณให้คุณในทิศทางใดทิศทางหนึ่ง
H, S และ L หมายถึงอะไรใน HSL
H คือเฉดสี ตำแหน่งบนวงล้อสีตั้งแต่ 0 ถึง 360 องศา โดยที่ 0 คือสีแดง 120 คือสีเขียว และ 240 คือสีน้ำเงิน S คือความอิ่มตัวของสี จากสีเทา 0% ไปจนถึงสีสดใสเต็มที่ 100% L คือความสว่าง ตั้งแต่สีดำ 0% จนถึงสีบริสุทธิ์ 50% ไปจนถึงสีขาว 100%
เหตุใดการแปลงไปมาจึงเปลี่ยนค่าเป็น 1
เปอร์เซ็นต์ HSL จะถูกปัดเศษเป็นจำนวนเต็มที่นี่ และช่อง RGB เป็นจำนวนเต็ม ดังนั้นการเดินทางไปกลับสามารถเปลี่ยนช่องได้หนึ่งหน่วย ความแตกต่างนั้นมองไม่เห็นด้วยตา เก็บค่า HEX หรือ RGB ดั้งเดิมของคุณเป็นสำเนาหลักเพื่อการทำงานที่สมบูรณ์แบบของพิกเซล
ฉันสามารถใช้ตัวแปลงนี้กับสีงานพิมพ์ได้หรือไม่
สำหรับการออกแบบหน้าจอใช่ การพิมพ์ใช้ CMYK ซึ่งเป็นรุ่นที่แตกต่างกันโดยใช้หมึกมากกว่าการใช้แสง ดังนั้นสีของหน้าจอที่แปลงสำหรับการพิมพ์จะดูแตกต่างออกไปบนกระดาษ ตรวจสอบสีงานพิมพ์ด้วยค่า CMYK ของเครื่องพิมพ์ของคุณเสมอ
