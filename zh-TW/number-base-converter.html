如何使用 進位換算器

電腦、程式設計師與電子工程師經常在數字進位之間切換：硬體用二進位，較舊的系統與檔案權限用八進位，日常算術用十進位，十六進位則是二進位的簡潔簡寫。這個換算器接受四種進位中任一進位的數字，並即時一次顯示全部四種數值，因此你永遠不需要換算兩次，也不需要懷疑某個數字在你選擇的進位中是否合法。

  1. 輸入你的數字請在第一個方框中輸入數值，例如 255、1010 或 FF。僅限非負整數；正負號與小數點不屬於這些整數進位。
  2. 告訴換算器它是哪種進位請從下拉選單中選擇二進位、八進位、十進位或十六進位。這很重要：1010 在二進位中表示十，在十進位中卻表示一千零一十。
  3. 按下「換算」並閱讀全部四種結果二進位、八進位、十進位與十六進位數值會一起出現，十進位數值會突出顯示，讓你可以複製你的程式碼或作業需要的任何形式。
  4. 若出現錯誤，請檢查你的數字每種進位只允許特定的數字。二進位只允許 0 與 1，因此 102 會被拒絕；八進位允許 0 到 7，因此 89 會被拒絕；十六進位允許 0 到 9 與 A 到 F，因此 G 會被拒絕。

什麼是數字進位？為什麼我們需要不只一種？

數字進位（也稱為基數）只是計數系統在進位到新位數之前使用多少個不同數字。我們從小學習的十進位使用十個數字（0 到 9），因為人類有十根手指。每個位數的值是右邊位數的十倍：在 255 中，數字表示 2 個百位 + 5 個十位 + 5 個個位。二進位只使用兩個數字 0 與 1，因為電腦硬體是由開或關的開關構成的。每個二進位位數的值是右邊位數的兩倍，因此 1010 表示 8 + 0 + 2 + 0 = 10。八進位使用八個數字 0 到 7，十六進位使用十六個：0 到 9 加上代表數值十到十五的字母 A 到 F。

十六進位存在的主要原因是方便人類閱讀二進位。一個十六進位數字恰好對應四個二進位數字，因此像 11111111 這樣的長二進位字串可以整齊地縮減為 FF。這就是為什麼你在運算中到處都看到十六進位：網路上的顏色代碼如 #FF5733，其實是紅、綠、藍三個十六進位位元組；記憶體位址以十六進位顯示；網路工程師也以十六進位讀取裝置位址。八進位在早期運算中扮演類似角色，當時機器的字組大小可被三個位元整除，它至今仍出現在 Unix 檔案權限中，像 755 這樣的數值編碼了擁有者、群組與其他人的讀取、寫入與執行權限。

手動換算：兩個計算範例

手動將二進位換算為十進位，比任何定義更能教會位值概念。以 101101 為例。從右邊讀起，各位數的值分別為 1、2、4、8、16 與 32。從右邊起的數字為 1、0、1、1、0、1，因此數值為 1 + 4 + 8 + 32 = 45。將十進位換算為二進位則方向相反：反覆除以 2 並記錄餘數。對於 45，餘數為 1、0、1、1、0、1，倒著讀就是 101101，確認了第一次換算。十六進位以相同方式運作，只是使用 16 的冪次：1A3 表示 1 乘以 256，加上 A（10）乘以 16，再加上 3，即 256 + 160 + 3 = 419。

有一個快速捷徑可以在不經過十進位的情況下連結二進位、八進位與十六進位。從右邊起將二進位數字三個一組分組以得到八進位，或四個一組分組以得到十六進位，再換算每一組。例如，101011110 在八進位分組中變為 101 011 110，即 5 3 6；在十六進位分組中變為 1 0101 1110，即 1 5 E，因此數值在八進位中為 536，在十六進位中為 15E。學生常犯兩個錯誤：忘記在最左邊的組前方補零，以及從左邊而非右邊開始讀取各組。兩者都會改變答案，因此請務必從最右邊的數字開始分組。

實用小提示與常見錯誤

第一，分享可能含糊的數字時，請務必說明進位：單寫 1010 無法告訴任何人你指的是十還是一千零一十，這就是程式設計師會寫 0b1010 表示二進位、0xFF 表示十六進位的原因。第二，請記得前導零不會改變數值，因此二進位的 0001010 仍然是十；它們常純粹為了將數字補齊到整齊的寬度（例如八個位元）而加入。第三，這個換算器只處理整數。其他進位中的分數、負數與超過 64 位數的極長輸入都不在範圍內，換算器會明確告知而非猜測。最後，一切都在你的瀏覽器內執行，沒有資料傳送到任何地方，因此你可以私下且任意多次換算作業答案、程式碼常數與權限數值。

常見問題（FAQs）

255 在二進位、八進位與十六進位中是多少？
255 在二進位中是 11111111，在八進位中是 377，在十六進位中是 FF。四種形式代表相同的數值，只是計數系統不同。
為什麼二進位的 102 會出現錯誤？
二進位只使用數字 0 與 1，因此數字 2 在 2 進位中不合法。若你指的是十進位數字一百零二，請先選擇十進位作為輸入進位。
十六進位字母 A 到 F 是什麼？
十六進位需要十六個數字，但我們只有十個數字符號，因此字母 A 到 F 代表數值 10、11、12、13、14 與 15。這就是 FF 表示 15 乘以 16 再加上 15（即 255）的原因。
如何快速將二進位換算為十六進位？
從右邊起將二進位數字四個一組分組，並在最左邊的組前方補零，再將每組四個數字換算為一個十六進位數字。例如，11111111 分組為 1111 1111，即 F F。
這個換算器可以處理負數或分數嗎？
不可以。它換算最多 64 位數的非負整數。其他進位中的負數與分數需要不同的表示方式，例如二補數或小數點，而這個工具並不涵蓋。
