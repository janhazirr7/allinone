如何使用顏色轉換器

設計師、開發人員和印刷商都用不同的語言描述相同的顏色。網頁開發人員編寫#2563EB，印刷設計師考慮青色和洋紅色的百分比，CSS 作者調整亮度達到 HSL。手動在這些格式之間進行轉換既緩慢又容易出錯，尤其是 HSL 背後的數學原理。此轉換器可以立即完成此操作：以任何一種格式輸入顏色，然後使用即時樣本立即檢視所有三種顏色，這樣您就可以用眼睛判斷結果，而不僅僅是數字。

  1. 從十六進位開始鍵入有或沒有雜湊值的十六進位程式碼，例如 #FF0000 或 2563EB，然後按「從十六進位轉換」。像 F00 這樣的三位數簡寫也可以使用並擴充套件為 FF0000。
  2. 或從RGB開始輸入紅色、綠色和藍色通道，每個通道的範圍為 0 到 255，然後按「從 RGB 轉換」。當設計工具或螢幕截圖選擇器為您提供 RGB 值時，這會很方便。
  3. 或從HSL開始輸入 0 到 360 度的色調，加上百分比形式的飽和度和亮度，然後按下從 HSL 轉換。 HSL 是建立較淺或較深顏色版本的最簡單格式。
  4. 複製您需要的內容轉換後的值與可複製的 CSS 一起顯示在下面。預覽樣本會根據任何輸入進行更新，因此您可以自由實驗並觀察顏色變化。

HEX、RGB 和 HSL 解釋

HEX 是網路上 RGB 的簡寫。每對十六進位制數字代表一個通道：第一對是紅色，第二對是綠色，第三對是藍色。因此，FF0000 是純紅色，00FF00 是純綠色，000000 是黑色，而 FFFFFF 是白色。十六進位使用數字 0 到 9 加上字母 A 到 F，其中 A 表示 10，F 表示 15，這就是為什麼兩個十六進位數字可以表示 0 到 255 之間的每個值。三位數簡寫只是將每個數字加倍，因此 F00 變成 FF0000，369 變成 336699。

RGB 將顏色描述為光：混合多少紅、綠、藍光。螢幕會發光，因此全力新增所有三個通道會產生白色，將它們全部關閉會產生黑色。這種附加模型對於螢幕來說很直觀，但對於嘗試調整顏色的人類來說很尷尬，因為改變亮度意味著同時改變所有三個數字。 HSL 透過描述人們對顏色的看法來解決這個問題：色調是色輪周圍的位置（以度為單位），其中 0 為紅色，120 為綠色，240 為藍色；飽和度是指顏色的鮮豔程度，從 0% 的灰色到 100% 的全綵亮度；從 0% 的黑色到 50% 的白色到純色的白色。

HEX #RRGGBB = RGB（紅、綠、藍），每 0-255
HSL（色調0-360，飽和度0-100%，亮度0-100%）
範例：純紅色為 #FF0000 = rgb(255, 0, 0) = hsl(0, 100%, 50%)。純綠色為 #00FF00 = rgb(0, 255, 0) = hsl(120, 100%, 50%)。灰色在任何色調下的飽和度都是 0%。

實際用途和輔助使用提示

最常見的轉換任務是在工具之間移動品牌顏色。標誌檔案可能會為您提供十六進位程式碼，開發人員的樣式表需要 RGB 來實現 rgba(37, 99, 235, 0.5) 等透明效果，而建立懸停狀態的設計人員需要 HSL 透過將亮度提高 10 個點來使相同的顏色變亮。在這裡執行這些步驟可以保留一個事實來源：輸入​​品牌顏色一次，每種格式都保持一致，而不是因手動重新輸入和舍入錯誤而漂移。

1. 用一種顏色建立調色盤

從 HSL 中的主色開始，然後保持色調固定並改變亮度：深色文字為 30%，主色為 50%，淺背景色調為 85%。結果看起來是經過設計的，而不是隨機的。

2. 出貨前檢查對比度

淺色背景上的淺色文字是網路上最常見的可訪問性失敗。使用樣本一目瞭然地判斷，並且更喜歡淺色上的深色文字和飽和深色上的白色文字。

3.修復螢幕截圖的顏色

顏色選擇器通常會報告 RGB 值。將它們貼到此處以獲得樣式表的十六進位程式碼，或 HSL 值以微調陰影，而無需逐個通道猜測。

關於精確度的最後一點說明：RGB 和 HSL 之間的轉換涉及舍入，因為此處 HSL 百分比是整數，而 RGB 通道是整數。將顏色轉換為 HSL 並轉換回來可能會將通道移動一個單位，這對於肉眼來說是不可見的，但對於每個轉換器來說都是正常的。如果您需要完美畫素的列印複製，請將原始十六進位或 RGB 值保留為主副本。這裡的所有內容都在您的瀏覽器中私下執行，因此您的品牌顏色和調色盤永遠不會上傳或儲存。

常見問題 (FAQ)

什麼是十六進位顏色程式碼？
十六進位程式碼是 RGB 值的六位十六進位簡寫，用前導雜湊編寫，例如表示純紅色的 #FF0000。每對數字代表紅色、綠色和藍色，從 00（無）到 FF（完整，或 255）。 F00 等三位數程式碼是將每個數字加倍為 FF0000 的簡寫形式。
如何將 HEX 轉換為 RGB？
將六個十六進位制數字分成三對，並將每對從十六進位制轉換為十進位制。對於#2563EB，25 變成 37，63 變成 99，EB 變成 235，得到 rgb(37, 99, 235)。該轉換器可以在任一方向上為您執行該算術。
HSL 中的 H、S 和 L 是什麼意思？
H是色調，色輪上從0到360度的位置，其中0是紅色，120是綠色，240是藍色。 S 是飽和度，從 0% 灰色到 100% 完全鮮豔。 L 是亮度，從 0% 黑色到 50% 純色再到 100% 白色。
為什麼來回轉換值會改變 1？
這裡，HSL 百分比四捨五入為整數，而 RGB 通道是整數，因此往返可以將通道移動一個單位。差異是肉眼看不見的。將原始 HEX 或 RGB 值保留為主副本，以實現畫素完美的工作。
我可以使用此轉換器來列印顏色嗎？
對於螢幕設計，是的。列印使用 CMYK，這是一種基於墨水而不是光線的不同模型，因此轉換為列印的螢幕顏色在紙張上看起來會有所不同。請務必使用印表機的 CMYK 值校樣列印顏色。
我的顏色資料是否已儲存？
不會。所有轉換都在您的瀏覽器中執行。您輸入的任何內容都不會傳送到伺服器或儲存。
