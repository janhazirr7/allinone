如何使用 色彩換算器

設計師、開發者與印刷業者都以不同的語言描述同一個顏色。網頁開發者寫 #2563EB，印刷設計師以青色與洋紅色的百分比思考，而調整亮度的 CSS 作者則會使用 HSL。手動在這些格式之間換算既慢又容易出錯，特別是 HSL 背後的數學。本換算器可以即時完成：以任一種格式輸入顏色，一次查看三種格式，並附上即時色塊，讓你用眼睛而不只是數字來判斷結果。

  1. 從 HEX 開始請輸入附有或不附井號的十六進位代碼，例如 #FF0000 或 2563EB，再按下「從 HEX 換算」。像 F00 這樣的三位簡寫也可以，會展開為 FF0000。
  2. 或從 RGB 開始請輸入紅、綠、藍三個色版，各自範圍為 0 到 255，再按下「從 RGB 換算」。當設計工具或螢幕截圖取色器給你 RGB 數值時，這很方便。
  3. 或從 HSL 開始請輸入 0 到 360 度的色相，加上以百分比表示的飽和度與明度，再按下「從 HSL 換算」。HSL 是建立顏色較淺或較深版本最容易的格式。
  4. 複製你需要的內容換算結果會顯示在下方，並附上可直接複製的 CSS。預覽色塊會隨任何輸入更新，因此你可以自由嘗試並觀察顏色變化。

HEX、RGB 與 HSL 說明

HEX 是網路上 RGB 的簡寫。每對十六進位數字代表一個色版：第一對是紅色，第二對是綠色，第三對是藍色。因此 FF0000 是純紅色，00FF00 是純綠色，000000 是黑色，而 FFFFFF 是白色。十六進位使用數字 0 到 9 加上字母 A 到 F，其中 A 表示 10、F 表示 15，這就是為什麼兩位十六進位數字可以表示 0 到 255 的每個值。三位簡寫只是將每個數字加倍，因此 F00 變為 FF0000，369 變為 336699。

RGB 將顏色描述為光：要混合多少紅、綠、藍光。螢幕會發光，因此將三個色版全部開到最強會產生白色，全部關閉則產生黑色。這種加色模型對螢幕來說很直覺，但對想要調整顏色的人來說卻很彆扭，因為改變亮度意味著同時改變三個數字。HSL 透過以人們思考的方式描述顏色來解決這個問題：色相是色輪上的位置（以度表示），0 是紅色、120 是綠色、240 是藍色；飽和度是顏色多鮮豔，從 0% 的灰色到 100% 的全彩；明度則從 0% 的黑色，經過 50% 的純色，到 100% 的白色。

HEX #RRGGBB = RGB（紅、綠、藍），各為 0–255
HSL（色相 0–360、飽和度 0–100%、明度 0–100%）
範例：純紅色為 #FF0000 = rgb(255, 0, 0) = hsl(0, 100%, 50%)。純綠色為 #00FF00 = rgb(0, 255, 0) = hsl(120, 100%, 50%)。灰色在任何色相下飽和度皆為 0%。

實際用途與無障礙小提示

最常見的換算任務是在工具之間轉移品牌顏色。標誌檔案可能給你一個十六進位代碼，開發者的樣式表需要 RGB 來實現像 rgba(37, 99, 235, 0.5) 這樣的透明效果，而設計師建立滑鼠懸停狀態時需要 HSL，透過提高明度十個百分點來調亮同一個顏色。在此完成這些步驟可以保持單一真實來源：輸入一次品牌顏色，每種格式都會保持一致，而不會因手動重打與四捨五入誤差而走樣。

1. 從一個顏色建立色盤

從 HSL 中的主色開始，然後固定色相、改變明度：30% 用於深色文字、50% 用於主色、85% 用於淺色背景色調。結果看起來經過設計，而非隨意拼湊。

2. 發布前檢查對比度

淺色背景上的淺色文字是網路上最常見的無障礙失敗。請用色塊一眼判斷，並偏好淺色上的深色文字與飽和深色上的白色文字。

3. 修正來自螢幕截圖的顏色

取色器常回報 RGB 數值。請將它們貼到這裡，取得樣式表用的十六進位代碼，或取得 HSL 數值，以便微調色調，而無需逐一猜測色版。

關於精確度的最後提醒：RGB 與 HSL 之間的換算涉及四捨五入，因為此處的 HSL 百分比是整數，而 RGB 色版也是整數。將顏色換算為 HSL 再換回來，可能使某個色版偏移一個單位，這是肉眼看不出來的，也是每個換算器的正常現象。若你需要印刷用的像素級精確重現，請保留原始的十六進位或 RGB 數值作為主副本。此處的一切都在你的瀏覽器內私下執行，因此你的品牌顏色與色盤絕不會被上傳或儲存。

常見問題（FAQs）

什麼是 HEX 顏色代碼？
HEX 代碼是以井號開頭的六位十六進位簡寫，代表 RGB 數值，例如純紅色的 #FF0000。每對數字分別代表紅、綠、藍，從 00（無）到 FF（全滿，即 255）。像 F00 這樣的三位代碼是簡寫，會將每個數字加倍為 FF0000。
如何將 HEX 換算為 RGB？
將六位十六進位數字分成三對，並將每對從十六進位換算為十進位。對於 #2563EB，25 變為 37、63 變為 99、EB 變為 235，得出 rgb(37, 99, 235)。本換算器會為你雙向完成這種算術。
HSL 中的 H、S、L 是什麼意思？
H 是色相，即色輪上 0 到 360 度的位置，其中 0 是紅色、120 是綠色、240 是藍色。S 是飽和度，從 0% 的灰色到 100% 的全彩。L 是明度，從 0% 的黑色，經過 50% 的純色，到 100% 的白色。
為什麼來回換算會使數值改變 1？
此處的 HSL 百分比會四捨五入為整數，RGB 色版也是整數，因此來回換算可能使某個色版偏移一個單位。這種差異肉眼看不出來。對於需要像素級精確的工作，請保留原始的 HEX 或 RGB 數值作為主副本。
這個換算器可以用於印刷顏色嗎？
對於螢幕設計，可以。印刷使用 CMYK，這是一種以墨水而非光線為基礎的不同模型，因此為印刷換算的螢幕顏色在紙上看起來會不同。請務必使用印刷廠的 CMYK 數值來校對印刷顏色。
我的顏色資料會被儲存嗎？
不會。所有換算都在你的瀏覽器內執行。你輸入的任何內容都不會傳送到伺服器或被儲存。
