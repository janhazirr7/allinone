Paano Gamitin ang OmniTools Password Generator

Ang isang malakas na password ay ang iyong unang linya ng depensa online, ngunit karamihan sa mga tao ay gumagamit pa rin ng maikli, predictable na mga password dahil ang pag-imbento ng bago para sa bawat account ay parang mahirap na trabaho. Inalis ng generator na ito ang pagsisikap na iyon: gumagawa ito ng tunay na random na password para sa iyo, sinusukat kung gaano ito kalakas, at hinahayaan kang kopyahin ito nang diretso sa iyong account o password manager. Walang anumang bagay na nabuo mo ang umalis sa iyong browser, kaya maaari mo itong gamitin nang may kumpiyansa sa iyong sariling device.

  1. Pumili ng haba I-drag ang slider upang itakda ang haba ng password, mula 8 hanggang 64 na character. Nag-a-update ang numero habang hina-drag mo. Para sa mga pang-araw-araw na account, ang 16 na character ay isang makabuluhang default; para sa email, banking at password-manager master password, isaalang-alang ang 20 character o higit pa.
  2. Piliin ang iyong mga set ng character Lagyan ng tsek ang malalaking titik, maliliit na titik, numero at simbolo. Ang bawat set na iyong lagyan ng tsek ay garantisadong lalabas kahit isang beses sa resulta, kaya ang password ay hindi kailanman lumalabas na nawawala ang isang uri na iyong hiniling. Kung tinatanggihan ng isang website ang isang partikular na simbolo, alisin ang check sa mga simbolo at bumuo muli.
  3. Ibukod ang mga hindi maliwanag na character kung kinakailangan Kung kailangan mong magbasa o mag-type ng password gamit ang kamay, lagyan ng tsek ang "Ibukod ang mga hindi maliwanag na character". Inaalis nito ang mga kamukha gaya ng digit 0 at letrang O, at ang digit 1 at maliit na letrang l, na madaling malito sa maraming font.
  4. Bumuo, suriin at kopyahin I-click ang "Bumuo ng Password", o baguhin lang ang anumang kontrol at awtomatikong lilitaw ang isang bagong password. Suriin ang label ng lakas, entropy at tinantyang oras ng pag-crack, pagkatapos ay i-click ang "Kopyahin" at i-paste ang password kung saan ito kinakailangan. I-click ang "I-reset" anumang oras upang bumalik sa mga default at i-clear ang resulta.

Ano ang Nagpapalakas ng Password?

Ang lakas ay bumababa sa dalawang bagay: haba at hindi mahuhulaan. Ang isang maikling password, gayunpaman matalino ang hitsura nito, ay may mas kaunting posibleng mga kumbinasyon kaysa sa isang mahabang random, kaya ang isang umaatake na nanghuhula nang sistematikong ay maaabot ito nang mas maaga. Ang hindi mahuhulaan ay mahalaga din. Madaling hulaan ang mga password na ginawa mula sa mga pangalan, kaarawan, paboritong team o karaniwang salita dahil sinusubukan muna ng mga attacker ang mga diksyunaryo, nag-leak na listahan ng password, at personal na detalye. Ang pagpapalit ng isang titik na may katulad na hitsura na numero, tulad ng pagsulat ng "p@ssw0rd" sa halip na "password", ay hindi nagpapatibay ng isang password, dahil ang mga trick na iyon ay nasa listahan na ng bawat umaatake.

Iniiwasan ng isang random na password ang lahat ng ito. Ang bawat karakter ay pinili nang nakapag-iisa, na walang pattern, salita o personal na kahulugan para samantalahin ng isang umaatake. Nakakatulong din ang paghahalo ng mga uri ng character, dahil pinapalaki nito ang pool ng mga posibleng character sa bawat posisyon. Sa mga malalaking titik, maliliit na titik, mga numero at mga simbolo na pinagsama, ang bawat posisyon ay maaaring isa sa humigit-kumulang 90 magkakaibang mga character, kaya kahit na ang isang katamtamang pagtaas sa haba ay nagpaparami nang malaki sa kabuuang bilang ng mga kumbinasyon. Iyon ang dahilan kung bakit ang mga eksperto sa seguridad ay patuloy na nagrerekomenda ng mahaba, random, natatanging mga password sa maikli, hindi malilimutang mga password, at kung bakit ang isang tagapamahala ng password ay lubhang kapaki-pakinabang: naaalala nito ang mga random na password upang hindi mo na kailanganin.

Mayroon ding mga gawi na nagpapahina kahit isang malakas na password. Ang muling paggamit ng isang password sa ilang site ay nangangahulugan na ang isang paglabag ay naglalantad sa lahat ng ito. Ang pagbabahagi ng mga password sa pamamagitan ng email o chat, pagsusulat ng mga ito sa mga sticky notes, o pag-save sa mga ito sa isang hindi protektadong dokumento ay lumilikha ng mga karagdagang kopya na mahahanap ng umaatake. At ang isang password lamang ay hindi kailanman ang buong kuwento: saanman ang isang site ay nag-aalok ng dalawang-factor na pagpapatotoo, i-on ito, upang ang isang ninakaw na password mismo ay hindi sapat upang mag-sign in bilang ikaw.

Ipinaliwanag ang Entropy sa Plain Language

Ang entropy ay isang solong numero, na sinusukat sa mga piraso, na nagbubuod kung gaano kahirap hulaan ang isang password sa pamamagitan ng malupit na puwersa. Isipin ito bilang ang laki ng haystack na dapat hanapin ng isang umaatake. Ang formula na ginagamit ng tool na ito ay simple at tapat, at ipinapalagay nito na random na nabuo ang password, na kung ano mismo ang ginagawa ng generator na ito:

Entropy (bits) = Haba × log2(Laki ng Pool ng Character)
saan:
• Haba = ang bilang ng mga character sa password
• Sukat ng Pool ng Character = kung gaano karaming iba't ibang mga character ang maaaring lumitaw sa bawat posisyon
• log2 = logarithm base 2

Halimbawa: ang isang 16-character na password gamit ang lahat ng apat na set ay may pool na 89 character. Ang log2(89) ay tungkol sa 6.48, kaya ang entropy nito ay mga 16 × 6.48 = 104 bits. Nangangahulugan iyon ng humigit-kumulang 2^104 na posibleng mga password.

Ang mga label ng lakas sa page na ito ay sumusunod sa marka ng entropy: mas mababa sa 28 bits ay Mahina, mas mababa sa 36 bits ay Fair, mas mababa sa 60 bits ay Malakas, at 60 bits o higit pa ay Napakalakas. Ang isang maikling password na ginawa lamang ng mga maliliit na titik ay madaling mahulog sa hanay ng Mahina, habang ang isang 16-character na password na gumagamit ng lahat ng apat na hanay ng character ay kumportableng umabot sa Very Strong. Ang tinantyang oras ng pag-crack na ipinapakita sa tabi ng marka ay nagsasalin ng entropy sa oras sa bilis na 10 bilyong hula bawat segundo. Iyon ay isang mabilis na umaatake, ngunit ang isang Napakalakas na password ay tumatagal pa rin ng mas matagal kaysa sa isang buhay ng tao upang ma-crack sa ganitong paraan. Tandaan, gayunpaman, ang entropy na iyon ay sumusukat lamang ng paglaban sa bulag na paghula. Hindi nito mapoprotektahan ang isang password na na-leak, na-phish o ginamit muli, kaya naman nananatiling mahalaga ang mga natatanging password at dalawang-factor na pagpapatotoo.

Gumamit ng Password Manager at Huwag Kabisaduhin ang Mga Random na Password

Ang tapat na problema sa malalakas na password ay walang sinuman ang makakasaulo ng dose-dosenang mahaba, random na mga string, at walang sinuman ang dapat sumubok. Malulutas ito ng isang tagapamahala ng password sa pamamagitan ng pag-iimbak ng bawat natatanging password sa isang naka-encrypt na vault na na-unlock mo gamit ang isang malakas na master password, na perpektong protektado ng two-factor na pagpapatotoo. Ang iyong browser o telepono ay maaaring nag-aalok na ng isang built-in, at ang mga dedikadong manager ay nagdaragdag ng mga kapaki-pakinabang na feature gaya ng babala sa iyo kapag may lumabas na password sa isang kilalang paglabag, pagsuri para sa mga muling ginamit na password, at awtomatikong pinupunan ang mga ito upang hindi mo na i-type ang mga ito kung saan maaaring makuha ng pekeng website ang mga ito.

Mukhang ganito ang isang praktikal na gawain. Magsimula sa iyong email account, dahil ang pag-access sa iyong email ay maaaring mag-reset ng maraming iba pang mga account, at bigyan ito ng mahaba, natatanging password at dalawang-factor na pagpapatotoo. Gawin ang parehong para sa pagbabangko, ang iyong password manager mismo at anumang account na naglalaman ng mga detalye ng pagbabayad. Pagkatapos, gawin ang iyong natitirang mga account nang paisa-isa, bumuo ng bagong password para sa bawat isa at i-save ito sa manager bago ka magpatuloy. Kung ang isang serbisyo ay nag-uulat ng isang paglabag, palitan kaagad ang isang password; dahil ito ay kakaiba, walang ibang apektado. Sa paglipas ng panahon, ginagawang simpleng ugali ng routine na ito ang seguridad ng password mula sa isang memory test, at ito ang nag-iisang pinakamabisang hakbang na magagawa ng karamihan sa mga tao para protektahan ang kanilang mga online na account.

Mga Madalas Itanong (FAQs)

Gaano katagal dapat ang isang malakas na password?
Layunin ng hindi bababa sa 16 na character para sa mahahalagang account. Ang mas mahahabang password ay mas mahirap i-crack: ang bawat dagdag na character ay nagpaparami ng bilang ng mga posibleng password sa laki ng pool ng character, kaya ang haba ay mas mahalaga kaysa sa matalinong pagpapalit.
Ang aking nabuong password ba ay ipinadala sa isang server o nakaimbak kahit saan?
Hindi. Ang generator na ito ay ganap na tumatakbo sa iyong browser. Ang iyong password ay hindi kailanman ipinadala sa isang server, nai-save sa isang database, o ibinahagi sa sinuman. Para sa kaligtasan, iwasan pa rin ang pagbuo ng mga password sa isang nakabahagi o hindi pinagkakatiwalaang device.
Ano ang ibig sabihin ng entropy score?
Ang entropy, na sinusukat sa mga bit, ay tinatantya kung gaano hindi mahuhulaan ang isang password. Kinakalkula ito bilang haba ng password na na-multiply sa logarithm base 2 ng laki ng pool ng character. Ang mas mataas na entropy ay nangangahulugan ng mas maraming posibleng kumbinasyon at mas mahabang tinantyang oras ng pag-crack.
Ano ang mga hindi maliwanag na character, at bakit ibubukod ang mga ito?
Magkamukha ang mga hindi maliwanag na character sa maraming font, gaya ng digit 0 at letrang O, o ang digit 1 at maliit na titik l. Ang pagbubukod sa mga ito ay ginagawang mas madaling basahin at i-type nang tama ang isang password kapag kinopya mo ito sa pamamagitan ng kamay.
Dapat ko bang gamitin muli ang parehong password para sa ilang account?
Hindi. Kung ang isang site ay nilabag, ang bawat iba pang account na gumagamit ng parehong password ay magiging mahina. Gumamit ng natatanging password para sa bawat account at iimbak ang mga ito sa isang kagalang-galang na tagapamahala ng password, na naka-on ang two-factor na pagpapatotoo saanman ito inaalok.
