Paano Gamitin ang Tagabuo ng Password ng OmniTools

Ang isang malakas na password ang iyong unang linya ng depensa online, ngunit karamihan sa mga tao ay muling gumagamit pa rin ng maiikli at nahuhulaang password dahil ang pag-imbento ng isang bago para sa bawat account ay parang mahirap na trabaho. Inaalis ng generator na ito ang pagsisikap na iyan: lumilikha ito ng isang tunay na random na password para sa iyo, sinusukat kung gaano ito kalakas, at hinahayaan kang kopyahin ito nang direkta sa iyong account o password manager. Walang anumang binuo mo ang kailanman umaalis sa iyong browser, kaya maaari mo itong gamitin nang may kumpiyansa sa iyong sariling device.

  1. Pumili ng haba I-drag ang slider upang itakda ang haba ng password, mula 8 hanggang 64 na karakter. Ang numero ay nag-a-update habang nag-drag ka. Para sa mga pang-araw-araw na account, ang 16 na karakter ay isang makatuwirang default; para sa email, banking at master password ng password manager, isaalang-alang ang 20 karakter o higit pa.
  2. Piliin ang iyong mga character set Lagyan ng tsek ang mga uppercase na letra, lowercase na letra, numero at simbolo. Ang bawat set na iyong tsekan ay garantisadong lilitaw nang hindi bababa sa isang beses sa resulta, kaya ang password ay hindi kailanman lalabas na kulang sa isang uri na iyong hiniling. Kung tinatanggihan ng isang website ang isang partikular na simbolo, alisin ang tsek sa mga simbolo at bumuo muli.
  3. Huwag isama ang mga ambiguous na karakter kung kinakailangan Kung kailangan mo kailanmang basahin o i-type ang isang password nang manu-mano, lagyan ng tsek ang "Huwag isama ang mga ambiguous na karakter". Inaalis nito ang mga kamukha tulad ng digit na 0 at letrang O, at ang digit na 1 at lowercase na letrang l, na madaling malito sa maraming font.
  4. Bumuin, suriin at kopyahin I-click ang "Bumuong Password", o baguhin lamang ang anumang control at ang isang sariwang password ay awtomatikong lumalabas. Suriin ang label ng lakas, entropy at tinatayang oras ng pag-crack, pagkatapos ay i-click ang "Kopyahin" at i-paste ang password kung saan ito kailangan. I-click ang "I-reset" anumang oras upang bumalik sa mga default at linisin ang resulta.

Ano ang Nagpapalakas sa isang Password?

Ang lakas ay nakasalalay sa dalawang bagay: haba at hindi mahuhulaan. Ang isang maikling password, gaano man ito katalino tingnan, ay may mas kaunting posibleng kombinasyon kaysa sa isang mahabang random, kaya mas maaga itong maaabot ng isang attacker na sistematikong nanghuhula. Ang hindi mahuhulaan ay kasinghalaga rin. Ang mga password na binuo mula sa mga pangalan, kaarawan, paboritong team o karaniwang salita ay madaling hulaan dahil sinusubukan muna ng mga attacker ang mga diksyunaryo, listahan ng mga leaked na password at personal na detalye. Ang pagpapalit ng isang letra ng isang kamukhang numero, tulad ng pagsulat ng "p@ssw0rd" sa halip na "password", ay hindi nagpapalakas sa isang password, dahil ang mga trick na iyan ay nasa listahan na ng bawat attacker.

Iniiwasan ng isang random na password ang lahat ng ito. Ang bawat karakter ay pinipili nang mag-isa, nang walang pattern, salita o personal na kahulugan na maaaring samantalahin ng isang attacker. Nakakatulong din ang paghahalo ng mga uri ng karakter, dahil pinalalaki nito ang pool ng mga posibleng karakter sa bawat posisyon. Sa pinagsamang mga uppercase na letra, lowercase na letra, numero at simbolo, ang bawat posisyon ay maaaring isa sa humigit-kumulang 90 magkakaibang karakter, kaya kahit ang isang katamtamang pagtaas sa haba ay nagpaparami nang malaki sa kabuuang bilang ng mga kombinasyon. Kaya pare-parehong inirerekomenda ng mga eksperto sa seguridad ang mahahaba, random, at natatanging password kaysa sa maiikli at madaling tandaan, at kaya napakagamit ng isang password manager: natatandaan nito ang mga random na password upang hindi mo na kailangang gawin ito.

May mga gawi rin na nagpapahina kahit sa isang malakas na password. Ang muling paggamit ng isang password sa ilang site ay nangangahulugang ang isang paglabag ay naglalantad sa lahat ng mga ito. Ang pagbabahagi ng mga password sa pamamagitan ng email o chat, pagsulat ng mga ito sa sticky notes, o pag-save ng mga ito sa isang hindi protektadong dokumento ay lumilikha ng mga karagdagang kopya na maaaring mahanap ng isang attacker. At ang isang password lamang ay hindi kailanman ang buong kuwento: saanman nag-aalok ang isang site ng two-factor authentication, i-on ito, upang ang isang ninakaw na password lamang ay hindi sapat upang mag-sign in bilang ikaw.

Ipinaliwanag ang Entropy sa Payak na Wika

Ang entropy ay isang numero, na sinusukat sa bits, na nagbubuod kung gaano kahirap hulaan ang isang password sa pamamagitan ng brute force. Isipin ito bilang laki ng haystack na dapat hanapin ng isang attacker. Ang formula na ginagamit ng tool na ito ay simple at tapat, at ipinapalagay nito na ang password ay nabuo nang random, na eksaktong ginagawa ng generator na ito:

Entropy (bits) = Haba × log2(Laki ng Pool ng Karakter)
Saan:
• Haba = ang bilang ng mga karakter sa password
• Laki ng Pool ng Karakter = kung ilang magkakaibang karakter ang maaaring lumitaw sa bawat posisyon
• log2 = logarithm na may base 2

Halimbawa: ang isang 16-karakter na password na gumagamit ng lahat ng apat na set ay may pool na 89 karakter. Ang log2(89) ay humigit-kumulang 6.48, kaya ang entropy nito ay humigit-kumulang 16 × 6.48 = 104 bits. Ibig sabihin, humigit-kumulang 2^104 na posibleng password.

Ang mga label ng lakas sa page na ito ay sumusunod sa entropy score: mas mababa sa 28 bits ay Mahina, mas mababa sa 36 bits ay Katamtaman, mas mababa sa 60 bits ay Malakas, at 60 bits o higit pa ay Napakalakas. Ang isang maikling password na binubuo lamang ng mga lowercase na letra ay madaling mahulog sa saklaw na Mahina, samantalang ang isang 16-karakter na password na gumagamit ng lahat ng apat na character set ay kumportableng umaabot sa Napakalakas. Ang tinatayang oras ng pag-crack na ipinapakita sa tabi ng score ay nagsasalin ng entropy sa oras sa rate na 10 bilyong hula kada segundo. Iyan ay isang mabilis na attacker, ngunit ang isang Napakalakas na password ay nangangailangan pa rin ng mas mahaba kaysa sa buhay ng tao upang ma-crack sa ganitong paraan. Tandaan, gayunpaman, na ang entropy ay sumusukat lamang sa paglaban sa bulag na panghuhula. Hindi nito mapoprotektahan ang isang password na na-leak, na-phish o muling ginamit, kaya ang mga natatanging password at two-factor authentication ay nananatiling mahalaga.

Gumamit ng Password Manager at Huwag Kailanman Kabisaduhin ang mga Random na Password

Ang tapat na problema sa malalakas na password ay walang sinuman ang makakakabisado ng dose-dosenang mahahaba at random na string, at walang sinuman ang dapat sumubok. Nalulutas ito ng isang password manager sa pamamagitan ng pag-iimbak ng bawat natatanging password sa isang naka-encrypt na vault na binubuksan mo gamit ang isang malakas na master password, na mainam na protektado ng two-factor authentication. Ang iyong browser o telepono ay maaaring mayroon nang built in, at ang mga dedikadong manager ay nagdaragdag ng mga kapaki-pakinabang na tampok tulad ng pagbababala sa iyo kapag ang isang password ay lumitaw sa isang kilalang breach, pagsusuri para sa mga muling ginamit na password, at awtomatikong pag-fill in ng mga ito upang hindi mo kailanman i-type ang mga ito kung saan maaaring makuha ang mga ito ng isang pekeng website.

Ang isang praktikal na routine ay ganito. Magsimula sa iyong email account, dahil ang pag-access sa iyong email ay maaaring mag-reset ng maraming iba pang account, at bigyan ito ng isang mahaba at natatanging password kasama ang two-factor authentication. Gawin din ito para sa banking, sa mismong password manager mo at sa anumang account na may hawak na mga detalye sa pagbabayad. Pagkatapos ay pagdaanan ang iyong mga natitirang account nang paunti-unti, na bumubuo ng isang sariwang password para sa bawat isa at sine-save ito sa manager bago ka magpatuloy. Kung ang isang serbisyo ay kailanmang mag-ulat ng isang breach, baguhin kaagad ang password na iyon; dahil ito ay natatangi, walang ibang naapektuhan. Sa paglipas ng panahon, ginagawa ng routine na ito ang seguridad ng password mula sa isang pagsubok sa memorya tungo sa isang simpleng gawi, at ito ang nag-iisang pinakamabisang hakbang na maaaring gawin ng karamihan sa mga tao upang protektahan ang kanilang mga online account.

Mga Madalas Itanong (FAQs)

Gaano kahaba dapat ang isang malakas na password?
Layunin ang hindi bababa sa 16 na karakter para sa mahahalagang account. Ang mas mahahabang password ay exponentially na mas mahirap i-crack: ang bawat karagdagang karakter ay nagpaparami sa bilang ng mga posibleng password sa laki ng character pool, kaya ang haba ay mas mahalaga kaysa sa matatalinong pagpapalit.
Naipapadala ba sa isang server o iniimbak kahit saan ang aking nabuong password?
Hindi. Ang generator na ito ay ganap na tumatakbo sa iyong browser. Ang iyong password ay hindi kailanman ipinapadala sa isang server, naka-save sa isang database, o ibinabahagi sa sinuman. Para sa kaligtasan, iwasan pa ring bumuo ng mga password sa isang pinagsasaluhang o hindi pinagkakatiwalaang device.
Ano ang ibig sabihin ng entropy score?
Ang entropy, na sinusukat sa bits, ay nagtatantya kung gaano hindi mahuhulaan ang isang password. Kinakalkula ito bilang haba ng password na iminultiply sa logarithm base 2 ng laki ng character pool. Ang mas mataas na entropy ay nangangahulugang mas maraming posibleng kombinasyon at isang mas mahabang tinatayang oras ng pag-crack.
Ano ang mga ambiguous na karakter, at bakit sila dapat ibukod?
Ang mga ambiguous na karakter ay magkamukha sa maraming font, tulad ng digit na 0 at letrang O, o ang digit na 1 at lowercase na letrang l. Ang pagbubukod sa mga ito ay nagpapadali sa pagbabasa at pag-type ng isang password nang tama kapag kinokopya mo ito nang manu-mano.
Dapat ko bang muling gamitin ang parehong password sa ilang account?
Hindi. Kung ang isang site ay nalabag, ang bawat iba pang account na gumagamit ng parehong password ay nagiging mahina. Gumamit ng isang natatanging password para sa bawat account at iimbak ang mga ito sa isang kagalang-galang na password manager, na may two-factor authentication na naka-on saanman ito inaalok.
