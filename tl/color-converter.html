Paano Gamitin ang Color Converter

Ang mga designer, developer, at printer ay naglalarawan ng parehong kulay sa iba't ibang wika. Ang isang web developer ay nagsusulat ng #2563EB, isang print designer ang nag-iisip sa mga porsyento ng cyan at magenta, at isang CSS author na nagsasaayos ng brightness na umaabot para sa HSL. Ang pag-convert sa pagitan ng mga format na ito sa pamamagitan ng kamay ay mabagal at madaling magkamali, lalo na sa mga matematika sa likod ng HSL. Ginagawa ito kaagad ng converter na ito: maglagay ng kulay sa alinmang isang format at tingnan ang tatlo nang sabay-sabay, na may live na swatch para mahusgahan mo ang resulta gamit ang iyong mga mata, hindi lamang mga numero.

  1. Magsimula sa HEXMag-type ng hex code na mayroon o walang hash, halimbawa #FF0000 o 2563EB, at pindutin ang I-convert mula sa HEX. Ang tatlong-digit na shorthand tulad ng F00 ay gumagana din at lumalawak sa FF0000.
  2. O magsimula sa RGBIlagay ang pula, berde, at asul na mga channel, bawat isa mula 0 hanggang 255, at pindutin ang I-convert mula sa RGB. Ito ay madaling gamitin kapag ang isang tool sa disenyo o isang tagapili ng screenshot ay nagbibigay sa iyo ng mga halaga ng RGB.
  3. O magsimula sa HSLMaglagay ng kulay mula 0 hanggang 360 degrees, kasama ang saturation at lightness bilang mga porsyento, at pindutin ang I-convert mula sa HSL. Ang HSL ay ang pinakamadaling format para sa paggawa ng mas magaan o mas madidilim na mga bersyon ng isang kulay.
  4. Kopyahin ang kailangan moAng mga na-convert na halaga ay lilitaw sa ibaba, kasama ang copy-ready na CSS. Nag-a-update ang preview swatch mula sa anumang input, para malaya kang makapag-eksperimento at mapanood ang pagbabago ng kulay.

Ipinaliwanag ang HEX, RGB, at HSL

Ang HEX ay shorthand ng web para sa RGB. Ang bawat pares ng hexadecimal digit ay kumakatawan sa isang channel: ang unang pares ay pula, ang pangalawang berde, ang ikatlong asul. Ang FF0000 ay samakatuwid ay purong pula, 00FF00 purong berde, at 000000 itim, habang ang FFFFFF ay puti. Gumagamit ang hexadecimal ng mga digit na 0 hanggang 9 kasama ang mga letrang A hanggang F, kung saan ang A ay nangangahulugang 10 at F ay nangangahulugang 15, kaya naman ang dalawang hex na digit ay maaaring kumatawan sa bawat halaga mula 0 hanggang 255. Ang tatlong-digit na shorthand ay nagdodoble lamang sa bawat digit, kaya ang F00 ay nagiging FF0000 at ang 369 ay nagiging 336699.

Inilalarawan ng RGB ang kulay bilang liwanag: kung gaano karaming pula, berde, at asul na ilaw ang paghaluin. Ang mga screen ay naglalabas ng liwanag, kaya ang pagdaragdag ng lahat ng tatlong channel nang buong lakas ay nagbubunga ng puti, at ang pag-off sa lahat ay nagbubunga ng itim. Ang additive model na iyon ay intuitive para sa mga screen ngunit awkward para sa mga taong sinusubukang ayusin ang isang kulay, dahil ang pagbabago ng liwanag ay nangangahulugan ng pagbabago sa lahat ng tatlong numero nang sabay-sabay. Inaayos iyon ng HSL sa pamamagitan ng paglalarawan ng kulay sa paraan ng pag-iisip ng mga tao tungkol dito: ang hue ay ang posisyon sa paligid ng color wheel sa mga degree, kung saan ang 0 ay pula, 120 ay berde, at 240 ay asul; ang saturation ay kung gaano katingkad ang kulay, mula sa kulay abo sa 0% hanggang sa buong kulay sa 100%; at ang liwanag ay tumatakbo mula sa itim sa 0% hanggang sa purong kulay sa 50% hanggang puti sa 100%.

HEX #RRGGBB = RGB (pula, berde, asul), bawat isa ay 0-255

Mga halimbawa: ang purong pula ay #FF0000 = rgb(255, 0, 0) = hsl(0, 100%, 50%). Ang purong berde ay #00FF00 = rgb(0, 255, 0) = hsl(120, 100%, 50%). Ang grey ay may 0% saturation sa anumang kulay.

Mga Praktikal na Paggamit at Mga Tip sa Accessibility

Ang pinakakaraniwang gawain sa conversion ay ang paglipat ng kulay ng brand sa pagitan ng mga tool. Ang isang logo na file ay maaaring magbigay sa iyo ng hex code, ang stylesheet ng developer ay nangangailangan ng RGB para sa mga transparency effect tulad ng rgba(37, 99, 235, 0.5), at ang isang taga-disenyo na gumagawa ng hover state ay nangangailangan ng HSL upang lumiwanag ang parehong kulay sa pamamagitan ng pagpapataas ng liwanag ng sampung puntos. Ang paggawa ng mga hakbang na iyon dito ay nagpapanatili ng isang mapagkukunan ng katotohanan: i-type ang kulay ng brand nang isang beses, at ang bawat format ay mananatiling pare-pareho sa halip na dumaan sa manu-manong muling pag-type at mga error sa pag-round.

1. Bumuo ng palette mula sa isang kulay

Magsimula sa iyong pangunahing kulay sa HSL, pagkatapos ay panatilihing maayos ang kulay at iba-iba ang liwanag: 30% para sa madilim na teksto, 50% para sa pangunahing kulay, 85% para sa isang maputlang kulay ng background. Ang resulta ay mukhang dinisenyo, hindi random.

2. Suriin ang contrast bago ipadala

Ang magaan na text sa isang maliwanag na background ay ang pinakakaraniwang pagkabigo sa accessibility sa web. Gamitin ang swatch upang hatulan sa isang sulyap, at mas gusto ang madilim na teksto sa maputlang kulay at puting teksto sa puspos na madilim na kulay.

3. Ayusin ang mga kulay mula sa mga screenshot

Ang mga tagapili ng kulay ay madalas na nag-uulat ng mga halaga ng RGB. I-paste ang mga ito dito para makuha ang hex code para sa iyong stylesheet, o ang mga halaga ng HSL para i-fine-tune ang shade nang hindi hinuhulaan ang channel ayon sa channel.

Ang huling tala sa katumpakan: ang pag-convert sa pagitan ng RGB at HSL ay nagsasangkot ng pag-ikot, dahil ang mga porsyento ng HSL ay mga buong numero dito habang ang mga RGB channel ay mga integer. Ang pag-convert ng kulay sa HSL at likod ay maaaring maglipat ng channel ng isang unit, na hindi nakikita ng mata at normal para sa bawat converter. Kung kailangan mo ng pixel-perfect reproduction para sa pag-print, panatilihin ang orihinal na mga halaga ng hex o RGB bilang iyong master copy. Lahat dito ay tumatakbo nang pribado sa iyong browser, kaya ang mga kulay at palette ng iyong brand ay hindi kailanman ina-upload o iniimbak.

Mga Madalas Itanong (FAQs)

Ano ang code ng kulay ng HEX?
Ang HEX code ay isang anim na digit na hexadecimal na shorthand para sa mga halaga ng RGB, na nakasulat na may nangungunang hash, tulad ng #FF0000 para sa purong pula. Ang bawat pares ng mga digit ay kumakatawan sa pula, berde, at asul, mula 00 (wala) hanggang FF (buo, o 255). Ang mga tatlong-digit na code tulad ng F00 ay shorthand na nagdodoble sa bawat digit sa FF0000.
Paano ko iko-convert ang HEX sa RGB?
Hatiin ang anim na hex digit sa tatlong pares at i-convert ang bawat pares mula hexadecimal hanggang decimal. Para sa #2563EB, ang 25 ay nagiging 37, ang 63 ay naging 99, at ang EB ay naging 235, na nagbibigay ng rgb(37, 99, 235). Ginagawa ng converter na ito ang aritmetika para sa iyo sa alinmang direksyon.
Ano ang ibig sabihin ng H, S, at L sa HSL?
Ang H ay hue, ang posisyon sa color wheel mula 0 hanggang 360 degrees, kung saan 0 ay pula, 120 ay berde, at 240 ay asul. Ang S ay saturation, mula 0% gray hanggang 100% na ganap na matingkad. L ay magaan, mula 0% itim hanggang 50% purong kulay hanggang 100% puti.
Bakit binabago ng pabalik-balik ang isang halaga ng 1?
Ang mga porsyento ng HSL ay ni-round sa buong mga numero dito, at ang mga RGB channel ay mga integer, kaya ang isang round trip ay maaaring maglipat ng channel ng isang unit. Ang pagkakaiba ay hindi nakikita ng mata. Panatilihin ang iyong orihinal na halaga ng HEX o RGB bilang master copy para sa pixel-perfect na gawa.
Maaari ko bang gamitin ang converter na ito para sa mga kulay ng pag-print?
Para sa disenyo ng screen, oo. Ang pag-print ay gumagamit ng CMYK, isang ibang modelo batay sa tinta sa halip na liwanag, kaya ang isang kulay ng screen na na-convert para sa pag-print ay magiging iba ang hitsura sa papel. Palaging patunay ang mga kulay ng pag-print gamit ang mga halaga ng CMYK ng iyong printer.
Nakaimbak ba ang data ng kulay ko?
Hindi. Tumatakbo ang lahat ng conversion sa iyong browser. Walang ipinadala sa isang server o iniimbak ang anumang ipinasok mo.
