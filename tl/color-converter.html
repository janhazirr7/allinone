Paano Gamitin ang Converter ng Kulay

Ang mga designer, developer, at printer ay naglalarawan lahat sa iisang kulay sa iba't ibang wika. Ang isang web developer ay sumusulat ng #2563EB, ang isang print designer ay nag-iisip sa porsyento ng cyan at magenta, at ang isang CSS author na nag-aayos ng liwanag ay gumagamit ng HSL. Ang pag-convert sa pagitan ng mga format na ito nang manu-mano ay mabagal at madaling magkamali, lalo na sa matematika sa likod ng HSL. Ginagawa ito ng converter na ito kaagad: maglagay ng kulay sa anumang format at makita ang lahat ng tatlo nang sabay, na may live na swatch upang mahusgahan mo ang resulta gamit ang iyong mga mata, hindi lamang mga numero.

  1. Magsimula sa HEXMag-type ng hex code na mayroon o walang hash, halimbawa #FF0000 o 2563EB, at pindutin ang I-convert mula sa HEX. Gumagana rin ang three-digit shorthand tulad ng F00 at lumalawak ito sa FF0000.
  2. O magsimula sa RGBIlagay ang red, green, at blue na mga channel, bawat isa mula 0 hanggang 255, at pindutin ang I-convert mula sa RGB. Maginhawa ito kapag ang isang design tool o isang screenshot picker ay nagbibigay sa iyo ng mga RGB value.
  3. O magsimula sa HSLIlagay ang hue mula 0 hanggang 360 degrees, kasama ang saturation at lightness bilang mga porsyento, at pindutin ang I-convert mula sa HSL. Ang HSL ang pinakamadaling format para sa paggawa ng mas maliwanag o mas madilim na bersyon ng isang kulay.
  4. Kopyahin ang kailangan moAng mga na-convert na value ay lumalabas sa ibaba, kasama ang CSS na handa nang kopyahin. Ang preview swatch ay nag-a-update mula sa anumang input, kaya maaari kang mag-eksperimento nang malaya at panoorin ang pagbabago ng kulay.

Ipinaliwanag ang HEX, RGB, at HSL

Ang HEX ay ang shorthand ng web para sa RGB. Ang bawat pares ng hexadecimal digit ay kumakatawan sa isang channel: ang unang pares ay pula, ang ikalawa ay berde, ang ikatlo ay asul. Ang FF0000 samakatuwid ay purong pula, ang 00FF00 ay purong berde, at ang 000000 ay itim, samantalang ang FFFFFF ay puti. Gumagamit ang hexadecimal ng mga digit na 0 hanggang 9 kasama ang mga letrang A hanggang F, kung saan ang A ay nangangahulugang 10 at ang F ay nangangahulugang 15, kaya ang dalawang hex digit ay maaaring kumatawan sa bawat value mula 0 hanggang 255. Ang three-digit shorthand ay dinodoble lamang ang bawat digit, kaya ang F00 ay nagiging FF0000 at ang 369 ay nagiging 336699.

Inilalarawan ng RGB ang kulay bilang liwanag: kung gaano karaming pula, berde, at asul na liwanag ang paghahaluin. Ang mga screen ay naglalabas ng liwanag, kaya ang pagdaragdag ng lahat ng tatlong channel sa buong lakas ay lumilikha ng puti, at ang pagpatay sa lahat ng ito ay lumilikha ng itim. Ang additive na modelong ito ay madaling maunawaan para sa mga screen ngunit mahirap para sa mga taong sinusubukang ayusin ang isang kulay, dahil ang pagbabago ng liwanag ay nangangahulugang baguhin ang lahat ng tatlong numero nang sabay. Inaayos ito ng HSL sa pamamagitan ng paglalarawan ng kulay sa paraang iniisip ito ng mga tao: ang hue ay ang posisyon sa paligid ng color wheel sa degrees, kung saan ang 0 ay pula, ang 120 ay berde, at ang 240 ay asul; ang saturation ay kung gaano katingkad ang kulay, mula sa grey sa 0% hanggang sa buong kulay sa 100%; at ang lightness ay tumatakbo mula sa itim sa 0% sa pamamagitan ng purong kulay sa 50% hanggang sa puti sa 100%.

HEX #RRGGBB = RGB (pula, berde, asul), bawat isa 0-255

Mga halimbawa: ang purong pula ay #FF0000 = rgb(255, 0, 0) = hsl(0, 100%, 50%). Ang purong berde ay #00FF00 = rgb(0, 255, 0) = hsl(120, 100%, 50%). Ang grey ay may 0% saturation sa anumang hue.

Mga Praktikal na Gamit at Tip sa Accessibility

Ang pinakakaraniwang gawain sa conversion ay ang paglipat ng kulay ng brand sa pagitan ng mga tool. Ang isang logo file ay maaaring magbigay sa iyo ng isang hex code, ang stylesheet ng isang developer ay nangangailangan ng RGB para sa mga transparency effect tulad ng rgba(37, 99, 235, 0.5), at ang isang designer na gumagawa ng hover state ay nangangailangan ng HSL upang paliwanagin ang iisang kulay sa pamamagitan ng pagtaas ng lightness ng sampung puntos. Ang paggawa ng mga hakbang na ito dito ay nagpapanatili ng isang source of truth: i-type ang kulay ng brand nang isang beses, at ang bawat format ay nananatiling pare-pareho sa halip na mag-iba dahil sa manu-manong pag-type muli at mga rounding error.

1. Bumuo ng palette mula sa isang kulay

Magsimula sa iyong pangunahing kulay sa HSL, pagkatapos ay panatilihing nakapirmi ang hue at baguhin ang lightness: 30% para sa madilim na text, 50% para sa pangunahing kulay, 85% para sa maputlang background tint. Ang resulta ay mukhang dinisenyo, hindi random.

2. Suriin ang contrast bago mag-ship

Ang maliwanag na text sa maliwanag na background ang pinakakaraniwang pagkabigo sa accessibility sa web. Gamitin ang swatch upang humusga sa isang tingin, at mas piliin ang madilim na text sa mapuputlang kulay at puting text sa mga puspos na madilim na kulay.

3. Ayusin ang mga kulay mula sa mga screenshot

Ang mga color picker ay madalas na nag-uulat ng mga RGB value. I-paste ang mga ito dito upang makuha ang hex code para sa iyong stylesheet, o ang mga HSL value upang ayusin ang shade nang hindi nanghuhula kada channel.

Isang huling paalala tungkol sa katumpakan: ang pag-convert sa pagitan ng RGB at HSL ay may kasamang rounding, dahil ang mga porsyento ng HSL ay buong numero dito samantalang ang mga channel ng RGB ay mga integer. Ang pag-convert ng isang kulay sa HSL at pabalik ay maaaring magbago ng isang channel ng isang unit, na hindi nakikita ng mata at normal para sa bawat converter. Kung kailangan mo ng pixel-perfect na reproduksyon para sa print, panatilihin ang orihinal na hex o RGB value bilang iyong master copy. Ang lahat dito ay tumatakbo nang pribado sa iyong browser, kaya ang iyong mga kulay ng brand at palette ay hindi kailanman ina-upload o iniimbak.

Mga Madalas Itanong (FAQs)

Ano ang HEX color code?
Ang HEX code ay isang six-digit na hexadecimal shorthand para sa mga RGB value, na isinusulat na may nangungunang hash, tulad ng #FF0000 para sa purong pula. Ang bawat pares ng digit ay kumakatawan sa pula, berde, at asul, mula 00 (wala) hanggang FF (buo, o 255). Ang mga three-digit code tulad ng F00 ay shorthand na dinodoble ang bawat digit upang maging FF0000.
Paano ko iko-convert ang HEX sa RGB?
Hatiin ang anim na hex digit sa tatlong pares at i-convert ang bawat pares mula hexadecimal patungong decimal. Para sa #2563EB, ang 25 ay nagiging 37, ang 63 ay nagiging 99, at ang EB ay nagiging 235, na nagbibigay ng rgb(37, 99, 235). Ginagawa ng converter na ito ang arithmetic na iyan para sa iyo sa alinmang direksyon.
Ano ang ibig sabihin ng H, S, at L sa HSL?
Ang H ay hue, ang posisyon sa color wheel mula 0 hanggang 360 degrees, kung saan ang 0 ay pula, ang 120 ay berde, at ang 240 ay asul. Ang S ay saturation, mula 0% grey hanggang 100% ganap na matingkad. Ang L ay lightness, mula 0% itim sa pamamagitan ng 50% purong kulay hanggang 100% puti.
Bakit nagbabago ng 1 ang isang value kapag nag-convert pabalik-balik?
Ang mga porsyento ng HSL ay naka-round sa buong numero dito, at ang mga channel ng RGB ay mga integer, kaya ang isang round trip ay maaaring magbago ng isang channel ng isang unit. Hindi nakikita ng mata ang pagkakaiba. Panatilihin ang iyong orihinal na HEX o RGB value bilang master copy para sa pixel-perfect na trabaho.
Maaari ko bang gamitin ang converter na ito para sa mga kulay sa print?
Para sa disenyo sa screen, oo. Gumagamit ang print ng CMYK, isang ibang modelo batay sa tinta sa halip na liwanag, kaya ang isang kulay sa screen na na-convert para sa print ay magmumukhang iba sa papel. Palaging i-proof ang mga kulay sa print gamit ang mga CMYK value ng iyong printer.
Naka-save ba ang aking datos ng kulay?
Hindi. Ang lahat ng conversion ay tumatakbo sa iyong browser. Walang anumang inilagay mo ang ipinapadala sa isang server o iniimbak.
