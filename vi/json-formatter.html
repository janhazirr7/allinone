  1. Dán JSON của bạnSao chép JSON từ API, tệp cấu hình hay hướng dẫn và dán vào ô lớn.
  2. Chọn hành độngNhấn Định dạng để dễ đọc với thụt lề, Thu gọn để thu thành một dòng, hoặc Chỉ kiểm tra để kiểm tra mà không thay đổi.
  3. Đọc lỗi nếu cóNếu JSON không hợp lệ, công cụ hiển thị lỗi chính xác từ trình phân tích bằng ngôn ngữ đơn giản, để bạn biết cần sửa gì.
  4. Sao chép kết quảDùng Sao chép đầu ra để đưa JSON đã định dạng hay thu gọn trở lại mã, cấu hình hay công cụ API của bạn.

JSON là gì và vì sao định dạng quan trọng

JSON, viết tắt của JavaScript Object Notation, là cách phổ biến nhất máy tính trao đổi dữ liệu có cấu trúc trên web. API, tệp cấu hình và nhiều ứng dụng đều nói JSON vì nó đơn giản để đọc và máy dễ phân tích. Tài liệu JSON hợp lệ được xây từ đối tượng trong dấu ngoặc nhọn, mảng trong dấu ngoặc vuông, chuỗi trong dấu ngoặc kép, số, và các giá trị true, false và null. Định dạng không thay đổi ý nghĩa dữ liệu, nhưng thay đổi mức độ dễ đọc với con người. JSON thu gọn, với mọi khoảng trắng bị loại, nhỏ hơn và gửi qua mạng nhanh hơn, đó là lý do API dùng nó, nhưng gần như không thể đọc hay gỡ lỗi. JSON làm đẹp, với thụt lề hai khoảng trắng và một giá trị mỗi dòng, lớn hơn nhưng cho bạn phát hiện dấu phẩy thiếu hay dấu ngoặc sai trong vài giây.

Lỗi JSON thường gặp nhất

  • Thiếu hoặc thừa dấu phẩy: mọi mục trong đối tượng hay mảng trừ mục cuối cần dấu phẩy, và dấu phẩy cuối sau mục cuối không được phép trong JSON nghiêm ngặt.
  • Dấu nháy đơn thay vì nháy kép: chuỗi JSON phải dùng dấu nháy kép, dù mã JavaScript thường cho phép nháy đơn.
  • Khóa không có dấu nháy: khóa đối tượng phải là chuỗi có dấu nháy, nên {name: "Ana"} không hợp lệ và phải là {"name": "Ana"}.
  • Chú thích: JSON không cho phép chú thích, nên dòng bắt đầu bằng // sẽ làm hỏng phân tích dù trông vô hại.
  • Văn bản thừa hay nhiều tài liệu: dán hai đối tượng JSON liên tiếp là không hợp lệ; hãy bọc chúng trong mảng hoặc sửa từng cái một.

Định dạng và thu gọn: Khi nào dùng cái nào

Dùng Định dạng khi bạn đang đọc, gỡ lỗi hay học từ JSON, vì thụt lề phô bày cấu trúc ngay và làm rõ lồng nhau. Dùng Thu gọn khi bạn cần dán JSON vào URL, ô cấu hình gọn, yêu cầu thử nghiệm hay tin nhắn nơi kích thước quan trọng và dễ đọc không quan trọng. Dùng Chỉ kiểm tra khi bạn chỉ cần đáp án có hay không, ví dụ trước khi lưu tệp cấu hình, vì nó kiểm tra JSON mà không thay văn bản gốc của bạn. Trong cả ba trường hợp công cụ phân tích JSON trước, nên kết quả thu gọn hay định dạng đảm bảo hợp lệ; nếu phân tích thất bại, bạn nhận lỗi thay vì đầu ra hỏng âm thầm, đúng điều bạn muốn trước khi xuất mã.

Riêng tư và giới hạn

Công cụ định dạng này chạy hoàn toàn trong trình duyệt của bạn. JSON của bạn không bao giờ bị tải lên, ghi nhật ký hay chia sẻ, điều này quan trọng vì JSON thường chứa khóa API, dữ liệu cá nhân hay cấu hình nội bộ. Không bao giờ dán bí mật vào bất kỳ công cụ định dạng trực tuyến nào bạn không tin tưởng, và xoay vòng mọi khóa bạn vô tình lộ. Công cụ xử lý dễ dàng phản hồi API và tệp cấu hình thông thường, nhưng tài liệu cực lớn, hàng chục megabyte, có thể chậm trong tab trình duyệt vì phân tích và chuyển lại thành chuỗi tốn bộ nhớ. Nó cũng tuân theo quy tắc JSON nghiêm ngặt, nên sẽ từ chối phần thêm kiểu JavaScript như dấu phẩy cuối, nháy đơn và chú thích, dù một số công cụ chấp nhận lỏng lẻo.

Câu hỏi thường gặp (FAQs)

Định dạng và thu gọn khác nhau như thế nào?
Định dạng thêm thụt lề và ngắt dòng để JSON dễ đọc với con người. Thu gọn loại bỏ mọi khoảng trắng và ngắt dòng không cần thiết để JSON nhỏ nhất có thể để gửi hay lưu trữ.
Vì sao JSON của tôi lỗi dấu phẩy cuối?
JSON nghiêm ngặt không cho phép dấu phẩy sau mục cuối trong đối tượng hay mảng. Loại dấu phẩy cuối đó và JSON sẽ phân tích được.
Tôi có thể dùng dấu nháy đơn trong JSON không?
Không. Chuỗi và khóa JSON phải dùng dấu nháy kép. Nháy đơn dùng được trong mã JavaScript, nhưng không hợp lệ trong JSON và công cụ này sẽ từ chối đúng.
Dữ liệu JSON của tôi có bị lưu hay gửi đi đâu không?
Không. Định dạng và kiểm tra chạy hoàn toàn trong trình duyệt của bạn, nên dữ liệu của bạn không bao giờ rời khỏi thiết bị.
Định dạng có thay đổi dữ liệu của tôi không?
Không. Định dạng và thu gọn chỉ thay đổi khoảng cách và ngắt dòng. Giá trị, khóa và cấu trúc giữ nguyên chính xác, miễn là JSON hợp lệ ngay từ đầu.
