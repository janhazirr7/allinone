Qué es JSON y por qué importa el formato

JSON, abreviatura de JavaScript Object Notation, es la forma más común en que los ordenadores intercambian datos estructurados en la web. Las API, los archivos de configuración y muchas aplicaciones hablan JSON porque es sencillo de leer y fácil de procesar para las máquinas. Un documento JSON válido se construye con objetos entre llaves, matrices entre corchetes, cadenas entre comillas dobles, números y los valores true, false y null. El formato no cambia lo que significan los datos, pero cambia lo fácil que es leerlos para una persona. El JSON minificado, sin espacios, es más pequeño y rápido de enviar por la red, por eso lo usan las API, pero es casi imposible de leer o depurar. El JSON embellecido, con sangría de dos espacios y un valor por línea, es más grande pero permite detectar una coma que falta o un corchete erróneo en segundos.

Los errores JSON más comunes

  • Comas que faltan o sobran: cada elemento de un objeto o matriz excepto el último necesita una coma, y una coma final tras el último elemento no está permitida en JSON estricto.
  • Comillas simples en lugar de dobles: las cadenas JSON deben usar comillas dobles, aunque el código JavaScript a menudo permita comillas simples.
  • Claves sin comillas: las claves de objeto deben ser cadenas entre comillas, así que {name: "Ana"} no es válido y debe ser {"name": "Ana"}.
  • Comentarios: JSON no permite comentarios, así que las líneas que empiezan con // romperán el análisis aunque parezcan inofensivas.
  • Texto sobrante o varios documentos: pegar dos objetos JSON uno tras otro no es válido; envuélvelos en una matriz o corrígelos uno a uno.

Formatear frente a minificar: cuándo usar cada uno

Usa Formatear cuando estés leyendo, depurando o aprendiendo de un JSON, porque la sangría revela la estructura de un vistazo y hace evidente el anidamiento. Usa Minificar cuando necesites pegar JSON en una URL, un campo de configuración compacto, una petición de prueba o un mensaje donde el tamaño importa y la legibilidad no. Usa Solo validar cuando solo necesites un sí o un no, por ejemplo antes de guardar un archivo de configuración, porque comprueba el JSON sin sustituir tu texto original. En los tres casos la herramienta primero analiza el JSON, así que un resultado formateado o minificado está garantizado como válido; si el análisis falla, recibes un error en lugar de una salida rota en silencio, que es exactamente lo que quieres antes de publicar código.

Privacidad y límites

Este formateador funciona por completo en tu navegador. Tu JSON nunca se sube, se registra ni se comparte, lo que importa porque el JSON a menudo contiene claves de API, datos personales o configuración interna. Nunca pegues secretos en ningún formateador en línea en el que no confíes, y cambia cualquier clave que expongas por accidente. La herramienta gestiona con facilidad respuestas de API y archivos de configuración habituales, pero documentos extremadamente grandes, de decenas de megabytes, pueden ser lentos en una pestaña del navegador porque analizarlos y volver a convertirlos consume memoria. También sigue reglas JSON estrictas, así que rechazará extras propios de JavaScript como comas finales, comillas simples y comentarios, aunque algunas herramientas los acepten de forma flexible.

Preguntas frecuentes

¿Cuál es la diferencia entre Formatear y Minificar?
Formatear añade sangría y saltos de línea para que el JSON sea fácil de leer para las personas. Minificar elimina todos los espacios y saltos innecesarios para que el JSON sea lo más pequeño posible para enviarlo o guardarlo.
¿Por qué mi JSON falla con un error de coma final?
El JSON estricto no permite una coma después del último elemento de un objeto o matriz. Elimina esa coma final y el JSON se analizará.
¿Puedo usar comillas simples en JSON?
No. Las cadenas y claves JSON deben usar comillas dobles. Las comillas simples funcionan en código JavaScript, pero no son JSON válido y esta herramienta las rechazará correctamente.
¿Mis datos JSON se guardan o se envían a algún sitio?
No. El formato y la validación se hacen por completo en tu navegador, así que tus datos nunca salen de tu dispositivo.
¿El formato cambia mis datos?
No. Formatear y minificar solo cambian espacios y saltos de línea. Los valores, claves y estructura quedan exactamente igual, siempre que el JSON fuera válido desde el principio.
