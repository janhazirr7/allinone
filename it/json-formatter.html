Cos'è JSON e perché la formattazione è importante

JSON, abbreviazione di JavaScript Object Notation, è il modo più comune con cui i computer scambiano dati strutturati sul web. API, file di configurazione e molte app parlano tutti JSON perché è semplice da leggere e facile da analizzare per le macchine. Un documento JSON valido è costituito da oggetti tra parentesi graffe, matrici tra parentesi quadre, stringhe tra virgolette doppie, numeri e i valori true, false e null. La formattazione non cambia il significato dei dati, ma cambia la facilità di lettura per un essere umano. JSON minimizzato, con tutti gli spazi rimossi, è più piccolo e più veloce da inviare su una rete, motivo per cui le API lo utilizzano, ma è quasi impossibile da leggere o eseguire il debug. JSON abbellito, con rientro di due spazi e un valore per riga, è più grande ma ti consente di individuare una virgola mancante o una parentesi sbagliata in pochi secondi.

Gli errori JSON più comuni

  • Virgole mancanti o aggiuntive: ogni elemento in un oggetto o array tranne l'ultimo necessita di una virgola e una virgola finale dopo l'ultimo elemento non è consentita in JSON rigoroso.
  • Virgolette singole anziché virgolette doppie: le stringhe JSON devono utilizzare virgolette doppie, anche se il codice JavaScript spesso consente le virgolette singole.
  • Chiavi senza virgolette: le chiavi degli oggetti devono essere stringhe tra virgolette, quindi {name: "Ana"} non è valido e deve essere {"name": "Ana"}.
  • Commenti: JSON non consente commenti, quindi le righe che iniziano con // interromperanno l'analisi anche se sembrano innocue.
  • Testo finale o più documenti: incollare due oggetti JSON uno dopo l'altro non è valido; avvolgili in un array o fissali uno alla volta.

Formattazione e minimizzazione: quando utilizzarle

Utilizza il formato durante la lettura, il debug o l'apprendimento da JSON, perché il rientro rivela la struttura a colpo d'occhio e rende evidente l'annidamento. Utilizza Minimizza quando devi incollare JSON in un URL, un campo di configurazione compatto, una richiesta di test o un messaggio in cui le dimensioni contano e la leggibilità no. Utilizza Convalida solo quando hai solo bisogno di una risposta sì o no, ad esempio prima di salvare un file di configurazione, perché controlla il JSON senza sostituire il testo originale. In tutti e tre i casi lo strumento analizza prima il JSON, quindi è garantita la validità di un risultato minimizzato o formattato; se l'analisi fallisce, viene visualizzato un errore invece di un output interrotto silenziosamente, che è esattamente ciò che desideri prima di spedire il codice.

Privacy e limiti

Questo formattatore funziona interamente nel tuo browser. Il tuo JSON non viene mai caricato, registrato o condiviso, il che è importante perché JSON spesso contiene chiavi API, dati personali o configurazione interna. Non incollare mai i segreti in un formattatore online di cui non ti fidi e ruota qualsiasi chiave che esponi accidentalmente. Lo strumento gestisce facilmente le tipiche risposte API e i file di configurazione, ma documenti estremamente grandi, decine di megabyte, potrebbero essere lenti in una scheda del browser perché l'analisi e la ristringificazione richiede memoria. Segue inoltre rigide regole JSON, quindi rifiuterà gli extra in stile JavaScript come virgole finali, virgolette singole e commenti, anche se alcuni strumenti li accettano in modo approssimativo.

Domande frequenti (FAQ)

Qual è la differenza tra Formato e Minimizza?
Il formato aggiunge rientro e interruzioni di riga in modo che JSON sia facile da leggere per gli esseri umani. Minimizza rimuove tutti gli spazi e le interruzioni di riga non necessari in modo che JSON sia il più piccolo possibile per l'invio o l'archiviazione.
Perché il mio JSON fallisce con un errore di virgola finale?
JSON rigoroso non consente una virgola dopo l'ultimo elemento in un oggetto o array. Rimuovi la virgola finale e il JSON verrà analizzato.
Posso utilizzare virgolette singole in JSON?
No. Le stringhe e le chiavi JSON devono utilizzare virgolette doppie. Le virgolette singole funzionano nel codice JavaScript, ma non sono JSON validi e questo strumento le rifiuterà correttamente.
I miei dati JSON vengono archiviati o inviati ovunque?
No. La formattazione e la convalida vengono eseguite interamente nel tuo browser, quindi i tuoi dati non lasciano mai il tuo dispositivo.
La formattazione modifica i miei dati?
No. La formattazione e la minimizzazione modificano solo la spaziatura e le interruzioni di riga. I valori, le chiavi e la struttura rimangono esattamente gli stessi, purché il JSON fosse valido all'inizio.
