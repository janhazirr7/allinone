Che cos'è JSON e perché la formattazione conta

JSON, abbreviazione di JavaScript Object Notation, è il modo più comune con cui i computer scambiano dati strutturati sul web. API, file di configurazione e molte app parlano JSON perché è semplice da leggere e facile da analizzare per le macchine. Un documento JSON valido è composto da oggetti tra parentesi graffe, array tra parentesi quadre, stringhe tra virgolette doppie, numeri e i valori true, false e null. La formattazione non cambia il significato dei dati, ma cambia quanto è facile leggerli per una persona. Il JSON ridotto, con tutti gli spazi rimossi, è più piccolo e più veloce da inviare in rete, ed è per questo che lo usano le API, ma è quasi impossibile da leggere o da correggere. Il JSON abbellito, con rientri di due spazi e un valore per riga, è più grande ma permette di individuare in pochi secondi una virgola mancante o una parentesi sbagliata.

Gli errori JSON più comuni

  • Virgole mancanti o in più: ogni elemento di un oggetto o di un array, tranne l'ultimo, ha bisogno di una virgola, e una virgola finale dopo l'ultimo elemento non è ammessa nel JSON stretto.
  • Virgolette singole al posto di virgolette doppie: le stringhe JSON devono usare virgolette doppie, anche se il codice JavaScript spesso permette le virgolette singole.
  • Chiavi senza virgolette: le chiavi degli oggetti devono essere stringhe tra virgolette, quindi {name: "Ana"} non è valido e deve essere {"name": "Ana"}.
  • Commenti: JSON non permette commenti, quindi le righe che iniziano con // interrompono l'analisi anche se sembrano innocue.
  • Testo in coda o documenti multipli: incollare due oggetti JSON uno dopo l'altro non è valido; racchiudili in un array oppure correggili uno alla volta.

Formattazione o riduzione: quando usare ciascuna

Usa Formatta quando stai leggendo, correggendo o imparando dal JSON, perché il rientro rivela la struttura a colpo d'occhio e rende evidente l'annidamento. Usa Riduci quando devi incollare il JSON in un URL, in un campo di configurazione compatto, in una richiesta di test o in un messaggio in cui conta la dimensione e non la leggibilità. Usa Solo valida quando ti serve solo una risposta sì o no, per esempio prima di salvare un file di configurazione, perché controlla il JSON senza sostituire il tuo testo originale. In tutti e tre i casi lo strumento prima analizza il JSON, quindi un risultato ridotto o formattato è garantito valido; se l'analisi fallisce, ricevi un errore invece di un output silenziosamente rotto, che è esattamente ciò che vuoi prima di pubblicare del codice.

Privacy e limiti

Questo formattatore funziona interamente nel tuo browser. Il tuo JSON non viene mai caricato, registrato o condiviso, il che conta perché il JSON contiene spesso chiavi API, dati personali o configurazioni interne. Non incollare mai segreti in un formattatore online di cui non ti fidi, e cambia subito qualsiasi chiave esposta per sbaglio. Lo strumento gestisce facilmente le tipiche risposte API e i file di configurazione, ma documenti enormi, di decine di megabyte, potrebbero risultare lenti in una scheda del browser perché analizzarli e ricomporli richiede memoria. Segue inoltre le regole strette del JSON, quindi rifiuterà extra in stile JavaScript come virgole finali, virgolette singole e commenti, anche se alcuni strumenti li accettano in modo permissivo.

Domande frequenti (FAQ)

Qual è la differenza tra Formatta e Riduci?
Formatta aggiunge rientri e interruzioni di riga in modo che il JSON sia facile da leggere per le persone. Riduci rimuove tutti gli spazi e le interruzioni di riga non necessari, così il JSON è il più piccolo possibile per l'invio o l'archiviazione.
Perché il mio JSON fallisce con un errore di virgola finale?
Il JSON stretto non permette una virgola dopo l'ultimo elemento di un oggetto o di un array. Rimuovi quella virgola finale e il JSON verrà analizzato.
Posso usare virgolette singole in JSON?
No. Stringhe e chiavi JSON devono usare virgolette doppie. Le virgolette singole funzionano nel codice JavaScript, ma non sono JSON valido e questo strumento le rifiuterà correttamente.
I miei dati JSON vengono salvati o inviati da qualche parte?
No. Formattazione e validazione avvengono interamente nel tuo browser, quindi i tuoi dati non lasciano mai il tuo dispositivo.
La formattazione cambia i miei dati?
No. Formattazione e riduzione cambiano solo spazi e interruzioni di riga. Valori, chiavi e struttura restano esattamente uguali, purché il JSON fosse valido fin dall'inizio.
